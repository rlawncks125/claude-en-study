## 📚 오늘의 학습 목표
- 미래를 표현하는 3가지 방법 이해하기 (will, be going to, 현재진행형)
- 각 미래형의 차이점과 사용 상황 파악
- 계획, 예측, 일정을 영어로 표현하기
- 비즈니스 약속과 의도 표현하기

**학습 시간**: 40분

## 1️⃣ 미래형 3가지 핵심 (10분)

### 1) Will - 즉석 결정, 예측, 약속

#### 형태
```
will + 동사원형
will not (won't) + 동사원형
```

#### 사용 상황

**A) 즉석 결정** (지금 막 결정)
```
A: We need coffee.
B: I'll buy some. (지금 결정)

The phone is ringing. I'll answer it.
(전화 울리네. 내가 받을게 - 즉석)
```

**B) 예측** (생각/추측)
```
I think the meeting will take 2 hours.
(미팅이 2시간 걸릴 것 같아요)

The project will probably succeed.
(프로젝트가 아마 성공할 거예요)
```

**C) 약속/의지**
```
I will send you the file today.
(오늘 파일을 보내드리겠습니다)

We will do our best.
(최선을 다하겠습니다)
```

### 2) Be going to - 계획, 의도, 확실한 예측

#### 형태
```
am/is/are + going to + 동사원형
```

#### 사용 상황

**A) 계획/의도** (이미 결정함)
```
I'm going to meet a client tomorrow.
(내일 고객을 만날 거예요 - 이미 계획)

We are going to launch the product next month.
(다음 달에 제품을 출시할 예정입니다)
```

**B) 확실한 예측** (증거가 있음)
```
Look at those clouds. It's going to rain.
(저 구름 봐. 비 올 거야 - 구름 보임)

The project is going to fail. We don't have enough resources.
(프로젝트가 실패할 거예요. 자원이 부족해요)
```

### 3) 현재진행형 - 확정된 일정

#### 형태
```
am/is/are + -ing
```

#### 사용 상황
확정된 미래 일정 (약속, 예약)
```
I'm meeting the CEO at 3pm.
(3시에 CEO를 만나요 - 약속 잡힘)

We are having a conference call tomorrow.
(내일 전화회의 해요 - 일정 확정)

She is flying to New York next week.
(다음 주에 뉴욕으로 가요 - 항공권 예약)
```

### 비교 정리
| Will | Be going to | 현재진행형 |
|------|-------------|----------|
| 즉석 결정 | 계획/의도 | 확정 일정 |
| 예측 (생각) | 예측 (증거) | 약속/예약 |
| 약속/의지 | - | - |
| **I'll call you** | **I'm going to call you** | **I'm calling you at 3pm** |
| (지금 결정) | (이미 계획) | (3시 약속) |

## 2️⃣ 핵심 어휘 25개 (10분)

### 비즈니스 동사
| 동사 | 뜻 | 예문 |
|------|-----|------|
| schedule | 일정을 잡다 | I'll schedule a meeting. |
| plan | 계획하다 | We're planning to expand. |
| launch | 출시하다 | We're launching next month. |
| implement | 실행하다 | We will implement the system. |
| expand | 확장하다 | We're going to expand our business. |
| hire | 고용하다 | We're hiring 10 people. |
| attend | 참석하다 | I'm attending the conference. |
| present | 발표하다 | I'm presenting tomorrow. |
| discuss | 논의하다 | We'll discuss it later. |
| review | 검토하다 | I'll review the document. |
| prepare | 준비하다 | I'm going to prepare the report. |
| arrange | 준비하다 | I'll arrange everything. |
| contact | 연락하다 | I'll contact you soon. |
| update | 업데이트하다 | We'll update the system. |
| improve | 개선하다 | We're going to improve quality. |

### 시간 표현
| 표현 | 뜻 |
|------|-----|
| tomorrow | 내일 |
| next week/month/year | 다음 주/달/해 |
| in 2 days | 2일 후 |
| in 3 weeks | 3주 후 |
| soon | 곧 |
| later | 나중에 |
| this afternoon | 오늘 오후 |
| by Friday | 금요일까지 |

| in the near future | 가까운 미래에 |

## 3️⃣ 실전 대화 (10분)

### 대화 1: 일정 조율
```
A: What are you doing tomorrow?
   (내일 뭐 해요?)

B: I'm meeting a supplier at 10, and then I'm having
   lunch with the team.
   (10시에 공급업체 만나고, 그 다음 팀이랑 점심 먹어요.)

A: Okay. I'll schedule our meeting for 2pm then.
   (알았어요. 그럼 우리 미팅은 2시로 잡을게요.)

B: Perfect. What are we going to discuss?
   (완벽해요. 우리 뭐 논의할 건가요?)

A: We'll talk about the new project.
   (새 프로젝트에 대해 이야기할 거예요.)
```

### 대화 2: 프로젝트 계획
```
Manager: What are your plans for next quarter?
        (다음 분기 계획이 뭐예요?)

Employee: We are going to focus on digital marketing.
         We're planning to launch 3 new campaigns.
         (디지털 마케팅에 집중할 예정입니다.
         3개의 새 캠페인을 출시할 계획입니다.)

Manager: Good. When will you start?
        (좋아요. 언제 시작할 건가요?)

Employee: We'll begin in April. I'm meeting the team
         next week to finalize the details.
         (4월에 시작할 거예요. 다음 주에 팀을 만나
         세부사항을 확정할 거예요.)

Manager: Excellent. I think this will bring great results.
        (훌륭해요. 좋은 결과가 나올 것 같아요.)
```

### 대화 3: 즉석 제안과 도움
```
A: I need to send this package urgently.
   (이 소포를 급히 보내야 해요.)

B: I'll go to the post office this afternoon.
   I can send it for you.
   (오늘 오후에 우체국 갈 거예요. 대신 보내줄게요.)

A: Really? That would be great! I'm meeting a client
   at that time.
   (정말요? 좋겠어요! 그 시간에 고객 만나거든요.)

B: No problem. Just give it to me before lunch.
   (문제없어요. 점심 전에 저한테 주세요.)

A: Thanks! I'll buy you coffee later.
   (고마워요! 나중에 커피 살게요.)
```

## 4️⃣ 비즈니스 표현 (5분)

### 약속 표현 (이메일에서 자주 사용)
```
✅ I will send you the document by tomorrow.
   (내일까지 문서를 보내드리겠습니다)

✅ We will get back to you within 24 hours.
   (24시간 내에 연락드리겠습니다)

✅ I will make sure it's done.
   (반드시 완료되도록 하겠습니다)

✅ I will check and let you know.
   (확인하고 알려드리겠습니다)
```

### 계획 발표
```
✅ We are going to implement a new system.
   (새로운 시스템을 도입할 예정입니다)

✅ The company is going to open 5 new branches.
   (회사가 5개의 새 지점을 열 예정입니다)

✅ We are planning to hire 20 people this year.
   (올해 20명을 채용할 계획입니다)

✅ I'm going to schedule a meeting for next week.
   (다음 주에 미팅을 잡을 예정입니다)
```

### 일정 확인
```
✅ I'm meeting a client at 10am.
   (10시에 고객을 만나요)

✅ We are having a conference call tomorrow.
   (내일 전화회의 해요)

✅ She is presenting at the event next month.
   (다음 달 행사에서 발표해요)

✅ Are you attending the meeting?
   (미팅에 참석하시나요?)
```

### 예측 표현
```
✅ I think the sales will increase.
   (매출이 증가할 것 같아요)

✅ The project will probably take 3 months.
   (프로젝트가 아마 3개월 걸릴 거예요)

✅ This will be challenging, but possible.
   (이게 도전적이겠지만 가능할 거예요)

✅ Look at the data. Sales are going to increase.
   (데이터를 보세요. 매출이 증가할 거예요)
```

## 5️⃣ 연습 문제 (5분)

### 문제 1: will / be going to / 현재진행형 선택
1. A: Why are you holding a laptop?
   B: I __________ (give) a presentation now.

2. A: We need more chairs.
   B: I __________ (get) some from the other room.

3. Look at the sky! It __________ (rain).

4. I __________ (meet) the client at 3pm tomorrow. (일정 확정)

5. I think the economy __________ (improve) next year.

### 문제 2: 빈칸 채우기 (적절한 형태)
1. We __________ (launch) the new product next month. (계획)
2. She __________ (not/attend) the meeting. She's traveling. (확정)
3. __________ you __________ (join) us for lunch? (즉석 제안)
4. The company __________ (hire) 50 people this year. (계획)
5. I __________ (send) you the file right now. (즉석)

### 문제 3: 나의 계획 쓰기
```
내일: I'm _____________ (확정 일정)
다음 주: I'm going to _____________ (계획)
미래에: I will _____________ (의지/목표)
```

## 📝 정답

4. I'm meeting (3시 약속 - 확정)

### 문제 2
1. are going to launch (계획)

3. Will, join (즉석 제안)
4. is going to hire (계획)
5. will send / 'll send (즉석 결정)

## ⚠️ 주의사항

### 시간/조건절에서는 will 사용 안 함!
```
❌ When he will arrive, call me.
✅ When he arrives, call me.
(그가 도착하면 전화해)

❌ If it will rain, we will cancel.
✅ If it rains, we will cancel.
(비가 오면 취소할 거예요)
```

**주의**: when, if, before, after, as soon as 등의 절에서는 미래여도 **현재형** 사용!
