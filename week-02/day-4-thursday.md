# Week 2 - Day 4 (목요일): 전치사와 접속사

## 📚 오늘의 학습 목표
- 시간/장소 전치사 마스터하기 (at, in, on)
- 비즈니스 전치사 활용하기 (by, for, with, about)
- 접속사로 복잡한 문장 만들기 (and, but, because, if, when)
- 논리적으로 말하고 쓰기

**학습 시간**: 40분

---

## 1️⃣ 전치사 핵심 (15분)

### A) 시간 전치사

#### at - 특정 시각
```
at 9am (9시에)
at noon (정오에)
at the moment (지금)
at the end of the month (월말에)

The meeting is at 2pm.
(미팅은 2시예요)
```

#### on - 특정 날짜/요일
```
on Monday (월요일에)
on June 15th (6월 15일에)
on weekdays (평일에)
on the weekend (주말에)

We have a deadline on Friday.
(금요일이 마감이에요)
```

#### in - 기간/달/년도
```
in the morning (아침에)
in January (1월에)
in 2024 (2024년에)
in 10 minutes (10분 후에)

I'll finish it in 2 hours.
(2시간 안에 끝낼게요)
```

#### 기타 시간 전치사
```
before the meeting (미팅 전에)
after lunch (점심 후에)
by Friday (금요일까지)
during the presentation (프레젠테이션 중에)
from 9 to 6 (9시부터 6시까지)
since 2020 (2020년부터)
for 3 years (3년 동안)
```

### B) 장소 전치사

#### at - 지점/특정 장소
```
at the office (사무실에)
at work (직장에)
at the meeting (미팅에서)
at home (집에)

I'm at a meeting now.
(지금 미팅 중이에요)
```

#### in - 공간 안
```
in the office (사무실 안에)
in Seoul (서울에)
in Korea (한국에)
in the company (회사에)

She works in the marketing department.
(마케팅 부서에서 일해요)
```

#### on - 표면/층
```
on the desk (책상 위에)
on the 5th floor (5층에)
on the street (거리에)
on the left/right (왼쪽/오른쪽에)

Our office is on the 10th floor.
(우리 사무실은 10층에 있어요)
```

### C) 비즈니스 전치사

#### by - 방법/수단
```
by email (이메일로)
by phone (전화로)
by car (차로)
by credit card (신용카드로)
by Friday (금요일까지)

Please send it by email.
(이메일로 보내주세요)
```

#### for - 목적/기간/대상
```
for business (업무 목적으로)
for 3 years (3년 동안)
for you (당신을 위해)
work for a company (회사에서 일하다)

I work for Samsung.
(삼성에서 일해요)
```

#### with - 함께/도구
```
with a client (고객과 함께)
with my team (내 팀과 함께)
with this software (이 소프트웨어로)

I'm working with the sales team.
(영업팀과 함께 일하고 있어요)
```

#### about/on - 주제
```
talk about the project (프로젝트에 대해)
a meeting about sales (매출에 관한 미팅)
a report on performance (성과에 관한 보고서)

We'll discuss about the budget.
→ We'll discuss the budget. (discuss는 전치사 불필요!)
```

#### of - 소속/소유
```
a member of the team (팀의 일원)
the CEO of the company (회사의 CEO)
one of the best (최고 중 하나)

I'm a member of the marketing team.
(마케팅 팀의 일원입니다)
```

## 2️⃣ 접속사 핵심 (10분)

### A) 등위접속사 (같은 레벨 연결)

#### and - 그리고 (추가)
```
I work and study.
(일하고 공부해요)

We develop and sell software.
(소프트웨어를 개발하고 판매합니다)
```

#### but - 하지만 (대조)
```
It's expensive, but it's worth it.
(비싸지만 그만한 가치가 있습니다)

I want to help, but I'm busy.
(돕고 싶지만 바쁩니다)
```

#### or - 또는 (선택)
```
Coffee or tea?
(커피 아니면 차?)

We can meet on Monday or Tuesday.
(월요일이나 화요일에 만날 수 있어요)
```

#### so - 그래서 (결과)
```
I was late, so I took a taxi.
(늦어서 택시를 탔어요)

The deadline is tight, so we need to hurry.
(마감이 촉박해서 서둘러야 해요)
```

### B) 종속접속사 (주절 + 종속절)

#### because - ~이기 때문에 (이유)
```
I'm late because of traffic.
(교통 때문에 늦었어요)

We chose this vendor because they offer the best price.
(최고의 가격을 제공하기 때문에 이 업체를 선택했습니다)
```

#### if - 만약 ~하면 (조건)
```
If you need help, call me.
(도움이 필요하면 전화하세요)

If you have questions, please ask.
(질문이 있으시면 말씀해주세요)
```

#### when - ~할 때 (시간)
```
Call me when you arrive.
(도착하면 전화하세요)

When the project is complete, we'll celebrate.
(프로젝트가 완료되면 축하할 거예요)
```

#### before/after - ~전에/후에
```
Check it before you send it.
(보내기 전에 확인하세요)

Let's talk after the meeting.
(미팅 후에 이야기해요)
```

#### although - 비록 ~이지만 (양보)
```
Although it's difficult, it's possible.
(어렵지만 가능해요)

Although the project is challenging, we'll complete it.
(프로젝트가 도전적이지만 완료할 거예요)
```

#### as soon as - ~하자마자
```
I'll call you as soon as I finish.
(끝나는 대로 전화할게요)

I'll send the file as soon as it's ready.
(준비되는 대로 파일을 보내드리겠습니다)
```

## 3️⃣ 실전 대화 (10분)

### 대화 1: 일정과 장소
```
A: When is the meeting?
   (미팅이 언제예요?)

B: It's on Tuesday at 10am.
   (화요일 10시예요.)

A: Where should we meet?
   (어디서 만날까요?)

B: At the conference room on the 3rd floor.
   (3층 회의실에서요.)

A: Okay. What are we going to discuss?
   (알겠어요. 뭘 논의할 건가요?)

B: We'll talk about the new project and the budget.
   (새 프로젝트와 예산에 대해 이야기할 거예요.)
```

### 대화 2: 연락 방법
```
A: How can I contact you?
   (어떻게 연락드릴까요?)

B: You can reach me by email or phone.
   I work from 9 to 6, so call me during that time.
   (이메일이나 전화로 연락 가능해요.
   9시부터 6시까지 일하니까 그 시간에 전화하세요.)

A: What's the best time to call?
   (전화하기 가장 좋은 시간이 언제예요?)

B: Between 2 and 4 in the afternoon would be best,
   because I'm usually in meetings in the morning.
   (오후 2시에서 4시 사이가 가장 좋아요,
   아침에는 보통 미팅 중이거든요.)
```

### 대화 3: 프로젝트 진행
```
A: The system is not working. What should we do?
   (시스템이 작동하지 않아요. 어떻게 해야 하죠?)

B: I'll call IT support right now, and they will fix it soon.
   (지금 IT 지원팀에 전화할게요, 그리고 곧 고칠 거예요.)

A: When can they come?
   (언제 올 수 있나요?)

B: They are coming at 2pm.
   While we wait, we can work on other tasks.
   (2시에 와요. 기다리는 동안 다른 업무를 할 수 있어요.)

A: Good idea. Let's prepare the report, so we don't waste time.
   (좋은 생각이에요. 시간 낭비하지 않도록 보고서를 준비합시다.)
```

## 4️⃣ 비즈니스 표현 (5분)

### 이메일/서신
```
✅ I'll contact you by email.
   (이메일로 연락드리겠습니다)

✅ Please send it to me by Friday.
   (금요일까지 보내주세요)

✅ I'll get back to you in 24 hours.
   (24시간 내에 연락드리겠습니다)

✅ If you have questions, please let me know.
   (질문이 있으시면 알려주세요)
```

### 회의/미팅
```
✅ The meeting is on Monday at 10am.
   (미팅은 월요일 10시예요)

✅ Let's meet at the conference room.
   (회의실에서 만나요)

✅ Before we start, let me introduce everyone.
   (시작하기 전에 모두를 소개하겠습니다)

✅ After the presentation, we'll have Q&A.
   (프레젠테이션 후에 질의응답이 있을 거예요)
```

### 업무 협력
```
✅ I work for Samsung in the IT department.
   (삼성 IT 부서에서 일해요)

✅ I'm working with the sales team on this project.
   (이 프로젝트에서 영업팀과 함께 일하고 있어요)

✅ I'm responsible for marketing.
   (마케팅을 담당하고 있어요)

✅ We've been partners since 2020.
   (2020년부터 파트너였습니다)
```

### 논리적 설명
```
✅ We need to act quickly because the market is changing.
   (시장이 변하고 있기 때문에 빨리 행동해야 합니다)

✅ Although it's expensive, it's worth the investment.
   (비싸지만 투자할 가치가 있습니다)

✅ If we work together, we will succeed.
   (함께 일하면 성공할 거예요)

✅ When the project is done, we'll move to the next phase.
   (프로젝트가 끝나면 다음 단계로 이동할 거예요)
```

## ⚠️ 주의사항

### 1. at/in/on 혼동 주의
```
❌ I work in Samsung. (회사 이름)
✅ I work for Samsung. / I work at Samsung.

❌ The meeting is in Monday.
✅ The meeting is on Monday.
```

### 2. discuss는 전치사 불필요
```
❌ discuss about the problem
✅ discuss the problem
```

### 3. because vs because of
```
✅ because + 주어 + 동사
I'm late because the train was delayed.

✅ because of + 명사
I'm late because of the train delay.
```
