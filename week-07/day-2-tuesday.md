## 🚨 The 4 Phases of Crisis Management

### Phase 1: PREVENTION (예방)

**Proactive Measures:**
```
✓ Risk assessment and monitoring
✓ Crisis communication plan
✓ Spokesperson training
✓ Media relationship building
✓ Social media monitoring
```

**Key Actions:**
- Identify potential crisis scenarios
- Establish crisis team and roles
- Create holding statements
- Set up communication channels
- Conduct simulation drills

---

### Phase 2: PREPARATION (준비)

**Crisis Communication Team:**
```
1. Crisis Leader (CEO/Senior Executive)
2. Spokesperson (Media Relations)
3. Legal Counsel
4. PR/Communications Director
5. Operations Lead
6. HR Representative
7. Social Media Manager
```

**Essential Documents:**
```
✓ Crisis Communication Plan
✓ Contact Lists (internal/external)
✓ Holding Statements
✓ Q&A Documents
✓ Social Media Protocols
✓ Media Training Guidelines
```

---

### Phase 3: RESPONSE (대응)

**The Golden Hour Rule:**
```
First 60 minutes are CRITICAL
↓
Gather facts → Assess impact → Activate team
→ Issue holding statement → Monitor situation
```

**The 3 Cs of Crisis Response:**

**1. CONTROL the narrative**
```
✓ Be first to communicate
✓ Use official channels
✓ Speak with one voice
✓ Provide regular updates
```

**2. COMPASSION for affected parties**
```
✓ Express genuine concern
✓ Acknowledge impact
✓ Show empathy
✓ Offer support
```

**3. COMMITMENT to resolution**
```
✓ Outline action steps
✓ Provide timeline
✓ Assign responsibility
✓ Follow through
```

---

### Phase 4: RECOVERY (회복)

**Post-Crisis Activities:**
```
1. Continue stakeholder communication
2. Conduct post-mortem analysis
3. Update crisis plans
4. Rebuild trust and reputation
5. Implement corrective measures
6. Share lessons learned
```

## 📺 Media Interview Techniques

### The Message House Framework

```
                    HEADLINE MESSAGE
                   (One key message)
                          │
         ┌────────────────┼────────────────┐
         │                │                │
    Supporting       Supporting       Supporting
    Point #1         Point #2         Point #3
         │                │                │
    Evidence         Evidence         Evidence
    Examples         Examples         Examples
```

### Example: Data Breach Crisis

```
HEADLINE: "We are taking immediate action to protect our customers
          and prevent future incidents."

SUPPORT 1: What happened
- "We detected unauthorized access on [date]"
- "Immediately shut down affected systems"
- "No financial data was compromised"

SUPPORT 2: What we're doing
- "Hired top cybersecurity firm"
- "Notifying all affected customers"
- "Offering free credit monitoring"

SUPPORT 3: How we're preventing this
- "Implementing enhanced security protocols"
- "Conducting full security audit"
- "Investing $X in infrastructure upgrades"
```

## 🎤 Spokesperson Skills: The Bridge Technique

### How to Bridge

**Pattern:**
```
Acknowledge question → Bridge phrase → Your message
```

**Bridge Phrases:**
```
"That's a fair question, and what's important to know is..."
"I understand the concern, and here's what I can tell you..."
"Let me put that in context..."
"What I can say is..."
"Here's what's most important..."
"The real issue here is..."
"Let me be clear about..."
```

### Example Bridging

**Q:** "Isn't this crisis due to management incompetence?"

**Bad Response:**
❌ "No, that's not true at all!" (defensive)

**Good Response:**
✅ "I understand why you'd ask that. What I can tell you is that we've
   taken this matter very seriously from day one. We immediately
   activated our crisis response team, and here's what we're doing..."
   (acknowledge → bridge → message)

## 📋 Crisis Communication Statement Template

### Initial Holding Statement (First Hour)

```
[OPENING - Acknowledge the situation]
"We are aware of [incident] that occurred at [time/location].

[FACTS - What we know]
Our understanding is that [brief factual description].
At this time, [what's confirmed].

[ACTION - What we're doing]
We have immediately [actions taken]. Our top priority is
[safety/security/resolution].

[COMMITMENT - Next steps]
We are working closely with [authorities/experts] to [investigate/resolve].
We will provide updates as we learn more.

[COMPASSION - If applicable]
Our thoughts are with [affected parties].

[CONTACT]
For more information: [contact details]"
```

### Full Crisis Statement (After Investigation)

```
CRISIS STATEMENT TEMPLATE

[HEADLINE MESSAGE]
One sentence summarizing your position

[SITUATION OVERVIEW]
"On [date], [incident occurred]. Here's what happened: [details]"

[IMPACT ASSESSMENT]
"This has affected [scope]. We understand the concern because [empathy]."

[ROOT CAUSE - If known]
"Our investigation has determined that [cause]."

[IMMEDIATE ACTIONS TAKEN]
"We immediately:
• [Action 1]
• [Action 2]
• [Action 3]"

[ONGOING RESPONSE]
"We are currently:
• [Action 1]
• [Action 2]"

[LONG-TERM COMMITMENT]
"To prevent this from happening again, we will:
• [Preventive measure 1]
• [Preventive measure 2]"

[APOLOGY - If appropriate]
"We sincerely apologize for [specific impact]. This is not the standard
we hold ourselves to."

[STAKEHOLDER COMMITMENT]
"To our [customers/employees/partners]: [commitment statement]"

[CLOSING]
"We are committed to [resolution/transparency].
For questions: [contact information]"
```

## ⚠️ Real Crisis Scenarios & Responses

### Scenario 1: Product Recall

**Crisis:**
Manufacturing defect found in 100,000 units; potential safety risk

**Statement:**
```
"Customer safety is our top priority. We have voluntarily recalled
[product] manufactured between [dates] due to [specific issue].

While no injuries have been reported, we are taking this precautionary
measure out of an abundance of caution.

Affected customers will receive:
• Full refund or replacement
• Free return shipping
• Direct customer support line

We have identified the root cause and implemented quality control
enhancements to prevent recurrence.

We apologize for any inconvenience and appreciate your trust in our
commitment to safety."
```

---

### Scenario 2: Executive Misconduct

**Crisis:**
CEO accused of inappropriate behavior; investigation ongoing

**Statement:**
```
"We take all allegations of misconduct extremely seriously and are
committed to fostering a respectful workplace.

Upon receiving these allegations, we immediately:
• Placed the executive on administrative leave
• Engaged an independent third-party investigator
• Implemented additional reporting channels for employees

We will not tolerate behavior inconsistent with our values. The
investigation will be thorough, and we will take appropriate action
based on the findings.

We are committed to transparency within the bounds of confidentiality
and will provide updates as appropriate."
```

---

### Scenario 3: Data Breach

**Crisis:**
Hackers accessed customer database; personal information compromised

**Statement:**
```
"We are writing to inform you of a data security incident that may
have affected your personal information.

WHAT HAPPENED:
On [date], we detected unauthorized access to our systems. We
immediately shut down the affected servers and engaged leading
cybersecurity experts.

WHAT INFORMATION WAS INVOLVED:
Names, email addresses, and [other data]. Importantly, credit card
information and passwords were NOT compromised.

WHAT WE'RE DOING:
• Notifying all affected customers
• Offering 12 months of free identity monitoring
• Implementing enhanced security measures
• Working with law enforcement

WHAT YOU CAN DO:
• Monitor your accounts for suspicious activity
• Enable two-factor authentication
• Contact our dedicated support line: [number]

We sincerely apologize for this incident. We are investing significantly
in security infrastructure to prevent future occurrences and protect
your information."
```

## 🎯 Media Interview Best Practices

### Before the Interview

**Preparation Checklist:**
```
✓ Know your 3 key messages
✓ Anticipate difficult questions
✓ Prepare specific examples
✓ Understand the reporter's angle
✓ Review recent coverage
✓ Practice with colleagues
✓ Get proper rest
```

**Message Discipline:**
```
If I could only say 3 things, what would they be?

1. _________________________________________
2. _________________________________________
3. _________________________________________
```

---

### During the Interview

**Do's:**
```
✓ Stay on message
✓ Speak in sound bites (10-15 seconds)
✓ Use specific examples
✓ Maintain eye contact
✓ Project calm confidence
✓ Correct inaccuracies politely
✓ Bridge back to your messages
```

**Don'ts:**
```
❌ Say "No comment" (sounds guilty)
❌ Speak off the record
❌ Speculate or guess
❌ Repeat negative language
❌ Argue with reporter
❌ Use jargon
❌ Fill silence with rambling
```

**Alternative to "No Comment":**
```
Instead of: "No comment"

Say:
• "I can't discuss that due to [legal/privacy], but what I can say is..."
• "That's not my area of expertise, but I can connect you with..."
• "We're still gathering information on that. What I do know is..."
• "I'm not able to comment on ongoing [litigation/investigation],
   but our position is..."
```

---

### Tough Question Techniques

**1. The Repeat Question**
```
Reporter: "So you're saying costs will increase?"
You: [Answer with bridge] "What I'm saying is we're investing in
     quality while managing costs responsibly."
Reporter: "But costs WILL increase, correct?"
You: [Stay on message] "Our focus is on delivering value. That means
     smart investments in areas that matter most to customers."
```

**2. The Hypothetical**
```
Reporter: "What if the CEO resigns?"
Bad: "Well, if that happened, we'd probably..."
Good: "I'm not going to speculate on hypothetical scenarios. What I
       can tell you is our current focus is on [key message]."
```

**3. The "Off the Record" Trap**
```
Reporter: "Off the record, what really happened?"
Bad: [Sharing anything]
Good: "I appreciate the question, but I prefer to keep everything on
       the record. Here's what I can share..."
```

**4. The False Choice**
```
Reporter: "Are you greedy or incompetent?"
Bad: Choosing either option
Good: "Neither characterization is accurate. The reality is [your message]."
```

**5. The Loaded Question**
```
Reporter: "When did you stop ignoring customer complaints?"
Bad: "We never ignored..." (repeats negative)
Good: "Customer feedback is central to how we operate. In fact, [positive example]."
```

## 📱 Social Media Crisis Management

### Social Media Response Timeline

```
MINUTES 0-15: Monitor and Assess
- Track mentions and sentiment
- Determine severity
- Alert crisis team

MINUTES 15-30: Initial Response
- Post acknowledgment
- Provide initial information
- Direct to official channels

HOURS 1-4: Ongoing Updates
- Regular updates (every 30-60 min)
- Respond to questions
- Correct misinformation

DAYS 1-7: Active Management
- Continue communication
- Share resolution steps
- Monitor sentiment shifts

WEEKS 2+: Recovery & Rebuild
- Share outcomes
- Highlight improvements
- Restore normal communications
```

### Social Media Response Template

**Acknowledgment Post:**
```
"We're aware of [issue]. We're looking into this and will share
updates as we have them. Thank you for your patience."
```

**Update Post:**
```
"Update on [issue]: [Brief factual information].
We're [action being taken]. More details: [link]"
```

**Resolution Post:**
```
"Resolved: [Issue] has been addressed. [Brief explanation].
Thank you for your patience. We've learned [lesson] and are
implementing [improvement]."
```
