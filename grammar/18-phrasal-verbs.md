# 구동사 (Phrasal Verbs)

## 📖 개념

**구동사 (Phrasal Verb)**: 동사 + 전치사/부사가 결합하여 새로운 의미를 만드는 표현

```
일반 동사: look (보다)
구동사: look into (조사하다)
        look after (돌보다)
        look forward to (기대하다)
```

구동사는 영어에서 매우 자연스럽고 빈번하게 사용되며, 특히 비즈니스 영어에서 필수적입니다.

---

## 1️⃣ 구동사의 종류

### A. 분리 가능 (Separable)
목적어가 명사일 때는 중간이나 뒤에, 대명사일 때는 반드시 중간에 위치합니다.

```
✓ Turn off the computer.
✓ Turn the computer off.
✓ Turn it off. (대명사는 반드시 중간!)
✗ Turn off it.

✓ Fill out the form.
✓ Fill the form out.
✓ Fill it out.
✗ Fill out it.
```

### B. 분리 불가능 (Inseparable)
목적어가 항상 구동사 뒤에 위치합니다.

```
✓ Look into the matter.
✗ Look the matter into.

✓ Look after the clients.
✗ Look the clients after.

✓ Come across a problem.
✗ Come a problem across.
```

### C. 3단어 구동사
동사 + 부사 + 전치사 조합으로, 항상 분리 불가능합니다.

```
✓ We need to catch up with the competition.
✓ I'm looking forward to the meeting.
✓ She came up with a great idea.
```

## 2️⃣ 비즈니스 영어 필수 구동사 50+

### A. 비즈니스 운영 (Business Operations)

#### 1. Set up (설립하다, 준비하다)
```
✓ We set up the company in 2020.
  (우리는 2020년에 회사를 설립했습니다)

✓ Can you help me set up the meeting room?
  (회의실 준비하는 것 좀 도와주실 수 있나요?)

✓ They're setting up a new branch in Seoul.
  (그들은 서울에 새 지점을 설립하고 있습니다)
```

#### 2. Carry out (수행하다, 실행하다)
```
✓ We need to carry out market research.
  (우리는 시장 조사를 수행해야 합니다)

✓ The team carried out the project successfully.
  (팀이 프로젝트를 성공적으로 수행했습니다)

✓ How will you carry out this plan?
  (이 계획을 어떻게 실행하실 건가요?)
```

#### 3. Take over (인수하다, 넘겨받다)
```
✓ Samsung took over the company last year.
  (삼성이 작년에 그 회사를 인수했습니다)

✓ Who will take over when the CEO retires?
  (CEO가 은퇴하면 누가 넘겨받나요?)

✓ She took over the project from John.
  (그녀가 존으로부터 프로젝트를 넘겨받았습니다)
```

#### 4. Phase out (단계적으로 중단하다)
```
✓ We're phasing out the old system.
  (우리는 구 시스템을 단계적으로 중단하고 있습니다)

✓ The product will be phased out by Q4.
  (그 제품은 4분기까지 단계적으로 중단될 것입니다)
```

#### 5. Scale up/down (확대/축소하다)
```
✓ We need to scale up production.
  (우리는 생산을 확대해야 합니다)

✓ They scaled down operations due to COVID.
  (코로나로 인해 그들은 운영을 축소했습니다)
```

#### 6. Cut back (삭감하다)
```
✓ We had to cut back on expenses.
  (우리는 비용을 삭감해야 했습니다)

✓ They're cutting back staff by 20%.
  (그들은 직원을 20% 삭감하고 있습니다)
```

#### 7. Bring in (도입하다, 초빙하다)
```
✓ We brought in a consultant.
  (우리는 컨설턴트를 초빙했습니다)

✓ The new CEO brought in many changes.
  (새 CEO가 많은 변화를 도입했습니다)
```

#### 8. Turn around (회복시키다, 반전시키다)
```
✓ The new strategy turned the company around.
  (새 전략이 회사를 회복시켰습니다)

✓ We need to turn around our sales numbers.
  (우리는 판매 실적을 반전시켜야 합니다)
```

### B. 회의 & 논의 (Meetings & Discussions)

#### 9. Bring up (제기하다, 언급하다)
```
✓ Who brought up this issue?
  (누가 이 문제를 제기했나요?)

✓ I'd like to bring up a few concerns.
  (몇 가지 우려사항을 제기하고 싶습니다)

✓ Don't bring up that topic in the meeting.
  (회의에서 그 주제를 언급하지 마세요)
```

#### 10. Point out (지적하다)
```
✓ She pointed out several errors.
  (그녀가 여러 오류를 지적했습니다)

✓ Let me point out the main issues.
  (주요 문제점들을 지적하겠습니다)
```

#### 11. Follow up (후속 조치를 취하다)
```
✓ I'll follow up with you next week.
  (다음 주에 후속 조치를 취하겠습니다)

✓ Did you follow up on the email?
  (그 이메일에 대해 후속 조치를 취했나요?)

✓ We need to follow up on this matter.
  (이 문제에 대해 후속 조치가 필요합니다)
```

#### 12. Wrap up (마무리하다)
```
✓ Let's wrap up this meeting.
  (이 회의를 마무리합시다)

✓ We need to wrap up by 5pm.
  (우리는 5시까지 마무리해야 합니다)

✓ Can you wrap up your presentation?
  (프레젠테이션을 마무리해 주시겠습니까?)
```

#### 13. Go over (검토하다, 살펴보다)
```
✓ Let's go over the budget.
  (예산을 검토합시다)

✓ I need to go over the contract again.
  (계약서를 다시 살펴봐야 합니다)
```

#### 14. Talk over (상의하다)
```
✓ We should talk this over with the team.
  (팀과 이것을 상의해야 합니다)

✓ Let's talk over the options.
  (선택사항들을 상의합시다)
```

#### 15. Narrow down (좁히다, 압축하다)
```
✓ We narrowed down the candidates to three.
  (우리는 후보를 3명으로 압축했습니다)

✓ Let's narrow down our focus.
  (우리의 초점을 좁힙시다)
```

### C. 프로젝트 관리 (Project Management)

#### 16. Kick off (시작하다)
```
✓ We'll kick off the project next Monday.
  (다음 주 월요일에 프로젝트를 시작합니다)

✓ The campaign kicks off in April.
  (캠페인은 4월에 시작됩니다)
```

#### 17. Roll out (출시하다, 전개하다)
```
✓ We're rolling out the new product in Q2.
  (우리는 2분기에 새 제품을 출시합니다)

✓ The system will be rolled out nationwide.
  (시스템이 전국적으로 전개될 것입니다)
```

#### 18. Push back (연기하다)
```
✓ We had to push back the deadline.
  (우리는 마감일을 연기해야 했습니다)

✓ The launch was pushed back to June.
  (출시가 6월로 연기되었습니다)
```

#### 19. Call off (취소하다)
```
✓ We had to call off the event.
  (우리는 행사를 취소해야 했습니다)

✓ The meeting was called off due to weather.
  (회의가 날씨 때문에 취소되었습니다)
```

#### 20. Speed up (속도를 높이다)
```
✓ We need to speed up the process.
  (우리는 프로세스의 속도를 높여야 합니다)

✓ Can you speed up production?
  (생산 속도를 높일 수 있나요?)
```

#### 21. Slow down (속도를 낮추다)
```
✓ We should slow down and review carefully.
  (우리는 속도를 낮추고 신중히 검토해야 합니다)
```

#### 22. Keep up with (따라가다, 보조를 맞추다)
```
✓ It's hard to keep up with the changes.
  (변화를 따라가기 어렵습니다)

✓ We need to keep up with the competition.
  (우리는 경쟁에 보조를 맞춰야 합니다)
```

### D. 커뮤니케이션 (Communication)

#### 23. Reach out (연락하다)
```
✓ Please reach out if you have questions.
  (질문이 있으시면 연락주세요)

✓ I'll reach out to the client tomorrow.
  (내일 고객에게 연락하겠습니다)

✓ Don't hesitate to reach out.
  (주저하지 말고 연락주세요)
```

#### 24. Get back to (회신하다, 다시 연락하다)
```
✓ I'll get back to you by Friday.
  (금요일까지 회신하겠습니다)

✓ When can you get back to me?
  (언제 저에게 다시 연락 주실 수 있나요?)
```

#### 25. Touch base (연락하다, 확인하다)
```
✓ Let's touch base next week.
  (다음 주에 연락합시다)

✓ I wanted to touch base about the project.
  (프로젝트에 대해 확인하고 싶었습니다)
```

#### 26. Run by (의견을 구하다)
```
✓ Can I run this idea by you?
  (이 아이디어에 대해 의견을 구해도 될까요?)

✓ Let me run it by my manager first.
  (먼저 매니저에게 의견을 구해보겠습니다)
```

#### 27. Fill in (정보를 제공하다, 대신하다)
```
✓ Can you fill me in on what happened?
  (무슨 일이 있었는지 정보를 제공해 주시겠습니까?)

✓ She's filling in for the manager today.
  (그녀가 오늘 매니저를 대신하고 있습니다)
```

#### 28. Catch up (따라잡다, 근황을 나누다)
```
✓ Let's catch up over coffee.
  (커피 마시며 근황을 나눕시다)

✓ I need to catch up on emails.
  (이메일을 따라잡아야 합니다)
```

### E. 의사결정 & 문제해결 (Decision Making & Problem Solving)

#### 29. Figure out (알아내다, 해결하다)
```
✓ We need to figure out the problem.
  (우리는 문제를 알아내야 합니다)

✓ I can't figure out why this isn't working.
  (왜 이게 작동하지 않는지 알아낼 수 없습니다)
```

#### 30. Work out (해결하다, 계산하다)
```
✓ We'll work out the details later.
  (세부사항은 나중에 해결하겠습니다)

✓ Let me work out the costs.
  (비용을 계산해 보겠습니다)
```

#### 31. Look into (조사하다)
```
✓ We're looking into the complaint.
  (우리는 불만사항을 조사하고 있습니다)

✓ Can you look into this issue?
  (이 문제를 조사해 주시겠습니까?)
```

#### 32. Come up with (생각해내다)
```
✓ We need to come up with a solution.
  (우리는 해결책을 생각해내야 합니다)

✓ Who came up with this idea?
  (누가 이 아이디어를 생각해냈나요?)
```

#### 33. Sort out (해결하다, 정리하다)
```
✓ We need to sort out this confusion.
  (이 혼란을 해결해야 합니다)

✓ Let me sort out the paperwork.
  (서류 작업을 정리하겠습니다)
```

#### 34. Deal with (다루다, 처리하다)
```
✓ How should we deal with this situation?
  (이 상황을 어떻게 다뤄야 할까요?)

✓ I'll deal with the client directly.
  (고객을 직접 처리하겠습니다)
```

#### 35. Think over (심사숙고하다)
```
✓ Let me think it over.
  (심사숙고해 보겠습니다)

✓ Take time to think over the offer.
  (제안을 심사숙고할 시간을 가지세요)
```

### F. 실적 & 성과 (Performance & Results)

#### 36. Pick up (향상되다, 회복하다)
```
✓ Sales are picking up this quarter.
  (이번 분기 매출이 향상되고 있습니다)

✓ The market is starting to pick up.
  (시장이 회복되기 시작하고 있습니다)
```

#### 37. Fall behind (뒤처지다)
```
✓ We're falling behind schedule.
  (우리는 일정에 뒤처지고 있습니다)

✓ Don't fall behind on payments.
  (지불에 뒤처지지 마세요)
```

#### 38. Make up for (보충하다, 만회하다)
```
✓ We need to make up for lost time.
  (잃어버린 시간을 만회해야 합니다)

✓ How can we make up for this delay?
  (이 지연을 어떻게 보충할 수 있을까요?)
```

#### 39. Step up (강화하다, 나서다)
```
✓ We need to step up our marketing efforts.
  (우리는 마케팅 노력을 강화해야 합니다)

✓ Someone needs to step up and lead.
  (누군가가 나서서 이끌어야 합니다)
```

#### 40. Pull off (성공시키다)
```
✓ They pulled off an amazing deal.
  (그들은 놀라운 거래를 성공시켰습니다)

✓ Can we pull this off by the deadline?
  (마감일까지 이것을 성공시킬 수 있을까요?)
```

1. **대명사 규칙**: 대명사(it, them 등)는 항상 동사와 전치사/부사 사이!
