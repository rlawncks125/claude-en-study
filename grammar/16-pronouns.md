# 대명사 (Pronouns)

## 📖 개념

대명사는 명사를 대신하는 말로, 반복을 피하고 문장을 간결하게 만듭니다.

---

## 1️⃣ 인칭대명사 (Personal Pronouns)

### A. 주격 (Subject Pronouns)

```
주어 자리에 사용:

단수:
- I (나는)
- you (너는/당신은)
- he (그는)
- she (그녀는)
- it (그것은)

복수:
- we (우리는)
- you (너희는/당신들은)
- they (그들은)

예시:
✓ I work at Samsung.
✓ She is the CEO.
✓ They are in a meeting.
✓ We need to discuss this.
```

### B. 목적격 (Object Pronouns)

```
목적어 자리에 사용:

단수:
- me (나를)
- you (너를/당신을)
- him (그를)
- her (그녀를)
- it (그것을)

복수:
- us (우리를)
- you (너희를/당신들을)
- them (그들을)

예시:
✓ Call me later.
✓ I'll email him tomorrow.
✓ Please send them the report.
✓ The manager wants to see us.
```

### C. 소유격 (Possessive Pronouns)

#### 소유격 형용사 (Possessive Adjectives)
```
명사 앞에 사용:

- my (나의)
- your (너의/당신의)
- his (그의)
- her (그녀의)
- its (그것의)
- our (우리의)
- your (너희의/당신들의)
- their (그들의)

예시:
✓ This is my office.
✓ Your presentation was excellent.
✓ Their team won the project.
✓ We need your approval.
```

#### 소유대명사 (Possessive Pronouns)
```
단독으로 사용 (뒤에 명사 없음):

- mine (나의 것)
- yours (너의/당신의 것)
- his (그의 것)
- hers (그녀의 것)
- its (X - 거의 사용 안 함)
- ours (우리의 것)
- yours (너희/당신들의 것)
- theirs (그들의 것)

예시:
✓ This desk is mine.
✓ That idea was hers.
✓ The decision is yours.
✓ These documents are theirs.

비교:
✓ This is my book. (소유격 형용사 + 명사)
✓ This book is mine. (소유대명사 단독)
```

### D. 재귀대명사 (Reflexive Pronouns)

```
자기 자신을 가리킬 때:

- myself (나 자신)
- yourself (너 자신)
- himself (그 자신)
- herself (그녀 자신)
- itself (그것 자신)
- ourselves (우리 자신)
- yourselves (너희 자신)
- themselves (그들 자신)

용법 1: 주어와 목적어가 같을 때
✓ I introduced myself at the meeting.
✓ She taught herself Python.
✓ They organized the event themselves.

용법 2: 강조 (by oneself = 혼자서)
✓ I did it myself. (내가 직접)
✓ She completed the project by herself. (혼자서)
✓ We can handle this ourselves.

비즈니스 예시:
✓ Please introduce yourself.
✓ The system updates itself automatically.
✓ We need to ask ourselves difficult questions.
✓ He prides himself on his work quality.
```

## 2️⃣ 지시대명사 (Demonstrative Pronouns)

```
가까운 것:
- this (이것) - 단수
- these (이것들) - 복수

먼 것:
- that (저것) - 단수
- those (저것들) - 복수

예시:
✓ This is our new product.
✓ These are the latest figures.
✓ That was a great presentation.
✓ Those are the documents you requested.

비즈니스 상황:
✓ This is what I suggest...
✓ These are the main challenges.
✓ That was discussed in the last meeting.
✓ Those were good points you made.
```

## 3️⃣ 의문대명사 (Interrogative Pronouns)

```
Who (누구) - 사람, 주격
- Who is responsible for this?
- Who will attend the meeting?

Whom (누구를) - 사람, 목적격 (격식)
- Whom did you meet? (격식)
- Who did you meet? (일상)
- To whom should I send this? (격식)
- Who should I send this to? (일상)

Whose (누구의) - 소유
- Whose idea was this?
- Whose presentation is next?

What (무엇)
- What is the deadline?
- What do you think?

Which (어느 것) - 선택
- Which option do you prefer?
- Which report are you referring to?

비즈니스 예시:
✓ Who is leading this project?
✓ Whose responsibility is it?
✓ What are the next steps?
✓ Which approach should we take?
```

## 4️⃣ 부정대명사 (Indefinite Pronouns)

### A. 사람

```
Everyone/Everybody (모든 사람) - 단수 취급
✓ Everyone is here.
✓ Everybody needs to attend.

Someone/Somebody (누군가)
✓ Someone left their laptop. (구어에서 their 허용)
✓ Somebody called you.

Anyone/Anybody (아무나)
✓ Anyone can join the meeting.
✓ Is anybody available?

No one/Nobody (아무도 ~않다)
✓ No one knows the answer.
✓ Nobody responded to the email.
```

### B. 사물

```
Everything (모든 것) - 단수
✓ Everything is ready.
✓ Is everything OK?

Something (무언가)
✓ Something went wrong.
✓ I need to tell you something.

Anything (아무것)
✓ Do you need anything?
✓ I'll do anything to help.

Nothing (아무것도 ~않다)
✓ Nothing has changed.
✓ There's nothing to worry about.
```

### C. 수량

```
All (모든/전부)
✓ All employees must attend. (모든 직원들)
✓ All of the reports are complete. (모든 보고서)

Some (일부, 약간)
✓ Some people disagree.
✓ Would you like some coffee?

Any (어떤, 일부)
✓ Do you have any questions?
✓ Are there any updates?

None (아무것도 없다)
✓ None of the solutions worked.
✓ None of us knew about it.

Both (둘 다)
✓ Both options are good.
✓ Both of them agreed.

Either (둘 중 하나)
✓ Either solution works.
✓ You can choose either.

Neither (둘 다 아니다)
✓ Neither option is ideal.
✓ Neither of them responded.

Each (각각)
✓ Each employee receives training.
✓ Each of us has responsibilities.

Every (모든) - 단수!
✓ Every employee must sign. (NOT employees)
✓ Every day is a new opportunity.

Several (여러, 몇몇)
✓ Several people complained.
✓ Several of the clients left.

Many (많은) - 가산명사
✓ Many employees work remotely.
✓ Many of them are experienced.

Much (많은) - 불가산명사
✓ Much has been accomplished.
✓ Not much time remains.

Few/A few (몇 안 되는/조금)
✓ Few people know this. (거의 없다, 부정적)
✓ A few people know this. (소수 있다, 긍정적)

Little/A little (거의 없는/조금)
✓ Little progress was made. (거의 없다, 부정적)
✓ A little time remains. (조금 있다, 긍정적)
```

## 5️⃣ 비즈니스 영어 실수 방지

### Common Mistakes

#### 실수 1: Everyone/Everybody는 단수!
```
✗ Everyone are ready.
✓ Everyone is ready.

✗ Everybody have finished.
✓ Everybody has finished.

✗ No one were available.
✓ No one was available.
```

#### 실수 2: Its vs. It's
```
Its = 소유격 (그것의)
✓ The company announced its new strategy.

It's = It is/has의 축약
✓ It's time to go. (= It is)
✓ It's been a pleasure. (= It has)

✗ The company announced it's new strategy.
✓ The company announced its new strategy.
```

#### 실수 3: Their vs. There vs. They're
```
Their = 그들의 (소유격)
✓ Their presentation was excellent.

There = 거기에 (장소)
✓ The files are over there.

They're = They are
✓ They're in a meeting.

✗ There presentation was good.
✓ Their presentation was good.
```

#### 실수 4: Me vs. I
```
주어 자리: I
✓ John and I will attend.
✗ John and me will attend.

목적어 자리: me
✓ Send it to John and me.
✗ Send it to John and I.

Tip: 상대방 이름 제거해서 테스트
- "I will attend" ✓ → "John and I"
- "Send it to me" ✓ → "Send it to John and me"
```

#### 실수 5: Myself 남용
```
Myself는 재귀/강조용:
✓ I did it myself. (강조)
✓ I hurt myself. (재귀)

일반 목적어로는 me:
✗ Please send the file to myself.
✓ Please send the file to me.

✗ John and myself will attend.
✓ John and I will attend.
```

## 💡 실전 팁

### 비즈니스 글쓰기 체크리스트
```
✓ Everyone/everybody는 단수 동사!
✓ Its (소유) vs. It's (축약) 구분했나?
✓ Their (소유) vs. There (장소) vs. They're (축약)
✓ 주어 자리는 I, 목적어 자리는 me
✓ Myself는 재귀/강조 용도로만!
✓ Every + 단수명사 (every employee, NOT employees)
```

- Myself는 남용하지 말 것!
