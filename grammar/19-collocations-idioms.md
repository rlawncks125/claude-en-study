# 연어 및 비즈니스 관용구 (Collocations & Business Idioms)

## 📖 개념

### 연어 (Collocations)란?
자연스럽게 함께 쓰이는 단어들의 조합입니다.

```
❌ do a mistake
✓ make a mistake

❌ say a speech
✓ give a speech

❌ strong tea (X - 맛이 강한)
✓ strong coffee (O)
✓ strong tea (O - 하지만 진한 차는 보통 "strong tea"보다 "black tea")
```

### 관용구 (Idioms)란?
단어들의 조합이 문자 그대로의 의미가 아닌 새로운 의미를 가지는 표현입니다.

```
"get the ball rolling" = 시작하다
(공을 굴린다 ✗, 일을 시작한다 ✓)

"think outside the box" = 창의적으로 생각하다
(상자 밖을 생각한다 ✗, 틀에서 벗어나 생각한다 ✓)
```

## 1️⃣ 비즈니스 연어 (Business Collocations)

### A. Verb + Noun (동사 + 명사)

#### Make 계열
```
make a decision (결정을 내리다)
✓ We need to make a decision by Friday.
✓ Who will make the final decision?

make a profit (이익을 내다)
✓ The company made a profit last year.

make a loss (손실을 보다)
✓ We made a loss in Q1.

make progress (진전을 이루다)
✓ We're making good progress on the project.

make an effort (노력하다)
✓ We should make an effort to improve.

make arrangements (준비/조치하다)
✓ I'll make arrangements for the meeting.

make an appointment (약속을 잡다)
✓ Can I make an appointment for next week?

make a suggestion (제안하다)
✓ May I make a suggestion?

make a presentation (발표하다)
✓ She'll make a presentation tomorrow.

make an exception (예외를 두다)
✓ We can make an exception this time.
```

#### Take 계열
```

✓ We need to take immediate action.

✓ I'll take full responsibility.

✓ We should take the initiative.

take a risk (위험을 감수하다)
✓ Sometimes you have to take risks.

take advantage of (활용하다)
✓ Let's take advantage of this opportunity.

take notes (메모하다)
✓ Please take notes during the meeting.

take place (개최되다)
✓ The conference will take place in Seoul.

take time (시간이 걸리다)
✓ This process takes time.

take over (인수하다)
✓ Samsung took over the company.

take turns (번갈아 하다)

```

#### Do 계열
```

do your best (최선을 다하다)

do damage (피해를 주다)

do a favor (호의를 베풀다)

do the job (일을 하다, 충분하다)

#### Give 계열
```
give a presentation (발표하다)
✓ I'll give a presentation on Monday.

give feedback (피드백을 주다)
✓ Please give me your feedback.

give notice (통지하다)
✓ You must give two weeks' notice.

give permission (허가하다)
✓ Who gave you permission?

give priority to (우선순위를 두다)
✓ We should give priority to this project.

give an estimate (견적을 내다)
✓ Can you give me an estimate?

give a discount (할인을 주다)
✓ We can give you a 10% discount.
```

#### Have 계열
```
have a meeting (회의하다)
✓ We're having a meeting at 3pm.

have an opportunity (기회가 있다)
✓ I had an opportunity to meet the CEO.

have a discussion (논의하다)
✓ Let's have a discussion about this.

have an impact (영향을 미치다)

```

reach a conclusion (결론에 도달하다)

```

## 2️⃣ 비즈니스 관용구 (Business Idioms) 50+

### A. 회의 & 협업 (Meetings & Collaboration)

#### 1. Get the ball rolling
**의미**: 시작하다
```
✓ Let's get the ball rolling with the introductions.
  (소개로 시작합시다)

✓ Who wants to get the ball rolling?
  (누가 시작하시겠습니까?)
```

#### 2. On the same page
**의미**: 같은 생각을 하다, 의견이 일치하다
```
✓ We need to make sure everyone is on the same page.
  (모두가 같은 생각을 하도록 해야 합니다)

✓ Are we all on the same page about this?
  (이것에 대해 모두 의견이 일치하나요?)
```

#### 3. Touch base
**의미**: 간단히 연락하다
```
✓ Let's touch base next week.
  (다음 주에 간단히 연락합시다)

✓ I'll touch base with you tomorrow.
  (내일 연락드리겠습니다)
```

#### 4. Think outside the box
**의미**: 창의적으로/틀을 깨고 생각하다
```
✓ We need to think outside the box to solve this.
  (이것을 해결하려면 창의적으로 생각해야 합니다)
```

#### 5. Bring to the table
**의미**: 기여하다, 제공하다
```
✓ What can you bring to the table?
  (당신은 무엇을 기여할 수 있나요?)

✓ He brings 10 years of experience to the table.
  (그는 10년의 경험을 기여합니다)
```

#### 6. Circle back
**의미**: 나중에 다시 논의하다
```
✓ Let's circle back to this later.
  (이것은 나중에 다시 논의합시다)

✓ I'll circle back with you next week.
  (다음 주에 다시 연락드리겠습니다)
```

#### 7. Loop someone in
**의미**: ~를 포함시키다, 알리다
```
✓ Let me loop you in on this.
  (이것에 대해 당신을 포함시키겠습니다)

✓ Please loop me in on all emails.
  (모든 이메일에 저를 포함시켜 주세요)
```

#### 8. Keep someone in the loop
**의미**: 계속 정보를 공유하다
```
✓ Please keep me in the loop.
  (계속 저에게 정보를 공유해 주세요)
```

#### 9. Pick your brain
**의미**: 의견을 구하다
```
✓ Can I pick your brain about this?
  (이것에 대해 의견을 구해도 될까요?)
```

#### 10. Run it by someone
**의미**: ~에게 의견을 구하다
```
✓ Let me run this by my manager.
  (매니저에게 의견을 구해보겠습니다)
```

### B. 프로젝트 & 마감 (Projects & Deadlines)

#### 11. Ahead of schedule

```

  (프로젝트가 일정보다 늦습니다)

```
✓ We need strategies that will move the needle.
  (진전을 만들 전략이 필요합니다)

```

```

  (우리는 빠른 성과가 필요합니다)

```

  (신입 사원이 즉시 효율적으로 시작했습니다)
```

  (우리는 공평한 경쟁 환경이 필요합니다)
