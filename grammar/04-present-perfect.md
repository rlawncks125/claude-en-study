# 현재완료 (Present Perfect)

## 📌 기본 개념

현재완료는 **과거에 시작된 일이 현재와 연결**되어 있을 때 사용합니다.
단순 과거(simple past)와 다른 점은 "지금 이 순간과의 관련성"입니다.

## ✏️ 형태

```
긍정문: have/has + 과거분사(p.p.)
부정문: have/has + not + 과거분사
의문문: Have/Has + 주어 + 과거분사?
```

### 주어에 따른 have/has 사용
- I/You/We/They → **have**
- He/She/It → **has**

## 🎯 3가지 주요 용법

### 1. 경험 (Experience)
"~해본 적이 있다" - 과거부터 지금까지의 인생 경험

```
I have worked in 5 different companies.
(나는 5개의 다른 회사에서 일해본 적이 있다)

She has met the CEO twice.
(그녀는 CEO를 두 번 만나본 적이 있다)

Have you ever given a presentation in English?
(영어로 프레젠테이션을 해본 적이 있나요?)
```

**경험을 나타내는 표현**:
- ever (의문문에서: 한 번이라도)
- never (부정: 한 번도 ~한 적 없다)
- once/twice/three times (몇 번)
- many times/several times (여러 번)
- before (이전에)

### 2. 완료/결과 (Completion/Result)
"~했다" (그래서 지금 결과가 있다)

```
I have finished the report.
(보고서를 끝냈어요) → 지금 완성된 보고서가 있음

We have signed the contract.
(우리는 계약서에 서명했습니다) → 지금 계약이 유효함

The project has been completed.
(프로젝트가 완료되었습니다) → 지금 완료된 상태임
```

**완료를 나타내는 표현**:
- already (이미 - 긍정문/의문문)
- yet (아직 - 부정문/의문문)
- just (방금)
- recently (최근에)

### 3. 계속 (Duration/Continuation)
"~해왔다" (과거부터 지금까지 계속)

```
I have worked here for 5 years.
(저는 여기서 5년 동안 일해왔습니다) → 지금도 일하고 있음

She has been a manager since 2020.
(그녀는 2020년부터 매니저였습니다) → 지금도 매니저임

How long have you known him?
(그를 얼마나 오래 알고 지냈나요?)
```

**계속을 나타내는 표현**:
- for + 기간 (for 3 years, for 2 months)
- since + 시작 시점 (since 2020, since Monday)
- How long...? (얼마나 오래)

## 📊 현재완료 vs 단순과거

| 현재완료 (Present Perfect) | 단순과거 (Simple Past) |
|---------------------------|----------------------|
| 현재와 연결 (지금도 관련 있음) | 과거 완결 (끝난 일) |
| 시점 불명확/중요하지 않음 | 명확한 과거 시점 |
| **I have worked there** | **I worked there in 2020** |
| (언젠가 일했음) | (2020년에 일했음 - 끝남) |
| **She has left** | **She left at 3pm** |
| (떠났음 - 지금 없음) | (3시에 떠났음) |

## 🔑 비즈니스에서 자주 쓰는 현재완료 표현

### 경험 관련
```
I have managed international projects.
(국제 프로젝트를 관리해본 경험이 있습니다)

We have dealt with similar issues before.
(우리는 비슷한 문제를 다뤄본 적이 있습니다)

Have you ever worked with this software?
(이 소프트웨어로 작업해본 적 있나요?)
```

### 완료/결과 관련
```
I have sent the email.
(이메일을 보냈습니다)

The team has completed the first phase.
(팀이 1단계를 완료했습니다)

Have you checked the data yet?
(데이터를 확인했나요?)

I haven't received the document yet.
(아직 문서를 받지 못했습니다)
```

### 계속 관련
```
I have been in this position for 3 years.
(이 직책에 3년째 있습니다)

We have worked together since 2019.
(우리는 2019년부터 함께 일해왔습니다)

How long have you been with the company?
(회사에 얼마나 계셨나요?)
```

## 💬 대화 예시

### 예시 1: 직장 동료와 대화
```
A: Have you finished the presentation?
   (프레젠테이션 끝냈어?)

B: Yes, I have just completed it.
   (응, 방금 완성했어.)

A: Great! Have you sent it to the manager?
   (좋아! 매니저한테 보냈어?)

B: Not yet. I will send it now.
   (아직. 지금 보낼게.)
```

### 예시 2: 면접에서
```
Interviewer: Have you ever led a team?
            (팀을 이끌어본 적 있나요?)

Candidate: Yes, I have managed a team of 10 people for 2 years.
          (네, 10명의 팀을 2년 동안 관리했습니다.)

Interviewer: What have you achieved in that role?
            (그 역할에서 무엇을 달성했나요?)

Candidate: We have increased productivity by 30%.
          (생산성을 30% 증가시켰습니다.)
```

### 예시 3: 프로젝트 업데이트
```
A: How is the project going?
   (프로젝트는 어떻게 되고 있어요?)

B: We have completed 80% of the work.
   (작업의 80%를 완료했습니다.)

A: Have you encountered any problems?
   (문제는 없었나요?)

B: We have had some technical issues, but we have solved them.
   (몇 가지 기술적 문제가 있었지만 해결했습니다.)
```

## ⚠️ 주의사항

### 1. 명확한 과거 시점과 함께 사용 불가
```
❌ I have finished it yesterday.
✅ I finished it yesterday.
(어제는 명확한 과거이므로 단순과거 사용)

❌ She has met him last week.
✅ She met him last week.
```

**과거 시점 표현**: yesterday, last week, in 2020, 3 days ago 등
→ 이런 표현과 함께는 **단순과거** 사용!

### 2. for vs since
```
✅ for + 기간 (for 3 years, for 2 months, for a long time)
✅ since + 시작점 (since 2020, since Monday, since last year)

❌ I have worked here since 3 years. (X)
✅ I have worked here for 3 years. (O)
```

### 3. been vs gone
```
have been to = 다녀왔다 (이미 돌아옴)
have gone to = 가버렸다 (아직 돌아오지 않음)

I have been to Seoul. (서울에 다녀왔어요 - 지금 여기 있음)
She has gone to Seoul. (그녀는 서울에 가버렸어요 - 지금 여기 없음)
```

## ✍️ 연습 문제

### 문제 1: 빈칸 채우기
1. I __________ (work) here for 5 years.
2. She __________ (already/finish) the report.
3. __________ you ever __________ (meet) the CEO?
4. We __________ (not/receive) the payment yet.
5. How long __________ he __________ (be) a manager?

### 문제 2: 현재완료 vs 단순과거 선택
1. I (have worked / worked) there in 2019.
2. She (has left / left) the office. She's not here now.
3. We (have met / met) him yesterday.
4. (Have you seen / Did you see) this movie before?
5. He (has been / was) our client since 2018.

### 문제 3: for vs since
1. I have lived here __________ 2015.
2. She has worked there __________ 3 months.
3. We have known each other __________ a long time.
4. They have been partners __________ last year.
5. I haven't seen him __________ Monday.

---

## 📚 정답

### 문제 1
1. have worked
2. has already finished
3. Have, met
4. have not (haven't) received
5. has, been

### 문제 2
1. worked (2019은 명확한 과거)
2. has left (지금 결과 - 여기 없음)
3. met (yesterday는 과거)
4. Have you seen (경험, 시점 불명확)
5. has been (since 2018 - 지금까지 계속)

### 문제 3
1. since (2015은 시작점)
2. for (3 months는 기간)
3. for (a long time은 기간)
4. since (last year는 시작점)
5. since (Monday는 시작점)
