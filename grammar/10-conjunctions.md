# 접속사 (Conjunctions)

## 📌 기본 개념

접속사는 **단어, 구, 절을 연결**하는 단어입니다.
복잡한 문장을 만들고 논리적으로 말할 때 필수적입니다.

## 🔗 등위접속사 (Coordinating Conjunctions)

같은 레벨의 것들을 연결 (단어+단어, 절+절)

### FANBOYS로 기억하기

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **F**or | ~이기 때문에 (이유) | I'm tired, **for** I worked all night. |
| **A**nd | 그리고 (추가) | I work **and** study. |
| **N**or | ~도 아니다 | I don't drink **nor** smoke. |
| **B**ut | 하지만 (대조) | It's expensive, **but** it's good. |
| **O**r | 또는 (선택) | Coffee **or** tea? |
| **Y**et | 그러나 (대조) | It's small, **yet** powerful. |
| **S**o | 그래서 (결과) | I was late, **so** I took a taxi. |

### 비즈니스에서 자주 쓰는 등위접속사

#### and (그리고)
```
We develop and sell software.
(우리는 소프트웨어를 개발하고 판매합니다)

She is smart and hardworking.
(그녀는 똑똑하고 성실합니다)

I checked the data, and it looks good.
(데이터를 확인했는데 좋아 보입니다)
```

#### but (하지만)
```
It's expensive, but it's worth it.
(비싸지만 그만한 가치가 있습니다)

I want to help, but I'm busy.
(돕고 싶지만 바쁩니다)

The product is good, but we need improvements.
(제품은 좋지만 개선이 필요합니다)
```

#### or (또는)
```
We can meet on Monday or Tuesday.
(월요일이나 화요일에 만날 수 있어요)

Would you like coffee or tea?
(커피 드시겠어요, 차 드시겠어요?)

Should we call or email them?
(그들에게 전화할까요, 이메일 할까요?)
```

#### so (그래서)
```
The deadline is tight, so we need to hurry.
(마감이 촉박해서 서둘러야 해요)

I was sick, so I didn't attend the meeting.
(아파서 미팅에 참석하지 못했어요)

The system failed, so we lost data.
(시스템이 고장나서 데이터를 잃었어요)
```

## 🔗 종속접속사 (Subordinating Conjunctions)

주절과 종속절을 연결

### 시간 (Time)

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **when** | ~할 때 | Call me **when** you arrive. |
| **while** | ~하는 동안 | I'll work **while** you're away. |
| **before** | ~하기 전에 | Check it **before** you send it. |
| **after** | ~한 후에 | Let's talk **after** the meeting. |
| **as soon as** | ~하자마자 | I'll call you **as soon as** I finish. |
| **until** | ~할 때까지 | Wait **until** I return. |
| **since** | ~한 이후로 | I've known him **since** we met. |

### 비즈니스 예문
```
Please review the document before you sign it.
(서명하기 전에 문서를 검토해주세요)

When the project is complete, we'll celebrate.
(프로젝트가 완료되면 축하할 거예요)

I'll send you the report as soon as it's ready.
(준비되는 대로 보고서를 보내드리겠습니다)

We've been partners since we started the company.
(회사를 시작한 이후로 파트너였습니다)
```

### 이유 (Reason/Cause)

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **because** | ~이기 때문에 | I'm late **because** of traffic. |
| **since** | ~이므로 | **Since** you're busy, I'll help. |
| **as** | ~이므로 | **As** it's raining, bring an umbrella. |

### 비즈니스 예문
```
We chose this vendor because they offer the best price.
(최고의 가격을 제공하기 때문에 이 업체를 선택했습니다)

Since everyone is here, let's start the meeting.
(모두 왔으니 미팅을 시작하겠습니다)

As the deadline is approaching, we need to work faster.
(마감이 다가오고 있으므로 더 빠르게 작업해야 합니다)
```

### 조건 (Condition)

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **if** | 만약 ~하면 | **If** you need help, call me. |
| **unless** | ~하지 않으면 | **Unless** we hurry, we'll be late. |
| **in case** | ~할 경우를 대비해 | Bring a charger **in case** you need it. |

### 비즈니스 예문
```
If you have questions, please ask.
(질문이 있으시면 말씀해주세요)

We won't succeed unless we work together.
(함께 일하지 않으면 성공하지 못할 거예요)

In case of emergency, contact the manager.
(비상시에는 매니저에게 연락하세요)
```

### 대조/양보 (Contrast/Concession)

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **although** | 비록 ~이지만 | **Although** it's difficult, it's possible. |
| **though** | ~이지만 | It's expensive, **though** worth it. |
| **even though** | ~임에도 불구하고 | **Even though** I'm busy, I'll help. |
| **while** | ~인 반면 | I like coffee **while** she likes tea. |

### 비즈니스 예문
```
Although the project is challenging, we'll complete it.
(프로젝트가 도전적이지만 완료할 거예요)

Even though the price is high, the quality is excellent.
(가격이 높음에도 불구하고 품질이 뛰어납니다)

While Product A is cheaper, Product B is more durable.
(제품 A가 더 저렴한 반면, 제품 B가 더 내구성이 있습니다)
```

### 목적 (Purpose)

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **so that** | ~하기 위해 | I study hard **so that** I can succeed. |
| **in order that** | ~하기 위해 | We plan ahead **in order that** we don't fail. |

### 비즈니스 예문
```
We test the product so that we ensure quality.
(품질을 보장하기 위해 제품을 테스트합니다)

I'll send the agenda in advance so that you can prepare.
(준비할 수 있도록 미리 안건을 보내드리겠습니다)
```

## 🔗 상관접속사 (Correlative Conjunctions)

쌍으로 사용되는 접속사

### 주요 상관접속사

| 접속사 | 의미 | 예문 |
|--------|------|------|
| **both A and B** | A와 B 둘 다 | **Both** quality **and** price are important. |
| **either A or B** | A 또는 B | **Either** Monday **or** Tuesday works. |
| **neither A nor B** | A도 B도 아닌 | **Neither** option **nor** plan is good. |
| **not only A but also B** | A뿐만 아니라 B도 | She is **not only** smart **but also** kind. |

### 비즈니스 예문
```
Both experience and skills are required.
(경험과 기술 둘 다 필요합니다)

We can meet either in person or online.
(직접이나 온라인으로 만날 수 있습니다)

Neither the time nor the budget is sufficient.
(시간도 예산도 충분하지 않습니다)

This solution is not only effective but also affordable.
(이 솔루션은 효과적일 뿐만 아니라 저렴합니다)
```

## 💼 비즈니스 상황별 접속사 활용

### 1. 프레젠테이션
```
First, I'll explain the problem. Then, I'll propose a solution.
(먼저 문제를 설명하고, 그 다음 해결책을 제안하겠습니다)

Although sales decreased, profits increased.
(매출은 감소했지만 이익은 증가했습니다)

We need to act quickly because the market is changing.
(시장이 변하고 있기 때문에 빨리 행동해야 합니다)
```

### 2. 이메일
```
Please let me know if you have any questions.
(질문이 있으시면 알려주세요)

I'll send the file as soon as it's ready.
(준비되는 대로 파일을 보내드리겠습니다)

Since the deadline is Friday, we need to finish today.
(마감이 금요일이므로 오늘 끝내야 합니다)
```

### 3. 회의
```
Before we start, let me introduce everyone.
(시작하기 전에 모두를 소개하겠습니다)

While I understand your concern, I think we should proceed.
(귀하의 우려를 이해하지만 진행해야 한다고 생각합니다)

Both options are good, but Option A is more cost-effective.
(두 옵션 모두 좋지만 옵션 A가 더 비용 효율적입니다)
```

### 4. 협상
```
If you order 100 units, we can offer a discount.
(100개를 주문하시면 할인을 제공할 수 있습니다)

We want quality, and we're willing to pay for it.
(품질을 원하며 그에 대한 비용을 지불할 의향이 있습니다)

Unless we reach an agreement, we'll consider other options.
(합의에 도달하지 못하면 다른 옵션을 고려할 것입니다)
```

## 💬 대화 예시

### 예시 1: 일정 조율
```
A: Can we meet on Monday?
   (월요일에 만날 수 있나요?)

B: I'm busy on Monday, but I'm free on Tuesday.
   (월요일은 바쁘지만 화요일은 한가합니다)

A: Okay. Let's meet on Tuesday, and we can discuss the project.
   (좋아요. 화요일에 만나서 프로젝트를 논의합시다)

B: Sounds good. Please send me the agenda before the meeting.
   (좋습니다. 미팅 전에 안건을 보내주세요)
```

### 예시 2: 문제 해결
```
A: The system is slow because we have too much data.
   (데이터가 너무 많아서 시스템이 느려요)

B: Should we delete old files or upgrade the server?
   (오래된 파일을 삭제할까요, 아니면 서버를 업그레이드할까요?)

A: Although deleting files is cheaper, upgrading is better long-term.
   (파일 삭제가 더 저렴하지만 업그레이드가 장기적으로 더 좋습니다)

B: I agree. Let's upgrade so that we don't have this problem again.
   (동의합니다. 이 문제가 다시 발생하지 않도록 업그레이드합시다)
```

### 예시 3: 제안 논의
```
A: This proposal looks good, but the cost is too high.
   (이 제안은 좋아 보이지만 비용이 너무 높습니다)

B: If we reduce the scope, we can lower the cost.
   (범위를 줄이면 비용을 낮출 수 있습니다)

A: That works. Since time is limited, let's focus on priorities.
   (괜찮습니다. 시간이 제한적이므로 우선순위에 집중합시다)

B: I'll revise the proposal and send it to you by tomorrow.
   (제안서를 수정해서 내일까지 보내드리겠습니다)
```

## 🔑 논리적 글쓰기를 위한 접속사

### 순서 (Sequence)
```
First, ... / Second, ... / Finally, ...
(첫째, ... / 둘째, ... / 마지막으로, ...)

To begin with, ... / Next, ... / Lastly, ...
(먼저, ... / 다음으로, ... / 마지막으로, ...)
```

### 추가 (Addition)
```
In addition, ... / Moreover, ... / Furthermore, ...
(게다가, ...)

Also, ... / Besides, ...
(또한, ...)
```

### 대조 (Contrast)
```
However, ... / Nevertheless, ... / On the other hand, ...
(그러나, ... / 그럼에도 불구하고, ... / 반면에, ...)
```

### 결과 (Result)
```
Therefore, ... / Thus, ... / As a result, ...
(따라서, ... / 그러므로, ... / 결과적으로, ...)

Consequently, ...
(결과적으로, ...)
```

### 예시 (Example)
```
For example, ... / For instance, ...
(예를 들어, ...)

Such as ...
(~와 같은)
```

## ⚠️ 주의사항

### 1. Because vs Because of
```
✅ because + 주어 + 동사
I'm late because the train was delayed.

✅ because of + 명사
I'm late because of the train delay.

❌ I'm late because of the train was delayed. (X)
```

### 2. Although vs Despite/In spite of
```
✅ although + 주어 + 동사
Although it rained, we went out.

✅ despite/in spite of + 명사
Despite the rain, we went out.

❌ Although the rain, we went out. (X)
```

### 3. 쉼표 위치
```
종속절이 앞에 오면: 쉼표 O
When I finish, I'll call you.

주절이 앞에 오면: 쉼표 X
I'll call you when I finish.
```

### 4. Both ... and (복수 동사)
```
✅ Both John and Mary are here. (복수)
❌ Both John and Mary is here. (X)
```

### 5. Either ... or / Neither ... nor (동사는 가까운 명사에 일치)
```
✅ Either you or he is responsible.
✅ Neither the manager nor the employees are happy.
```

3. Call me _____ (when/while) you arrive.
4. _____ (If/Unless) you need help, let me know.
5. I was late _____ (because/because of) traffic.

### 문제 2
1. as (as soon as)
2. Both (both A and B)
