# 고급 문장 구조 (Advanced Sentence Structures)

## 📖 개념

고급 문장 구조는 더욱 정교하고 전문적인 영어 표현을 가능하게 합니다. 비즈니스 영어에서 설득력 있고 명확한 커뮤니케이션을 위해 필수적입니다.

```
기본: Our sales increased. This is good.
고급: What is particularly encouraging is that our sales increased by 20%.

기본: We need to cut costs.
고급: Rarely have we faced such a need to cut costs dramatically.
```

---

## 1️⃣ 병렬 구조 (Parallel Structure)

### 개념
같은 문법 형태를 반복하여 리듬감과 명확성을 높이는 구조입니다.

### A. 명사 병렬
```
✗ Our goals are increasing sales, to improve quality, and market expansion.
✓ Our goals are increasing sales, improving quality, and expanding the market.
  (모두 동명사 형태로 통일)

✓ We need creativity, dedication, and teamwork.
  (모두 명사)

✓ Success requires planning, execution, and persistence.
  (모두 명사)
```

### B. 동사 병렬
```
✓ We analyzed the data, identified the trends, and developed strategies.
  (모두 과거형 동사)

✓ She manages the team, oversees projects, and reports to the board.
  (모두 현재형 동사)

✓ The CEO will review the proposal, discuss it with the board, and make a decision.
  (모두 will + 동사원형)
```

### C. 형용사 병렬
```
✓ We're looking for candidates who are qualified, experienced, and motivated.
  (모두 형용사)

✓ The product is innovative, affordable, and reliable.
  (모두 형용사)
```

### D. 비즈니스 활용
```
✓ Our company values integrity, excellence, and innovation.
✓ To succeed, you need to plan carefully, execute efficiently, and adapt quickly.
✓ The project was completed on time, within budget, and above expectations.
✓ We offer competitive salaries, comprehensive benefits, and flexible working hours.
```

## 2️⃣ 도치 (Inversion)

### 개념
강조를 위해 정상적인 어순(주어 + 동사)을 바꾸는 구조입니다.

### A. 부정어 도치
부정어가 문장 앞에 오면 의문문 어순이 됩니다.

```
기본: We have never seen such growth.
도치: Never have we seen such growth.
      (더 강조됨)

기본: We rarely encounter such challenges.
도치: Rarely do we encounter such challenges.

기본: I have seldom witnessed such dedication.
도치: Seldom have I witnessed such dedication.

기본: The company had hardly recovered when another crisis hit.
도치: Hardly had the company recovered when another crisis hit.

기본: We not only met the target but also exceeded it.
도치: Not only did we meet the target, but we also exceeded it.
```

### B. Only 도치
```
기본: We realized the problem only then.
도치: Only then did we realize the problem.

기본: We can succeed only by working together.
도치: Only by working together can we succeed.

기본: You will understand the complexity only when you see the data.
도치: Only when you see the data will you understand the complexity.
```

### C. 비즈니스 활용
```
✓ Never before have we faced such competition.
  (이전에 이런 경쟁에 직면한 적이 없습니다)

✓ Rarely does an opportunity like this come along.
  (이런 기회는 좀처럼 오지 않습니다)

✓ Not only do we offer quality products, but we also provide excellent service.
  (우리는 품질 좋은 제품뿐만 아니라 훌륭한 서비스도 제공합니다)

✓ Only by innovating can we stay competitive.
  (혁신해야만 경쟁력을 유지할 수 있습니다)

✓ Under no circumstances should we compromise on quality.
  (어떤 상황에서도 품질을 타협해서는 안 됩니다)
```

## 3️⃣ 분열문 (Cleft Sentences)

### 개념
특정 부분을 강조하기 위해 문장을 두 부분으로 나누는 구조입니다.

### A. It is/was...that/who 구문

```
기본: We need better communication.
강조: What we need is better communication.
     It is better communication that we need.

기본: The CEO made this decision.
강조: It was the CEO who made this decision.
     (CEO를 강조)

기본: We achieved success through teamwork.
강조: It was through teamwork that we achieved success.
     (방법을 강조)

기본: The lack of planning caused the failure.
강조: It was the lack of planning that caused the failure.
     (원인을 강조)
```

### B. What...is/was 구문
주어나 목적어를 강조할 때 사용합니다.

```
기본: We need investment.
강조: What we need is investment.

기본: I want your commitment.
강조: What I want is your commitment.

기본: The high costs surprised us.
강조: What surprised us was the high costs.

기본: Customer satisfaction matters most.
강조: What matters most is customer satisfaction.
```

### C. 비즈니스 활용
```
✓ What distinguishes us from competitors is our customer service.
  (경쟁사와 우리를 구분하는 것은 고객 서비스입니다)

✓ It is innovation that drives our success.
  (우리의 성공을 이끄는 것은 혁신입니다)

✓ What we're looking for is a strategic partnership.
  (우리가 찾고 있는 것은 전략적 파트너십입니다)

✓ It was the marketing campaign that boosted sales.
  (판매를 증가시킨 것은 마케팅 캠페인이었습니다)

✓ What makes this product unique is its versatility.
  (이 제품을 독특하게 만드는 것은 다용성입니다)
```

## 4️⃣ 명사화 (Nominalization)

### 개념
동사나 형용사를 명사로 전환하여 더 격식 있고 간결한 표현을 만듭니다.

### A. 동사 → 명사
```
일반: We decided to expand.
명사화: Our decision to expand...

일반: The company grew rapidly.
명사화: The company's rapid growth...

일반: We implemented the new system.
명사화: The implementation of the new system...

일반: Profits increased.
명사화: The increase in profits...

일반: We developed a new strategy.
명사화: The development of a new strategy...
```

### B. 형용사 → 명사
```
일반: The process is efficient.
명사화: The efficiency of the process...

일반: The product is available.
명사화: The availability of the product...

일반: The market is competitive.
명사화: The competitiveness of the market...

일반: The team is productive.
명사화: The productivity of the team...
```

### C. 비즈니스 활용
```
✓ The implementation of this strategy will take six months.
  (이 전략의 실행은 6개월이 걸릴 것입니다)

✓ The acquisition of the company was completed last month.
  (회사의 인수는 지난달에 완료되었습니다)

✓ The effectiveness of our marketing campaign exceeded expectations.
  (마케팅 캠페인의 효과성이 기대를 초과했습니다)

✓ The sustainability of this growth depends on innovation.
  (이 성장의 지속 가능성은 혁신에 달려 있습니다)
```

### D. 주의사항
과도한 명사화는 문장을 이해하기 어렵게 만들 수 있습니다.

```
과도한 명사화:
✗ The implementation of the facilitation of the improvement of productivity...
  (이해하기 어려움)

적절한 명사화:
✓ We implemented measures to improve productivity.
  (명확하고 이해하기 쉬움)
```

## 5️⃣ 축약된 관계절 (Reduced Relative Clauses)

### 개념
관계대명사와 be동사를 생략하여 간결한 표현을 만듭니다.

### A. 현재분사로 축약
```
기본: The company which is leading the market...
축약: The company leading the market...

기본: Employees who work remotely...
축약: Employees working remotely...

기본: Projects that require more funding...
축약: Projects requiring more funding...
```

### B. 과거분사로 축약
```
기본: The report which was submitted yesterday...
축약: The report submitted yesterday...

기본: Products that are made in Korea...
축약: Products made in Korea...

기본: Issues that were discussed in the meeting...
축약: Issues discussed in the meeting...
```

### C. 비즈니스 활용
```
✓ The strategy adopted by the board has proven successful.
  (이사회가 채택한 전략이 성공적임이 입증되었습니다)

✓ Companies operating in this sector face many challenges.
  (이 분야에서 운영되는 회사들은 많은 도전에 직면합니다)

✓ The figures presented in the report are encouraging.
  (보고서에 제시된 수치들은 고무적입니다)

✓ Employees selected for the program will receive training.
  (프로그램에 선발된 직원들은 교육을 받을 것입니다)
```

## 6️⃣ 생략과 대치 (Ellipsis & Substitution)

### A. 생략 (Ellipsis)
반복을 피하기 위해 문장의 일부를 생략합니다.

```
기본: Some people support the plan, and some people oppose the plan.
생략: Some people support the plan, and some oppose it.
     Some support the plan, and some oppose it.

기본: I can attend the morning session, but I cannot attend the afternoon session.
생략: I can attend the morning session, but I cannot the afternoon session.
     I can attend the morning session, but not the afternoon session.

✓ A: Will you join the meeting?
  B: I will. (join the meeting 생략)

✓ A: Have you reviewed the contract?
  B: I have. (reviewed the contract 생략)
```

### B. 대치 (Substitution)
반복을 피하기 위해 다른 단어로 대체합니다.

```
명사 대치 (one, ones):
✓ This laptop is expensive. I need a cheaper one.
✓ These strategies are outdated. We need new ones.

동사 대치 (do, does, did):
✓ She works harder than I do.
✓ The team performed better than expected, and they did so consistently.

so/not 대치:
✓ A: Will we meet the deadline?
  B: I hope so. / I don't think so.
```

### C. 비즈니스 활용
```
✓ Our profits increased last year, and we expect them to do so again this year.
  (우리의 이익은 작년에 증가했고, 올해도 그렇게 되기를 기대합니다)

✓ Some departments have adopted the new system, while others have not.
  (일부 부서는 새 시스템을 도입했지만, 다른 부서들은 그렇지 않습니다)

✓ We can offer the basic package or the premium one.
  (기본 패키지나 프리미엄 패키지를 제공할 수 있습니다)
```

## 7️⃣ 헤징과 외교적 언어 (Hedging & Diplomatic Language)

### 개념
확신을 줄이거나 완곡하게 표현하여 공손하고 외교적으로 말합니다.

### A. 확신 줄이기 (Hedging)

#### Modal Verbs
```
확신 강함:
✓ This will increase sales.

확신 줄임:
✓ This could increase sales.
✓ This might increase sales.
✓ This may increase sales.
✓ This should increase sales.
```

#### Adverbs
```
✓ This is probably the best solution.
✓ We perhaps need to reconsider.
✓ This possibly indicates a trend.
✓ Presumably, costs will decrease.
```

#### Verbs
```
강한 표현: This proves that...
완곡한 표현: This suggests that...
           This indicates that...
           This seems to show that...
           This tends to suggest that...
           This appears to indicate that...
```

### B. 외교적 비판
```
직접적: Your proposal is wrong.
외교적: There might be some issues with the proposal.
       The proposal may need some refinement.
       Perhaps we could reconsider certain aspects.

직접적: This won't work.
외교적: This might be challenging to implement.
       This could present some difficulties.
       We may want to explore alternatives.

직접적: You made a mistake.
외교적: There seems to be a small discrepancy here.
       We might want to double-check these figures.
       Perhaps we could review this section again.
```

### C. 공손한 요청
```
직접적: Send me the report.
공손함: Could you send me the report?
       Would you mind sending me the report?
       I was wondering if you could send me the report?
       Would it be possible to send me the report?

직접적: This needs to change.
공손함: We might need to make some changes.
       Perhaps we should consider some adjustments.
       It may be worth reviewing this aspect.
```

### D. 비즈니스 활용
```
✓ It would seem that our current approach may need some adjustment.
  (현재 접근 방식이 다소 조정이 필요한 것 같습니다)

✓ The data appears to suggest a downward trend.
  (데이터가 하락 추세를 나타내는 것 같습니다)

✓ We might want to consider alternative strategies.
  (대안 전략을 고려하는 것이 좋을 것 같습니다)

✓ This could potentially lead to some complications.
  (이것이 잠재적으로 일부 복잡한 문제로 이어질 수 있습니다)

✓ Perhaps it would be advisable to seek expert opinion.
  (전문가 의견을 구하는 것이 바람직할 것 같습니다)
```

## 8️⃣ 복잡한 문장 패턴 (Complex Sentence Patterns)

### A. 조건절 + 결과절
```
✓ Should you need any assistance, please don't hesitate to contact us.
  (= If you should need...)

✓ Were we to expand now, we would need significant investment.
  (= If we were to expand...)

✓ Had we known earlier, we could have prepared better.
  (= If we had known...)
```

### B. 양보절 고급 패턴
```
✓ Despite the challenges, we achieved our goals.
✓ Notwithstanding the difficulties, the project succeeded.
✓ Regardless of the obstacles, we remained committed.
✓ While acknowledging the risks, we believe the opportunity is worth pursuing.
✓ Much as I appreciate the offer, I must decline.
```

### C. 인과관계 고급 패턴
```
✓ Given the current market conditions, we should postpone the launch.
✓ Owing to budget constraints, we need to scale back operations.
✓ In light of recent developments, we must revise our strategy.
✓ On account of increasing costs, prices will be adjusted.
```

## 9️⃣ 비즈니스 글쓰기 패턴

### A. 보고서 작성
```
✓ This report examines the factors contributing to the decline in sales.
✓ The analysis reveals several key trends.
✓ The findings suggest that immediate action is required.
✓ Based on the data, we recommend the following measures.
```

### B. 제안서 작성
```
✓ We propose to implement a three-phase strategy.
✓ The proposed solution offers several advantages.
✓ Implementation would require an initial investment of $500,000.
✓ We anticipate a return on investment within 18 months.
```

### C. 이메일 작성
```
정중한 요청:
✓ I would be grateful if you could review the attached document.
✓ Would it be possible to schedule a meeting next week?

정보 제공:
✓ I am writing to inform you that the deadline has been extended.
✓ Please be advised that the policy will change effective January 1st.

후속 조치:
✓ Further to our conversation, I am pleased to confirm...
✓ With reference to your inquiry, I would like to clarify...
```

## 💡 실전 팁

### 언제 사용하는가?

**병렬 구조**: 리스트, 목표, 가치 등을 나열할 때
```
✓ Our values are integrity, excellence, and innovation.
```

**도치**: 강조하고 싶을 때, 격식 있는 문서에서
```
✓ Never before have we seen such growth.
```

**분열문**: 특정 부분을 강조하고 싶을 때
```
✓ What matters most is customer satisfaction.
```

**명사화**: 학술적/격식 있는 글에서
```
✓ The implementation of this strategy...
```

**헤징**: 비판하거나 불확실할 때
```
✓ This might need some adjustment.
```

### 주의사항

1. **과도한 사용 금지**: 고급 구조를 너무 많이 사용하면 이해하기 어려워집니다.
2. **맥락 고려**: 이메일에서는 간단히, 보고서에서는 격식 있게
3. **명확성 우선**: 복잡한 구조보다 명확한 의사소통이 우선
