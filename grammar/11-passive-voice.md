# 수동태 (Passive Voice)

## 📌 기본 개념

수동태는 **행동의 대상**에 초점을 맞출 때 사용합니다.
능동태는 "누가 했다"를, 수동태는 "무엇이 되었다"를 강조합니다.

**비즈니스에서 수동태를 쓰는 이유**:
- 더 객관적이고 전문적으로 들림
- 행위자가 불명확하거나 중요하지 않을 때
- 결과에 초점을 맞출 때
- 책임을 모호하게 할 때

## ✏️ 형태

```
능동태: 주어 + 동사 + 목적어
수동태: 주어(원래 목적어) + be동사 + 과거분사 (+ by 행위자)
```

### 예시
```
능동태: The team completed the project.
       (팀이 프로젝트를 완료했다)

수동태: The project was completed (by the team).
       (프로젝트가 완료되었다)
```

## 🎯 시제별 수동태 형태

### 현재형 (Present Simple)
```
능동: We make this product in Korea.
수동: This product is made in Korea.
     (이 제품은 한국에서 만들어집니다)

능동: They speak English here.
수동: English is spoken here.
     (영어가 여기서 사용됩니다)
```

**형태**: am/is/are + 과거분사

### 과거형 (Past Simple)
```
능동: The company launched the product in 2020.
수동: The product was launched in 2020.
     (제품이 2020년에 출시되었습니다)

능동: Someone sent the email yesterday.
수동: The email was sent yesterday.
     (이메일이 어제 발송되었습니다)
```

**형태**: was/were + 과거분사

### 현재완료 (Present Perfect)
```
능동: We have finished the report.
수동: The report has been finished.
     (보고서가 완료되었습니다)

능동: They have sold 1,000 units.
수동: 1,000 units have been sold.
     (1,000개가 판매되었습니다)
```

**형태**: have/has been + 과거분사

### 미래형 (Future)
```
능동: We will complete the project next month.
수동: The project will be completed next month.
     (프로젝트가 다음 달에 완료될 것입니다)

능동: They are going to announce the results.
수동: The results are going to be announced.
     (결과가 발표될 것입니다)
```

**형태**: will be + 과거분사

### 진행형 (Progressive)
```
능동: We are reviewing the document.
수동: The document is being reviewed.
     (문서가 검토되고 있습니다)

능동: They were discussing the issue.
수동: The issue was being discussed.
     (문제가 논의되고 있었습니다)
```

**형태**: am/is/are being + 과거분사 (현재진행)
       was/were being + 과거분사 (과거진행)

### 조동사 (Modals)
```
능동: You should check the data.
수동: The data should be checked.
     (데이터가 확인되어야 합니다)

능동: We can solve the problem.
수동: The problem can be solved.
     (문제가 해결될 수 있습니다)
```

**형태**: 조동사 + be + 과거분사

## 💼 비즈니스에서 자주 쓰는 수동태

### 보고서 작성
```
The report was prepared by our team.
(보고서는 우리 팀에 의해 준비되었습니다)

The data has been analyzed carefully.
(데이터가 신중하게 분석되었습니다)

The following points should be considered.
(다음 사항들이 고려되어야 합니다)

The project is expected to be completed by June.
(프로젝트는 6월까지 완료될 것으로 예상됩니다)
```

### 회의/공지
```
The meeting will be held on Monday at 10am.
(회의가 월요일 10시에 개최될 것입니다)

All employees are required to attend the training.
(모든 직원은 교육에 참석해야 합니다)

The decision was made after careful consideration.
(결정은 신중한 고려 후에 내려졌습니다)

The results will be announced next week.
(결과는 다음 주에 발표될 것입니다)
```

### 제품/서비스 설명
```
This product is made with high-quality materials.
(이 제품은 고품질 재료로 만들어집니다)

Our services are provided 24/7.
(우리 서비스는 24시간 제공됩니다)

The software has been downloaded over 1 million times.
(소프트웨어가 100만 번 이상 다운로드되었습니다)

This feature is designed for business users.
(이 기능은 비즈니스 사용자를 위해 설계되었습니다)
```

### 절차/프로세스
```
Applications should be submitted by Friday.
(신청서는 금요일까지 제출되어야 합니다)

The forms must be filled out completely.
(양식은 완전히 작성되어야 합니다)

Payment can be made by credit card.
(결제는 신용카드로 할 수 있습니다)

The issue is being investigated.
(문제가 조사되고 있습니다)
```

## 🔑 수동태 vs 능동태 선택

### 수동태를 쓰는 경우

#### 1) 행위자가 불명확하거나 중요하지 않을 때
```
✅ The office was broken into last night.
   (사무실이 어젯밤에 도난당했다)
   - 누가 했는지 모르거나 중요하지 않음

✅ English is spoken in many countries.
   (영어는 많은 나라에서 사용된다)
   - 누가 말하는지 중요하지 않음
```

#### 2) 결과나 대상에 초점을 맞출 때
```
✅ The project was completed ahead of schedule.
   (프로젝트가 일정보다 빨리 완료되었다)
   - 완료된 것이 중요

✅ 1,000 units were sold in the first week.
   (첫 주에 1,000개가 판매되었다)
   - 판매된 수량이 중요
```

#### 3) 객관적이고 전문적인 어조를 원할 때
```
✅ The proposal has been approved.
   (제안이 승인되었습니다)
   - 전문적이고 격식 있음

vs

❌ We approved the proposal.
   (우리가 제안을 승인했습니다)
   - 덜 격식적
```

#### 4) 책임을 모호하게 하고 싶을 때
```
✅ Mistakes were made.
   (실수가 있었습니다)
   - 누가 했는지 명시하지 않음

✅ The deadline was missed.
   (마감이 놓쳤습니다)
   - 책임 소재 불분명
```

### 능동태를 쓰는 경우

#### 1) 행위자가 중요할 때
```
✅ Steve Jobs founded Apple in 1976.
   (스티브 잡스가 1976년에 애플을 설립했다)

✅ Our CEO will announce the new strategy.
   (우리 CEO가 새 전략을 발표할 것이다)
```

#### 2) 더 직접적이고 명확한 표현을 원할 때
```
✅ I completed the report.
   (제가 보고서를 완료했습니다)

✅ We increased sales by 30%.
   (우리가 매출을 30% 증가시켰습니다)
```

## 💬 대화 예시

### 예시 1: 프로젝트 상태 보고
```
Manager: What's the status of the project?
        (프로젝트 상태가 어떻게 되나요?)

Employee: The design phase has been completed, and
         the development is being done by the IT team.
         The product will be tested next week, and
         it is expected to be launched in March.
         (디자인 단계가 완료되었고, 개발이 IT 팀에 의해
         진행되고 있습니다. 제품은 다음 주에 테스트될
         것이고, 3월에 출시될 것으로 예상됩니다.)
```

### 예시 2: 회의 공지
```
A: When will the meeting be held?
   (회의가 언제 열리나요?)

B: The meeting will be held on Tuesday at 2pm.
   All team members are required to attend.
   The agenda has been sent to everyone by email.
   (회의는 화요일 2시에 열릴 것입니다.
   모든 팀원이 참석해야 합니다.
   안건이 이메일로 모두에게 발송되었습니다.)
```

### 예시 3: 제품 설명
```
Customer: Where is this product made?
         (이 제품은 어디서 만들어지나요?)

Sales: This product is manufactured in Korea using
      high-quality materials. It has been tested
      thoroughly and is trusted by over 10,000 customers.
      (이 제품은 고품질 재료를 사용하여 한국에서
      제조됩니다. 철저히 테스트되었고 10,000명 이상의
      고객에게 신뢰받고 있습니다.)
```

## ⚠️ 주의사항

### 1. by + 행위자는 생략 가능
```
✅ The report was written by John. (행위자 명시)
✅ The report was written. (행위자 생략 - 더 일반적)

비즈니스에서는 대부분 생략
```

### 2. 자동사는 수동태 불가
```
❌ The meeting was happened yesterday.
✅ The meeting happened yesterday.
(happen은 자동사)

❌ The price was risen.
✅ The price rose. / The price was raised.
(rise는 자동사, raise는 타동사)
```

### 3. 수동태 남용 주의
```
❌ The report was written by me, and it was sent by me.
✅ I wrote and sent the report.
(능동태가 더 간결하고 명확)

수동태를 과도하게 쓰면 문장이 복잡하고 지루해짐
```

### 4. get을 이용한 수동태 (비격식적)
```
격식: The document was delivered.
비격식: The document got delivered.

격식: He was promoted to manager.
비격식: He got promoted to manager.

비즈니스 글쓰기에서는 be동사 수동태 사용 권장
```
