# 명사와 관사 (Nouns & Articles)

## 📖 개념

명사는 사람, 사물, 장소, 개념의 이름이고, 관사는 명사 앞에서 명사를 한정하는 역할을 합니다.

---

## 1️⃣ 명사의 종류 (Types of Nouns)

### A. 가산명사 vs. 불가산명사

#### 가산명사 (Countable Nouns)
```
셀 수 있는 명사:
- 단수: a book, one employee, an office
- 복수: books, employees, offices

비즈니스 예시:
✓ one project → two projects
✓ a client → five clients
✓ an email → ten emails
✓ a meeting → several meetings
```

#### 불가산명사 (Uncountable Nouns)
```
셀 수 없는 명사 (항상 단수 취급):
- 물질: water, coffee, paper
- 추상: information, advice, progress, work
- 집합: furniture, equipment, luggage

비즈니스 예시:
✓ information (NOT informations)
✓ equipment (NOT equipments)
✓ advice (NOT advices)
✓ research (NOT researches)
✓ feedback (NOT feedbacks)
✓ homework (NOT homeworks)

수량 표현 방법:
- a piece of information
- some equipment
- much advice
- a lot of research
```

### B. 주요 불가산명사 (비즈니스)

```
절대 복수형 안 됨:
- information (정보)
- advice (조언)
- feedback (피드백)
- research (연구)
- evidence (증거)
- knowledge (지식)
- progress (진행)
- work (업무)
- news (뉴스)
- furniture (가구)
- equipment (장비)
- luggage/baggage (수하물)
- traffic (교통)
- weather (날씨)

예시:
✓ We need more information.
✗ We need more informations.

✓ Let me give you some advice.
✗ Let me give you some advices.

✓ The equipment is expensive.
✗ The equipments are expensive.
```

### C. 항상 복수형인 명사

```
항상 복수 (단수형 없음):
- scissors (가위)
- pants/trousers (바지)
- glasses (안경)
- goods (상품)
- clothes (옷)
- stairs (계단)
- thanks (감사)
- congratulations (축하)

예시:
✓ These scissors are sharp.
✓ My glasses are on the desk.
✓ The goods were delivered yesterday.
```

## 2️⃣ 관사 (Articles)

### A. 부정관사 (Indefinite Articles: a/an)

#### 사용 규칙
```
A (자음 소리 앞):
- a book
- a company
- a user
- a European country (유럽 = /jʊ/, 자음 소리)
- a university (유니 = /juː/, 자음 소리)

AN (모음 소리 앞):
- an email
- an office
- an hour (아워, h 묵음)
- an honest person (어네스트, h 묵음)
- an MBA (엠비에이, M = /em/, 모음 소리)
```

#### 용법
```
1. 처음 언급하는 것:
   - I have a meeting tomorrow.
   - We need a new strategy.

2. 직업이나 신분:
   - She is a manager.
   - He is an engineer.

3. "어떤 ~" "하나의 ~":
   - We need a solution.
   - This is a good opportunity.
```

### B. 정관사 (Definite Article: the)

#### 사용하는 경우
```
1. 이미 언급된 것:
   - I have a meeting. The meeting is at 2pm.
   - We hired a consultant. The consultant starts Monday.

2. 유일한 것:
   - the CEO (회사에 CEO는 한 명)
   - the sun, the moon, the earth
   - the internet, the economy

3. 특정한 것:
   - The report you sent was excellent.
   - The project we discussed yesterday...

4. 최상급 앞:
   - the best solution
   - the most important issue
   - the largest market

5. 서수 앞:
   - the first quarter
   - the second meeting
   - the next step

6. 악기:
   - play the piano
   - play the guitar

7. 국가명 (특정 패턴):
   - the United States
   - the United Kingdom
   - the Netherlands
   - the Philippines
```

### C. 무관사 (Zero Article)

#### 관사를 쓰지 않는 경우
```
1. 복수 명사 (일반적):
   - Employees need training. (일반적인 직원들)
   - Computers are essential. (일반적인 컴퓨터들)

2. 불가산명사 (일반적):
   - Information is power.
   - Time is money.
   - Success requires hard work.

3. 대부분의 나라, 도시, 거리 이름:
   - Korea, Japan, China
   - Seoul, Tokyo, New York
   - Main Street, Wall Street

4. 대부분의 회사명:
   - Google, Microsoft, Samsung
   - (BUT: The New York Times)

5. 식사:
   - have breakfast/lunch/dinner
   - (BUT: The dinner was delicious. = 특정 저녁)

6. 학문, 언어, 스포츠:
   - study economics, learn English, play soccer

7. by + 교통수단:
   - by car, by train, by email
   - (BUT: in my car, on the train)
```

## 3️⃣ 비즈니스 영어에서 자주 실수하는 부분

### Common Mistakes

#### 실수 1: 불가산명사에 복수형
```
✗ We need more informations.
✓ We need more information.

✗ Thank you for your advices.
✓ Thank you for your advice.

✗ The equipments are ready.
✓ The equipment is ready.

✗ Let me give you some feedbacks.
✓ Let me give you some feedback.
```

#### 실수 2: 관사 누락
```
✗ I am manager.
✓ I am a manager.

✗ This is good opportunity.
✓ This is a good opportunity.

✗ Please review report.
✓ Please review the report.
```

#### 실수 3: 불필요한 관사
```
✗ I go to work by the car.
✓ I go to work by car.

✗ The success requires hard work.
✓ Success requires hard work.

✗ We need the teamwork.
✓ We need teamwork.
```

#### 실수 4: a/an 혼동
```
✗ an university
✓ a university (유 = /juː/ 소리)

✗ a hour
✓ an hour (h 묵음)

✗ a MBA
✓ an MBA (엠 = /em/ 소리)
```

## 4️⃣ 비즈니스 영어 실전 예문

### 이메일 작성
```
✓ I have a question about the project.
  (처음 언급 = a, 특정 프로젝트 = the)

✓ The information you provided was helpful.
  (불가산명사, 특정 정보 = the)

✓ We need to hire an experienced manager.
  (처음 언급, 모음 소리 = an)

✓ Thank you for the feedback.
  (불가산명사, 특정 피드백 = the)
```

### 회의
```
✓ Let's move on to the next agenda item.
  (서수 = the)

✓ This is the best solution we have.
  (최상급 = the)

✓ We need more time to complete the analysis.
  (불가산명사, 일반적 = 무관사)

✓ Teamwork is essential for success.
  (추상명사, 일반적 = 무관사)
```

### 프레젠테이션
```
✓ The company was founded in 2010.
  (특정 회사 = the)

✓ We are the largest provider in Korea.
  (최상급 = the)

✓ Innovation drives growth.
  (추상명사, 일반적 = 무관사)

✓ Customers expect quality and service.
  (일반적 복수 = 무관사)
```

### Exercise 1 정답:
1. - (불가산명사, 일반적)

## 💡 실전 팁

### 비즈니스 글쓰기 체크리스트
```
✓ 불가산명사에 s를 붙이지 않았나?
  (information, advice, equipment, feedback)

✓ 직업 앞에 a/an을 넣었나?
  (I am a manager, She is an engineer)

✓ 이미 언급한 것에 the를 썼나?
  (I have a meeting. The meeting is at 2pm.)

✓ by + 교통수단에 the를 안 붙였나?
  (by car, by email, by train)

✓ 추상명사 일반화할 때 the를 안 붙였나?
  (Success requires effort, NOT The success...)
```

---

**💡 기억하세요**:
- 불가산명사는 항상 단수! (information, advice, equipment)
- 처음 언급 = a/an, 두 번째부터 = the
- 최상급 앞에는 항상 the!
- by + 교통수단에는 관사 없음!
