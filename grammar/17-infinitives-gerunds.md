# to부정사와 동명사 (Infinitives & Gerunds)

## 📖 개념

**To부정사 (Infinitive)**: to + 동사원형 (to work, to go, to be)
**동명사 (Gerund)**: 동사원형 + -ing (working, going, being)

둘 다 "동사를 명사처럼" 사용하지만, 어떤 동사 뒤에 어떤 형태가 오는지 규칙이 있습니다.

---

## 1️⃣ To부정사 (Infinitive)

### A. To부정사의 용법

#### 1. 명사 용법 (주어, 목적어, 보어)
```
주어:
✓ To learn English is important.
✓ To succeed requires hard work.
(It을 주어로 쓰는 게 더 자연스러움)
✓ It is important to learn English.
✓ It requires hard work to succeed.

목적어:
✓ I want to learn.
✓ We decided to expand.
✓ She hopes to succeed.

보어:
✓ My goal is to improve productivity.
✓ The plan is to launch in Q2.
```

#### 2. 형용사 용법 (명사 수식)
```
✓ I have a meeting to attend.
  (참석해야 할 회의)

✓ There's work to do.
  (해야 할 일)

✓ We need someone to lead the project.
  (프로젝트를 이끌 누군가)

✓ This is an opportunity to grow.
  (성장할 기회)
```

#### 3. 부사 용법 (목적, 원인, 결과)
```
목적 (위해서):
✓ I came here to discuss the proposal.
✓ We're working hard to meet the deadline.
✓ She called to confirm the meeting.

원인 (해서):
✓ I'm glad to hear that.
✓ We're sorry to inform you.
✓ I'm pleased to announce...

결과 (결과적으로):
✓ He grew up to become CEO.
✓ We worked late only to find an error.
```

### B. To부정사를 목적어로 취하는 동사

```
암기 필수 동사들:

want (원하다)
✓ I want to apply for the position.

hope (희망하다)
✓ We hope to expand next year.

plan (계획하다)
✓ They plan to hire 50 employees.

decide (결정하다)
✓ She decided to accept the offer.

expect (기대하다)
✓ We expect to complete by Friday.

agree (동의하다)
✓ They agreed to the terms.

promise (약속하다)
✓ I promise to deliver on time.

need (필요하다)
✓ You need to review this document.

refuse (거절하다)
✓ He refused to compromise.

manage (해내다)
✓ We managed to meet the deadline.

offer (제안하다)
✓ They offered to help.

seem (보이다)
✓ The project seems to be progressing well.

tend (경향이 있다)
✓ Prices tend to increase in Q4.

fail (실패하다)
✓ We failed to anticipate this issue.

learn (배우다)
✓ She learned to code.

afford (여유가 있다)
✓ We can't afford to make mistakes.
```

## 2️⃣ 동명사 (Gerund)

### A. 동명사의 용법

#### 1. 주어
```
✓ Working remotely has become common.
✓ Learning new skills is essential.
✓ Meeting deadlines is crucial.
✓ Hiring talent is challenging.
```

#### 2. 목적어
```
✓ I enjoy working here.
✓ We finished reviewing the proposal.
✓ She avoided making a decision.
```

#### 3. 보어
```
✓ My hobby is reading.
✓ The key is understanding customer needs.
```

#### 4. 전치사의 목적어
```
✓ Thank you for coming.
✓ I'm interested in learning more.
✓ We're thinking about expanding.
✓ She's good at problem-solving.
```

### B. 동명사를 목적어로 취하는 동사

```
암기 필수 동사들:

enjoy (즐기다)
✓ I enjoy working with this team.

finish (끝내다)
✓ We finished reviewing the documents.

avoid (피하다)
✓ We should avoid making hasty decisions.

consider (고려하다)
✓ They're considering expanding overseas.

suggest (제안하다)
✓ I suggest postponing the meeting.

recommend (추천하다)
✓ I recommend reading this book.

admit (인정하다)
✓ He admitted making a mistake.

deny (부인하다)
✓ The company denied violating regulations.

mind (꺼리다)
✓ Would you mind closing the door?

miss (그리워하다, 놓치다)
✓ I miss working in the office.

practice (연습하다)
✓ Practice speaking English daily.

quit (그만두다)
✓ He quit smoking last year.

risk (위험을 무릅쓰다)
✓ We can't risk losing this client.

keep (계속하다)
✓ Keep trying!

imagine (상상하다)
✓ I can't imagine working anywhere else.

postpone/delay (연기하다)
✓ We postponed launching the product.
```

## 3️⃣ 둘 다 가능한 동사 (의미 차이 있음)

### A. 의미가 다른 경우

#### 1. Remember
```
remember to + V: ~할 것을 기억하다 (미래, 아직 안 함)
✓ Remember to send the email. (아직 안 보냄, 보낼 것을 기억)

remember + V-ing: ~했던 것을 기억하다 (과거, 이미 함)
✓ I remember sending the email. (이미 보냈고, 그것을 기억함)
```

#### 2. Forget
```
forget to + V: ~할 것을 잊다 (미래, 안 함)
✓ I forgot to call him. (전화하지 않음)

forget + V-ing: ~했던 것을 잊다 (과거, 이미 함)
✓ I'll never forget meeting you. (만났던 것을 잊지 못함)
```

#### 3. Stop
```
stop to + V: ~하기 위해 멈추다 (목적)
✓ I stopped to rest. (쉬기 위해 멈췄다)

stop + V-ing: ~하는 것을 멈추다 (중단)
✓ I stopped working at 6pm. (일하는 것을 멈췄다)
```

#### 4. Try
```
try to + V: ~하려고 노력하다 (시도)
✓ I tried to call you. (전화하려고 했으나 연결 안 됨)

try + V-ing: (실험 삼아) ~해보다
✓ Try calling again later. (다시 전화해보는 게 어때요?)
```

#### 5. Regret
```
regret to + V: ~하게 되어 유감이다 (현재/미래, 나쁜 소식 전달)
✓ I regret to inform you... (알려드리게 되어 유감입니다)

regret + V-ing: ~했던 것을 후회하다 (과거)
✓ I regret not accepting the offer. (그 제안을 받지 않은 것을 후회한다)
```

### B. 의미가 거의 같은 경우

```
begin/start:
✓ It began to rain. = It began raining.

continue:
✓ We continued to work. = We continued working.

like/love/hate:
✓ I like to work early. = I like working early.
✓ I love to travel. = I love traveling.
✓ I hate to interrupt. = I hate interrupting.
```

## 4️⃣ 전치사 + 동명사

### 전치사 뒤에는 항상 동명사!

```
전치사 + V-ing:

about:
✓ What about having lunch?
✓ We're thinking about expanding.

after:
✓ After finishing the report, I left.

before:
✓ Check it before sending.

by:
✓ You can improve by practicing.

for:
✓ Thank you for coming.
✓ This tool is useful for analyzing data.

in:
✓ I'm interested in learning more.
✓ She succeeded in getting the contract.

of:
✓ I'm thinking of applying.
✓ What's the purpose of having this meeting?

on:
✓ Congratulations on getting promoted!
✓ We insist on receiving payment first.

to (전치사일 때):
✓ I'm looking forward to hearing from you.
✓ I'm used to working long hours.
✓ He's committed to improving quality.

without:
✓ We can't proceed without approving the budget.

at:
✓ She's good at solving problems.

from:
✓ This prevents us from making mistakes.
```

### 주의: to가 전치사인 표현들

```
look forward to + V-ing
✓ I look forward to meeting you.
✗ I look forward to meet you.

be used to + V-ing (익숙하다)
✓ I'm used to working remotely.
✗ I'm used to work remotely.

be accustomed to + V-ing
✓ We're accustomed to dealing with challenges.

object to + V-ing (반대하다)
✓ They objected to changing the plan.

in addition to + V-ing
✓ In addition to managing the team, she handles clients.

when it comes to + V-ing
✓ When it comes to negotiating, he's the best.

be committed to + V-ing
✓ We're committed to delivering quality.

be dedicated to + V-ing
✓ She's dedicated to helping others.
```

## 5️⃣ 비즈니스 영어에서 자주 쓰는 패턴

### To부정사 패턴

```

✓ It is important to meet deadlines.
✓ It is necessary to review the contract.
✓ It is essential to communicate clearly.

목적 표현:
✓ In order to succeed, we need to innovate.

✓ I'm writing to inquire about the position.

의견/감정:
✓ I'm pleased to announce...
✓ We're happy to help.
✓ I'd like to propose...
```

### 동명사 패턴

```

✓ I apologize for not responding sooner.

✓ No smoking

```

## 6️⃣ 비즈니스 영어 실수 방지

### Common Mistakes

#### 실수 1: 전치사 뒤에 to부정사
```
✗ Thank you for to come.
✓ Thank you for coming.

✗ I'm interested in to learn.
✓ I'm interested in learning.

✗ We're thinking about to expand.
✓ We're thinking about expanding.
```

#### 실수 2: Look forward to + 동사원형
```
✗ I look forward to meet you.
✓ I look forward to meeting you.

✗ We look forward to hear from you.
✓ We look forward to hearing from you.
```

#### 실수 3: 동사 선택 실수
```
✗ I suggest to postpone the meeting.
✓ I suggest postponing the meeting.

✗ We enjoyed to work with you.
✓ We enjoyed working with you.

✗ They finished to review the proposal.
✓ They finished reviewing the proposal.

✗ He avoided to answer the question.
✓ He avoided answering the question.
```

#### 실수 4: Remember/Forget 혼동
```
✗ Remember sending the email tomorrow. (X - 내일 보낼 건데 과거형?)
✓ Remember to send the email tomorrow.

✗ I forgot meeting him. (실제로 만났는데 잊었다?)
✓ I forgot to meet him. (만나기로 했는데 까먹음)
```

## 8️⃣ 연습 문제

### Exercise 1: To부정사 vs. 동명사

1. I want ___ (learn/learning) Python.
2. We enjoy ___ (work/working) with this client.
3. They decided ___ (expand/expanding) overseas.
4. Have you finished ___ (review/reviewing) the proposal?
5. I'm looking forward to ___ (meet/meeting) you.
6. We need ___ (discuss/discussing) the budget.
7. She avoided ___ (make/making) eye contact.
8. I suggest ___ (postpone/postponing) the meeting.
9. We hope ___ (complete/completing) this by Friday.
10. Thank you for ___ (come/coming) today.

### Exercise 2: 의미 구분

1. I stopped ___ (talk/talking) to him. (이야기하는 것을 멈췄다)
2. I stopped ___ (talk/talking) to him. (그에게 말하기 위해 멈췄다)
3. Remember ___ (send/sending) the email tomorrow. (내일 보낼 것을 기억)
4. I remember ___ (send/sending) the email. (보냈던 것을 기억)
5. Try ___ (restart/restarting) your computer. (재시작해보는 게 어때?)

### Exercise 3: 틀린 문장 고치기

1. I suggest to wait until next week.
2. Thank you for to attend the meeting.
3. I look forward to meet you.
4. We finished to prepare the presentation.
5. She's interested in to learn more.
6. Remember sending the report tomorrow.
7. I'm used to work long hours.
8. We enjoy to collaborate with you.
9. They plan expanding their business.
10. I regret to not accept the offer. (과거 행동 후회)

## 💡 실전 팁

### 암기 방법
```
To부정사 동사들: W-H-P-D-E-A-P-N-R (위험에 동의 합니다)
- Want, Hope, Plan, Decide, Expect, Agree, Promise, Need, Refuse

동명사 동사들: E-F-A-C-S (이팩스)
- Enjoy, Finish, Avoid, Consider, Suggest

전치사 뒤 = 무조건 동명사!
Look forward to = to가 전치사 = 동명사!
```

### 비즈니스 이메일 필수 표현
```
✓ I'm writing to inquire about...
✓ Thank you for contacting us.
✓ I look forward to hearing from you.
✓ Please let me know if you need any assistance.
✓ We suggest scheduling a meeting.
✓ I apologize for not responding sooner.
```

---

**💡 기억하세요**:
- 전치사 뒤에는 항상 동명사! (for coming, about expanding)
- Look forward to = to가 전치사 = 동명사! (to meeting)
- Stop to V (하기 위해 멈추다) ≠ Stop V-ing (하는 것을 멈추다)
- Remember to V (할 것을 기억) ≠ Remember V-ing (했던 것을 기억)
