# 가정법 (Conditionals)

## 📌 기본 개념

가정법은 **조건과 결과**를 표현할 때 사용합니다.
"만약 ~라면, ~할 것이다"라는 구조로 상황의 가능성에 따라 3가지 유형이 있습니다.

## 🎯 3가지 가정법

| 유형 | 시간 | 가능성 | 용도 |
|------|------|--------|------|
| **1st** | 미래 | 가능성 높음 | 실제 가능한 미래 상황 |
| **2nd** | 현재 | 가능성 낮음/상상 | 현재 사실과 반대/비현실적 상황 |
| **3rd** | 과거 | 불가능 | 과거 사실과 반대/후회 |

## ✏️ First Conditional (1st)

### 형태
```
If + 주어 + 현재형, 주어 + will + 동사원형
```

### 의미
**실제로 일어날 가능성이 있는 미래 상황**

### 예시
```
If you work hard, you will succeed.
(열심히 일하면 성공할 것입니다)

If we launch the product, sales will increase.
(제품을 출시하면 매출이 증가할 것입니다)

If the weather is good, we will have the meeting outside.
(날씨가 좋으면 회의를 밖에서 할 것입니다)
```

### 비즈니스 활용
```
If you order 100 units, we will offer a 10% discount.
(100개를 주문하시면 10% 할인을 제공하겠습니다)

If we finish on time, we will get a bonus.
(제시간에 끝내면 보너스를 받을 것입니다)

If you need help, I will assist you.
(도움이 필요하시면 도와드리겠습니다)

If the project succeeds, the company will expand.
(프로젝트가 성공하면 회사가 확장할 것입니다)
```

### 변형
```
unless = if not
Unless you hurry, you will be late.
= If you don't hurry, you will be late.
(서두르지 않으면 늦을 것입니다)

will 대신 can, may, should 등 가능
If you have questions, you can call me.
(질문이 있으시면 전화하셔도 됩니다)
```

## ✏️ Second Conditional (2nd)

### 형태
```
If + 주어 + 과거형, 주어 + would + 동사원형
```

### 의미
**현재 사실과 반대이거나 가능성이 매우 낮은 상황**

### 예시
```
If I had more time, I would help you.
(시간이 더 있다면 도와줄 텐데) → 실제로는 시간이 없음

If I were the CEO, I would change the policy.
(내가 CEO라면 정책을 바꿀 텐데) → 실제로는 CEO가 아님

If we had more budget, we would hire more people.
(예산이 더 있다면 더 많은 사람을 고용할 텐데) → 실제로는 예산이 부족
```

**주의**: be동사는 모든 주어에 **were** 사용 (격식적)
```
격식: If I were you, I would accept the offer.
일반: If I was you, I would accept the offer.

비즈니스에서는 were 권장
```

### 비즈니스 활용

**제안/조언**:
```
If I were you, I would take this opportunity.
(제가 당신이라면 이 기회를 잡을 텐데요)

If we had better technology, we could reduce costs.
(더 나은 기술이 있다면 비용을 줄일 수 있을 텐데)
```

**가정 상황**:
```
If the price were lower, more people would buy it.
(가격이 더 낮다면 더 많은 사람들이 살 텐데)

If we expanded to Asia, we would increase revenue.
(아시아로 확장한다면 수익이 증가할 텐데)
```

**공손한 요청** (would 대신 could):
```
If you could send me the file, I would appreciate it.
(파일을 보내주실 수 있다면 감사하겠습니다)
```

## ✏️ Third Conditional (3rd)

### 형태
```
If + 주어 + had + 과거분사, 주어 + would have + 과거분사
```

### 의미
**과거 사실과 반대 상황 (후회, 비난, 비판)**

### 예시
```
If I had known, I would have helped.
(알았더라면 도왔을 텐데) → 실제로는 몰랐고 돕지 못함

If we had started earlier, we would have finished on time.
(더 일찍 시작했더라면 제시간에 끝냈을 텐데)
→ 실제로는 늦게 시작해서 제시간에 못 끝냄

If they had invested in R&D, they wouldn't have failed.
(R&D에 투자했더라면 실패하지 않았을 텐데)
→ 실제로는 투자하지 않아서 실패함
```

### 비즈니스 활용

**후회**:
```
If we had launched the product earlier, we would have
dominated the market.
(제품을 더 일찍 출시했더라면 시장을 지배했을 텐데)

If I had prepared better, the presentation would have
been successful.
(더 잘 준비했더라면 프레젠테이션이 성공적이었을 텐데)
```

**과거 상황 분석**:
```
If we had hired more people, we would have completed
the project faster.
(더 많은 사람을 고용했더라면 프로젝트를 더 빨리 완료했을 것입니다)

If the economy had been better, sales would have increased.
(경제가 더 좋았더라면 매출이 증가했을 것입니다)
```

## 📊 3가지 가정법 비교

| | If절 | 결과절 | 예시 |
|---|------|--------|------|
| **1st** | 현재형 | will | If it rains, I will stay home. |
| **2nd** | 과거형 | would | If it rained, I would stay home. |
| **3rd** | had p.p. | would have p.p. | If it had rained, I would have stayed home. |

```
1st: If I have time tomorrow, I will call you.
     (내일 시간이 있으면 전화할게요 - 가능성 있음)

2nd: If I had time now, I would call you.
     (지금 시간이 있다면 전화할 텐데 - 실제로는 없음)

3rd: If I had had time yesterday, I would have called you.
     (어제 시간이 있었더라면 전화했을 텐데 - 실제로는 없었음)
```

## 💼 비즈니스 상황별 활용

### 협상
```
1st: If you increase your order, we will reduce the price.
     (주문을 늘리시면 가격을 낮출게요)

2nd: If you ordered 1,000 units, we could offer a better price.
     (1,000개를 주문하신다면 더 나은 가격을 제공할 수 있을 텐데요)
```

### 제안
```
1st: If we implement this system, productivity will improve.
     (이 시스템을 도입하면 생산성이 향상될 것입니다)

2nd: If we had more resources, we could expand faster.
     (자원이 더 있다면 더 빨리 확장할 수 있을 텐데)
```

### 회의
```
1st: If everyone agrees, we will proceed with the plan.
     (모두 동의하면 계획을 진행할 것입니다)

3rd: If we had consulted experts, we would have avoided
     this problem.
     (전문가와 상담했더라면 이 문제를 피했을 텐데)
```

## 🔑 Mixed Conditionals (혼합 가정법)

과거 조건 + 현재 결과:
```
If I had studied harder (과거), I would be a manager now (현재).
(더 열심히 공부했더라면 지금 매니저일 텐데)

If we had invested in technology (과거), we would be more
competitive now (현재).
(기술에 투자했더라면 지금 더 경쟁력이 있을 텐데)
```

현재 조건 + 과거 결과:
```
If I were more careful (현재 성격), I wouldn't have made that
mistake (과거).
(내가 더 신중하다면 그 실수를 하지 않았을 텐데)
```

## 💬 대화 예시

### 예시 1: 협상 (1st & 2nd)
```
Client: Can you offer a discount?
       (할인을 제공할 수 있나요?)

Sales: If you order 100 units, we will give you 10% off. (1st)
      If you ordered 500 units, we could offer 20% off. (2nd)
      (100개를 주문하시면 10% 할인을 드립니다.
      500개를 주문하신다면 20% 할인을 제공할 수 있을 텐데요.)

Client: That sounds good. If we sign a long-term contract,
       would you reduce the price further? (2nd)
       (좋네요. 장기 계약을 한다면 가격을 더 낮춰주시겠어요?)

Sales: Yes, if you committed to a 2-year contract, we could
      discuss additional discounts. (2nd)
      (네, 2년 계약을 약속하신다면 추가 할인을 논의할 수
      있을 것입니다.)
```

### 예시 2: 프로젝트 회의 (3rd)
```
Manager: The project was delayed. What happened?
        (프로젝트가 지연되었습니다. 무슨 일이 있었나요?)

Team: If we had had more developers, we would have finished
     on time. Also, if the requirements hadn't changed,
     we would have delivered earlier.
     (개발자가 더 있었더라면 제시간에 끝냈을 것입니다.
     또한 요구사항이 변경되지 않았더라면 더 일찍 전달했을
     것입니다.)

Manager: I understand. If I had known about the resource issue,
        I would have hired more people.
        (이해합니다. 자원 문제를 알았더라면 더 많은 사람을
        고용했을 텐데요.)
```

### 예시 3: 조언 (2nd)
```
A: I'm not sure if I should take this job offer.
   (이 일자리 제안을 받아야 할지 확신이 서지 않아요.)

B: If I were you, I would consider the long-term benefits.
   If the salary were higher, would you accept it?
   (제가 당신이라면 장기적 이익을 고려할 거예요.
   급여가 더 높다면 받아들이겠어요?)

A: Yes, if they offered 20% more, I would definitely accept.
   (네, 20% 더 제안한다면 확실히 받아들일 거예요.)
```

## ⚠️ 주의사항

### 1. If절에서 will 사용 안 함
```
❌ If you will order 100 units...
✅ If you order 100 units, we will give you a discount.
```

### 2. would vs will 혼동 주의
```
1st (가능): If it rains, I will stay home.
2nd (비현실): If it rained, I would stay home.
```

### 3. 시제 일치
```
✅ If I had known, I would have helped.
❌ If I had known, I would help.
❌ If I knew, I would have helped.
```

### 4. 절 순서 바꾸기 가능
```
If you need help, call me.
= Call me if you need help. (쉼표 없음)
```

## ✍️ 연습 문제

### 문제 1: 적절한 가정법 선택 (1st, 2nd, 3rd)
1. If I _____ (have) time tomorrow, I _____ (help) you.
2. If I _____ (be) you, I _____ (accept) the offer.
3. If we _____ (start) earlier, we _____ (finish) on time.
4. If the price _____ (be) lower, more people _____ (buy) it.
5. If you _____ (order) now, we _____ (ship) it today.

### 문제 2: 문장 완성
1. If I were the CEO, ______________________________
2. If we had invested more, ______________________________
3. If you work hard, ______________________________

### 문제 3: 틀린 부분 찾아 고치기
1. If you will need help, call me.
2. If I would be you, I would accept it.
3. If we started earlier, we will finish on time.
4. If I had knew, I would have helped.

---

## 📚 정답

### 문제 1
1. have, will help (1st - 가능한 미래)
2. were, would accept (2nd - 비현실적 현재)
3. had started, would have finished (3rd - 과거 후회)
4. were, would buy (2nd - 비현실적 현재)
5. order, will ship (1st - 가능한 미래)

### 문제 2 (예시 답안)
1. If I were the CEO, I would change the company policy.
2. If we had invested more, we would have succeeded.
3. If you work hard, you will get promoted.

### 문제 3
1. If you need help (if절에 will 불가)
2. If I were you (would be → were)
3. would finish (will → would, 2nd conditional)
4. had known (had knew → had known)
