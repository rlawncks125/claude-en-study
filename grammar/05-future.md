# 미래형 (Future Tense)

## 📌 기본 개념

영어에는 미래를 표현하는 방법이 **3가지**가 있으며, 각각 사용하는 상황이 다릅니다.

1. **will** - 즉석 결정, 예측, 약속
2. **be going to** - 계획, 의도, 확실한 예측
3. **현재진행형** - 확정된 미래 일정

## 🎯 1. Will

### 형태
```
긍정문: will + 동사원형
부정문: will not (won't) + 동사원형
의문문: Will + 주어 + 동사원형?
```

### 사용 상황

#### A) 즉석 결정 (Spontaneous Decision)
지금 막 결정한 것

```
A: We don't have coffee.
B: I'll buy some. (지금 막 결정)

The phone is ringing. I'll get it.
(전화 울리네. 내가 받을게 - 즉석 결정)

A: This bag is heavy.
B: I'll help you. (도와줄게 - 즉석 제안)
```

#### B) 예측 (Prediction)
생각이나 추측

```
I think the meeting will take 2 hours.
(미팅이 2시간 걸릴 것 같아요)

The project will probably succeed.
(프로젝트가 아마 성공할 거예요)

I don't think he will come.
(그가 올 것 같지 않아요)
```

#### C) 약속/의지 (Promise/Willingness)
```
I will send you the file today. (약속)
(오늘 파일 보내드리겠습니다)

We will do our best. (의지)
(최선을 다하겠습니다)

I will not be late. (약속)
(늦지 않겠습니다)
```

### 비즈니스에서 자주 쓰는 will 표현
```
I will check and get back to you.
(확인하고 연락드리겠습니다)

We will send the proposal by Friday.
(금요일까지 제안서를 보내드리겠습니다)

I will make sure it's done.
(반드시 완료되도록 하겠습니다)

The report will be ready tomorrow.
(보고서는 내일 준비될 것입니다)
```

## 🎯 2. Be going to

### 형태
```
긍정문: am/is/are + going to + 동사원형
부정문: am/is/are + not + going to + 동사원형
의문문: Am/Is/Are + 주어 + going to + 동사원형?
```

### 사용 상황

#### A) 미리 계획한 것 (Plan/Intention)
이미 결정하고 계획한 것

```
I'm going to meet a client tomorrow.
(내일 고객을 만날 거예요 - 이미 계획됨)

We are going to launch the product next month.
(다음 달에 제품을 출시할 예정입니다 - 계획)

She is going to apply for the position.
(그녀는 그 직책에 지원할 거예요 - 의도)
```

#### B) 확실한 증거가 있는 예측 (Prediction with Evidence)
눈으로 보이는 근거가 있을 때

```
Look at those clouds. It's going to rain.
(저 구름 봐. 비 올 거야 - 구름이 보임)

The project is going to fail. We don't have enough resources.
(프로젝트가 실패할 거예요. 자원이 부족해요 - 증거)

She's going to be late. There's heavy traffic.
(그녀가 늦을 거예요. 교통이 막혀요 - 상황)
```

### 비즈니스에서 자주 쓰는 be going to 표현
```
We are going to expand our business.
(사업을 확장할 계획입니다)

I'm going to schedule a meeting.
(미팅을 잡을 예정입니다)

They are going to hire 10 new employees.
(그들은 신입 10명을 채용할 예정입니다)

What are you going to do about this issue?
(이 문제를 어떻게 처리할 예정인가요?)
```

## 🎯 3. 현재진행형 for Future (Present Continuous)

### 형태
```
am/is/are + -ing
```

### 사용 상황
확정된 미래 일정 (특히 약속, 예약)

```
I'm meeting the CEO at 3pm.
(3시에 CEO를 만나요 - 약속 잡힘)

We are having a conference call tomorrow.
(내일 전화회의 해요 - 일정 확정)

She is flying to New York next week.
(그녀는 다음 주에 뉴욕으로 가요 - 항공권 예약됨)

What are you doing this weekend?
(이번 주말에 뭐 해요? - 계획 물어봄)
```

### 비즈니스에서 자주 쓰는 현재진행형 미래 표현
```
We are launching the product on June 1st.
(6월 1일에 제품을 출시합니다 - 확정)

I'm presenting at the conference next month.
(다음 달 컨퍼런스에서 발표합니다 - 확정)

The team is visiting the factory on Friday.
(팀이 금요일에 공장을 방문합니다 - 일정 잡힘)

Are you attending the meeting?
(미팅에 참석하시나요? - 일정 확인)
```

## 📊 Will vs Be going to vs 현재진행형 비교

| Will | Be going to | 현재진행형 |
|------|------------|----------|
| 즉석 결정 | 계획/의도 | 확정된 일정 |
| 예측 (생각) | 예측 (증거) | 약속/예약 |
| 약속/의지 | - | - |
| **I'll call you** | **I'm going to call you** | **I'm calling you at 3pm** |
| (지금 결정) | (이미 계획) | (3시 약속 잡힘) |

### 예시로 비교
```
상황: 전화벨이 울림
Will: I'll answer it. (지금 막 결정)

상황: 미리 계획
Be going to: I'm going to visit the client. (이미 계획함)

상황: 약속 잡힘
현재진행형: I'm visiting the client at 2pm. (2시 약속)
```

## 💼 비즈니스 상황별 미래형 사용

### 1. 이메일에서 약속
```
I will send you the document by tomorrow.
(내일까지 문서를 보내드리겠습니다)

We will get back to you within 24 hours.
(24시간 내에 연락드리겠습니다)
```

### 2. 회의에서 계획 발표
```
We are going to implement a new system.
(새로운 시스템을 도입할 예정입니다)

The company is going to open 5 new branches.
(회사가 5개의 새 지점을 열 예정입니다)
```

### 3. 일정 조율
```
I'm meeting a client at 10am.
(10시에 고객을 만나요)

We are having a team building event next Friday.
(다음 주 금요일에 팀빌딩 행사가 있어요)
```

### 4. 예측 표현
```
I think the sales will increase.
(매출이 증가할 것 같아요 - will)

Look at the data. Sales are going to increase.
(데이터를 보세요. 매출이 증가할 거예요 - be going to)
```

## 🔑 미래를 나타내는 시간 표현

```
tomorrow (내일)
next week/month/year (다음 주/달/해)
in 2 days/3 weeks/5 years (2일/3주/5년 후)
soon (곧)
later (나중에)
in the future (미래에)
this afternoon/evening (오늘 오후/저녁)
by Friday (금요일까지)
```

## 💬 대화 예시

### 예시 1: 일정 조율
```
A: What are you doing tomorrow?
   (내일 뭐 해?)

B: I'm meeting a supplier at 10, and then I'm having lunch with the team.
   (10시에 공급업체 만나고, 그 다음에 팀이랑 점심 먹어.)

A: Okay. I'll schedule our meeting for 2pm then.
   (알았어. 그럼 우리 미팅은 2시로 잡을게.)
```

### 예시 2: 프로젝트 계획
```
Manager: What are your plans for next quarter?
        (다음 분기 계획이 뭐예요?)

Employee: We are going to focus on digital marketing.
         (디지털 마케팅에 집중할 예정입니다.)

Manager: Good. I think it will bring great results.
        (좋아요. 좋은 결과가 나올 것 같아요.)
```

### 예시 3: 즉석 제안
```
A: I need to send this package.
   (이 소포를 보내야 해.)

B: I'll go to the post office this afternoon. I can send it for you.
   (오늘 오후에 우체국 갈 거야. 대신 보내줄게.)

A: Really? Thanks! I'm meeting a client at that time.
   (정말? 고마워! 그 시간에 고객 만나거든.)
```

### 예시 4: 문제 해결
```
A: The system is not working.
   (시스템이 작동하지 않아요.)

B: Don't worry. I'll call IT support right now.
   (걱정 마세요. 지금 IT 지원팀에 전화할게요.)

A: Thanks. When are they going to fix it?
   (고마워요. 언제 고칠 건가요?)

B: They are coming at 2pm.
   (2시에 온대요.)
```

## ⚠️ 주의사항

### 1. 시간/조건 부사절에서는 will 사용 안 함
```
❌ When he will arrive, call me.
✅ When he arrives, call me.
(그가 도착하면 전화해)

❌ If it will rain, we will cancel.
✅ If it rains, we will cancel.
(비가 오면 취소할 거예요)
```

**시간/조건 접속사**: when, if, before, after, as soon as, unless 등
→ 이런 절에서는 미래여도 **현재형** 사용!

### 2. 혼동하기 쉬운 표현
```
I'm going to go (X - 어색하지만 문법적으로 가능)
I'm going (O - 더 자연스러움)

I will go = I'm going to go = I'm going
(모두 "갈 거예요"라는 뜻이지만 뉘앙스 다름)
```

### 3. will의 축약형
```
I will → I'll
You will → You'll
He will → He'll
She will → She'll
We will → We'll
They will → They'll

will not → won't
```

## ✍️ 연습 문제

### 문제 1: will / be going to / 현재진행형 중 선택
1. A: Why are you holding a camera?
   B: I __________ (take) photos of the office.

2. A: We need more chairs.
   B: I __________ (get) some from the other room.

3. Look at the sky! It __________ (rain).

4. I __________ (meet) the client at 3pm tomorrow. (일정 확정)

5. I think the economy __________ (improve) next year.

### 문제 2: 빈칸 채우기 (적절한 형태)
1. We __________ (launch) the new product next month. (계획)
2. She __________ (not/attend) the meeting. She's on a business trip. (확정 일정)
3. __________ you __________ (join) us for lunch? (즉석 제안)
4. The company __________ (hire) 50 people this year. (계획)
5. I __________ (send) you the file right now. (즉석 결정)

### 문제 3: 틀린 부분 찾아 고치기
1. When I will finish, I will call you.
2. If you will need help, let me know.
3. I will to send the email tomorrow.
4. She is go to attend the conference.
5. We will meeting at 10am tomorrow.

## 📚 정답

### 문제 1
1. I'm going to take (이미 카메라를 들고 있음 - 계획/의도)
2. I'll get (지금 막 결정)
3. It's going to rain (하늘을 보면 알 수 있음 - 증거 있는 예측)
4. I'm meeting (3시 약속 - 확정 일정)
5. will improve (생각/예측 - I think와 함께)

### 문제 2
1. are going to launch (계획)
2. isn't attending / is not attending (확정 일정)
3. Will, join (즉석 제안)
4. is going to hire (계획)
5. will send / 'll send (즉석 결정)

### 문제 3
1. When I finish (시간 부사절에서는 현재형)
2. If you need help (조건 부사절에서는 현재형)
3. I will send (will 뒤에는 동사원형, to 불필요)
4. She is going to attend (be going to 형태)
5. We will meet / We are meeting (will 뒤 동사원형 or 현재진행형)
