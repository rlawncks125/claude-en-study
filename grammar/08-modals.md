# 조동사 (Modal Verbs)

## 📖 개념

조동사는 **가능성, 능력, 허가, 의무, 제안** 등을 표현하는 동사입니다.

**특징:**
- 조동사 뒤에는 항상 **동사원형**
- 주어에 관계없이 형태 동일 (3인칭 단수 -s 없음)
- 부정문: 조동사 + not
- 의문문: 조동사를 앞으로

---

## 📊 주요 조동사

### Can / Could

#### Can (능력, 가능성, 허가)

**1. 능력 (~할 수 있다)**
```
I can speak English.
(영어를 할 수 있다)

She can code in Python.
(파이썬으로 코딩할 수 있다)

They can finish by Friday.
(금요일까지 끝낼 수 있다)
```

**2. 허가 요청 (비격식)**
```
Can I leave early today?
(오늘 일찍 퇴근해도 될까요?)

Can we use this meeting room?
(이 회의실 써도 될까요?)
```

**3. 제안**
```
We can meet at 3 PM.
(3시에 만날 수 있어요)
```

#### Could (can의 과거형, 공손한 요청)

**1. 과거의 능력**
```
I could speak French when I was young.
(어렸을 때 프랑스어를 할 수 있었다)
```

**2. 공손한 요청 (can보다 정중)**
```
Could you send me the file?
(파일 보내주시겠어요?)

Could I have a moment?
(잠깐 시간 좀 내주시겠어요?)
```

**3. 가능성 (추측)**
```
It could be a good opportunity.
(좋은 기회일 수 있어요)
```

---

### Will / Would

#### Will (미래, 의지)

**1. 미래**
```
I will finish it tomorrow.
(내일 끝낼 거예요)

The meeting will start at 2.
(미팅은 2시에 시작할 거예요)
```

**2. 의지, 약속**
```
I will help you.
(도와드릴게요)

We will deliver by Friday.
(금요일까지 배송할게요)
```

#### Would (will의 과거형, 공손한 표현)

**1. 공손한 요청**
```
Would you send me the report?
(보고서 보내주시겠어요?)

I would like to schedule a meeting.
(미팅을 잡고 싶습니다)
```

**2. 과거의 습관 (used to와 유사)**
```
I would work late every day.
(매일 늦게까지 일하곤 했다)
```

---

### Should / Must / Have to

#### Should (~해야 한다, 권고)

**조언, 권고:**
```
You should check your email.
(이메일 확인해야 해요)

We should finish this by Friday.
(금요일까지 이걸 끝내야 해요)

You shouldn't skip the meeting.
(미팅 빠지면 안 돼요)
```

#### Must (~해야 한다, 강한 의무)

**1. 강한 의무/필수**
```
You must submit the report by 5 PM.
(오후 5시까지 보고서를 제출해야 합니다)

All employees must attend the training.
(모든 직원이 교육에 참석해야 합니다)
```

**2. 강한 추측 (~임에 틀림없다)**
```
He must be busy.
(그는 바쁜 게 틀림없다)
```

#### Have to (~해야 한다, 외부 의무)

**외부 규칙/상황에 의한 의무:**
```
I have to finish this today.
(오늘 이걸 끝내야 해요)

She has to attend the meeting.
(그녀는 미팅에 참석해야 해요)

We don't have to work on weekends.
(주말에 일할 필요 없어요)
```

**Must vs Have to:**
- Must: 화자의 의견/규칙 (주관적)
- Have to: 외부 상황/규칙 (객관적)

---

### May / Might

#### May (허가, 가능성)

**1. 공손한 허가 요청 (격식)**
```
May I ask a question?
(질문해도 될까요?)

May I use your phone?
(전화 좀 써도 될까요?)
```

**2. 가능성 (50%)**
```
It may rain tomorrow.
(내일 비가 올 수도 있어요)

She may be late.
(그녀가 늦을 수도 있어요)
```

#### Might (may보다 약한 가능성)

**가능성 (30-40%)**
```
I might go to the conference.
(컨퍼런스에 갈지도 몰라요)

It might take longer.
(더 걸릴 수도 있어요)
```

## 📝 문장 구조

### 평서문
```
주어 + 조동사 + 동사원형

I can help you.
She should check it.
We will finish soon.
```

### 부정문
```
주어 + 조동사 + not + 동사원형

I can't attend.
She shouldn't worry.
We won't be late.

축약형:
can't, couldn't, won't, wouldn't
shouldn't, mustn't, mightn't
```

### 의문문
```
조동사 + 주어 + 동사원형?

Can you help me?
Should I call him?
Will they come?
```

## 🎯 비즈니스 표현

### 요청 (공손한 순서)
```
격식도 낮음: Can you ~?
중간: Could you ~?
격식도 높음: Would you ~?

Can you send me the file?
Could you review this document?
Would you be able to join the meeting?
```

### 제안
```
We can discuss this tomorrow.
We could try a different approach.
Should we schedule a follow-up?
```

### 허가
```
Can I leave early?
May I ask a question?
Could I take a day off?
```

## ⚠️ 주의사항

### 1. 조동사 뒤는 항상 동사원형
```
❌ I can helps you.
✅ I can help you.

❌ She should checks it.
✅ She should check it.
```

### 2. 조동사는 중복 불가
```
❌ I will can do it.
✅ I will be able to do it.

❌ You must should go.
✅ You should go. / You must go.
```

### 3. Must vs Have to 부정문
```
mustn't = 금지 (~하면 안 된다)
You mustn't smoke here.
(여기서 담배 피우면 안 돼요)

don't have to = 필요 없음 (~할 필요 없다)
You don't have to come early.
(일찍 올 필요 없어요)
```

## 🎯 실전 대화

### 업무 요청
```
A: Could you review my presentation?
B: Sure, I can do that this afternoon.

A: Would you be able to join the call?
B: Yes, I should be available.
```

### 일정 조율
```
A: Can we meet tomorrow?
B: I might have another meeting. Could we do Wednesday?
A: Yes, that would work.
```

## ✏️ 연습 문제

### 문제 1: 알맞은 조동사 선택
1. I _____ speak Korean. (능력)
2. _____ you help me? (공손한 요청)
3. You _____ submit it by Friday. (강한 의무)
4. We _____ meet tomorrow. (미래)
5. It _____ rain later. (가능성)

### 문제 2: 부정문 만들기
1. I can attend. → _____
2. She should go. → _____
3. They will come. → _____

### 문제 3: 의문문 만들기
1. You can help. → _____
2. I should call. → _____
3. They will attend. → _____

---

## 📌 정답

### 문제 1
1. can
2. Could/Would
3. must/should
4. will/can
5. may/might

### 문제 2
1. I can't attend. / I cannot attend.
2. She shouldn't go.
3. They won't come. / They will not come.

### 문제 3
1. Can you help?
2. Should I call?
3. Will they attend?
