# 진행형 (Progressive Tenses)

## 📖 개념

진행형은 **진행 중인 동작**을 표현할 때 사용합니다.

**기본 구조:** be동사 + 동사ing

---

## 📊 진행형 종류

### 현재진행형 (Present Progressive)

```
am/is/are + 동사ing

I am working. (지금 일하는 중이다)
She is studying. (공부하는 중이다)
They are meeting. (미팅 중이다)
```

### 과거진행형 (Past Progressive)

```
was/were + 동사ing

I was working. (일하는 중이었다)
She was studying. (공부하는 중이었다)
They were meeting. (미팅 중이었다)
```

---

## 💡 동사-ing 만들기

### 규칙

| 동사 끝 | 변화 | 예시 |
|---------|------|------|
| 일반 | +ing | work → working, study → studying |
| -e | e 탈락 + ing | make → making, write → writing |
| -ie | ie → ying | lie → lying, die → dying |
| 단모음+단자음 | 자음 중복 + ing | run → running, sit → sitting |

**예시:**
```
work → working
make → making
run → running
study → studying
write → writing
sit → sitting
```

---

## 💡 현재진행형 사용법

### 1. 지금 진행 중인 동작
```
I'm working on a project right now.
(지금 프로젝트 작업 중이다)

She's attending a meeting.
(미팅 참석 중이다)

They're discussing the proposal.
(제안서를 논의하는 중이다)
```

### 2. 임시적인 상황
```
I'm working from home this week.
(이번 주는 재택근무 중이다)

She's using my laptop.
(그녀가 내 노트북을 쓰고 있다)
```

### 3. 가까운 미래 계획
```
I'm meeting the client tomorrow.
(내일 고객을 만날 예정이다)

We're launching the product next week.
(다음 주에 제품을 출시할 예정이다)
```

---

## 📝 문장 구조

### 평서문
```
주어 + am/is/are + 동사ing

I'm working.
She's studying.
They're meeting.
```

### 부정문
```
주어 + am/is/are + not + 동사ing

I'm not working.
She isn't studying. / She's not studying.
They aren't meeting. / They're not meeting.
```

### 의문문
```
Am/Is/Are + 주어 + 동사ing?

Are you working?
Is she studying?
Are they meeting?
```

## 🎯 현재 vs 현재진행형

### 현재 시제 (습관, 반복)
```
I work from 9 to 6. (일반적 사실)
She studies English every day. (습관)
```

### 현재진행형 (지금, 임시)
```
I'm working on a report. (지금 하는 중)
She's studying for the exam. (현재 진행 중)
```

### 비교
```
일반적: I work at Samsung.
(삼성에서 일한다 - 직장)

현재: I'm working on a new project.
(새 프로젝트 작업 중이다 - 지금)
```

---

## ⚠️ 진행형을 안 쓰는 동사

### 상태 동사 (Stative Verbs)

진행형으로 쓰지 않는 동사들:

**감정:**
- love, like, hate, want, need, prefer

**사고:**
- know, understand, believe, think (의견), remember, forget

**소유:**
- have (소유), own, belong, possess

**감각:**
- see, hear, smell, taste (인식)

**기타:**
- be, seem, appear, cost, contain

```
❌ I'm knowing the answer.
✅ I know the answer.

❌ She's having a car.
✅ She has a car.

❌ I'm understanding it.
✅ I understand it.
```

**예외:**
```
have (경험) - I'm having a meeting. ✅
think (생각하는 중) - I'm thinking about it. ✅
see (만나다) - I'm seeing him tomorrow. ✅
```

## 🎯 실전 예문

### 업무 상황
```
A: What are you doing?
B: I'm working on the quarterly report.

A: Is she available?
B: No, she's attending a meeting right now.

A: Are they coming to the presentation?
B: Yes, they're joining via Zoom.
```

### 임시 상황
```
I'm working from home this week.
(이번 주는 재택근무 중)

She's covering for me while I'm on vacation.
(내가 휴가 중일 때 그녀가 대신한다)

We're using a temporary office.
(임시 사무실을 쓰고 있다)
```

### 가까운 미래
```
I'm meeting the client at 3 PM.
We're launching the campaign next Monday.
They're presenting tomorrow.
```

---

## 🕐 시간 표현

현재진행형과 자주 쓰이는 표현:

```
now (지금)
right now (바로 지금)
at the moment (현재)
currently (현재)
these days (요즘)
this week/month (이번 주/월)
```

**예문:**
```
I'm working on it right now.
She's traveling a lot these days.
We're hiring new employees this month.
```

## ✏️ 연습 문제

### 문제 1: -ing 형태 만들기
1. work → _____
2. make → _____
3. run → _____
4. study → _____
5. write → _____

### 문제 2: 현재진행형 만들기
1. I (work) on a project. → I _____ on a project.
2. She (attend) a meeting. → She _____ a meeting.
3. They (discuss) the plan. → They _____ the plan.

### 문제 3: 부정문 만들기
1. I'm working. → _____
2. She's studying. → _____
3. They're meeting. → _____

### 문제 4: 의문문 만들기
1. You are working. → _____
2. He is coming. → _____
3. They are hiring. → _____

---

## 📌 정답

### 문제 1
1. working
2. making
3. running
4. studying
5. writing

### 문제 2
1. I am working (I'm working) on a project.
2. She is attending (She's attending) a meeting.
3. They are discussing (They're discussing) the plan.

### 문제 3
1. I'm not working.
2. She isn't studying. / She's not studying.
3. They aren't meeting. / They're not meeting.

### 문제 4
1. Are you working?
2. Is he coming?
3. Are they hiring?
