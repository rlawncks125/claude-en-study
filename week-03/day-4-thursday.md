## 1️⃣ Third Conditional (10분)

### 형태
```
If + 주어 + had + 과거분사, 주어 + would have + 과거분사
```

### 의미
**과거 사실과 반대 (후회, 비판)**

### 예시
```
If I had known, I would have helped.
(알았더라면 도왔을 텐데) → 실제로는 몰랐고 돕지 못함

If we had started earlier, we would have finished on time.
(더 일찍 시작했더라면 제시간에 끝냈을 텐데)

If they had invested in R&D, they wouldn't have failed.
(R&D에 투자했더라면 실패하지 않았을 텐데)
```

### 비즈니스 활용
```
✅ If we had launched earlier, we would have dominated the market.
✅ If I had prepared better, the presentation would have been successful.
✅ If we had hired more people, we would have completed faster.
```

## 2️⃣ 간접화법 기초 (15분)

### 기본 형태
```
직접화법: He said, "I am busy."
간접화법: He said (that) he was busy.
```

### 시제 변화
| 직접화법 | 간접화법 |
|---------|---------|
| 현재 (am/is/are) | 과거 (was/were) |
| 현재 (do/does) | 과거 (did) |
| 과거 (did) | 과거완료 (had done) |
| will | would |
| can | could |

### Say vs Tell vs Ask

**Say**: 사람 없이 또는 say to + 사람
```
He said (that) he was busy.
He said to me (that) he was busy.
```

**Tell**: tell + 사람 (필수)
```
He told me (that) he was busy.
```

**Ask**: 질문이나 요청
```
He asked if I was busy.
He asked me to help him.
```

## 3️⃣ 간접화법 유형별 (10분)

### 평서문
```
직접: "I am tired."
간접: He said (that) he was tired.
```

### Yes/No 질문
```
직접: "Are you busy?"
간접: He asked if I was busy.
```

### 의문사 질문
```
직접: "Where do you work?"
간접: He asked where I worked.

주의: 평서문 어순 (주어 + 동사)
```

### 명령문
```
직접: "Please help me."
간접: She asked me to help her.

직접: "Don't be late."
간접: He told me not to be late.
```

## 4️⃣ 비즈니스 활용 (5분)

### 회의록 작성
```
직접 대화:
CEO: "We need to increase sales."
Manager: "I will create a new plan."

회의록:
The CEO said that we needed to increase sales.
The manager said he would create a new plan.
```

### 이메일에서 대화 전달
```
✅ The client said they were satisfied with our service.
✅ The supplier told us they would deliver by Friday.
✅ My colleague asked if I could attend the meeting.
```

### 보고서에서 인용
```
✅ The survey showed that 80% of customers were satisfied.
✅ Experts suggested that we should invest in R&D.
✅ The analysis indicated that sales had increased by 20%.
```

## 5️⃣ 실전 대화 (5분)

### 대화: 회의 내용 전달
```
A: What did the manager say in the meeting?
   (미팅에서 매니저가 뭐라고 했어요?)

B: He said that we needed to finish the project by Friday.
   He also told us that the client was very important.
   He asked if we needed more resources.
   (금요일까지 프로젝트를 끝내야 한다고 말했어요.
   또한 고객이 매우 중요하다고 우리에게 말했어요.
   더 많은 자원이 필요한지 물었어요.)

A: What about the budget?
   (예산은요?)

B: He said it had been approved and that we could start
   immediately.
   (승인되었고 즉시 시작할 수 있다고 말했어요.)
```

## 6️⃣ 연습 문제 (5분)

### 문제 1: 3rd Conditional
1. If we _____ (start) earlier, we _____ (finish) on time.
2. If I _____ (know), I _____ (help) you.

### 문제 2: 간접화법으로 전환
1. She said, "I am working on a project."
   → She said _______________________________

2. He asked, "Are you busy?"
   → He asked _______________________________

3. She said, "Please send me the file."
   → She asked _______________________________

---

## 📝 정답

### 문제 1
1. had started, would have finished
2. had known, would have helped

### 문제 2
1. She said (that) she was working on a project.
2. He asked if I was busy.
3. She asked me to send her the file.
