## 2️⃣ 비즈니스 제안서 작성 (30분)

### 제안서 구조
```
Business Proposal

1. Executive Summary (요약)
2. Problem Statement (문제점)
3. Proposed Solution (해결책)
4. Benefits (이점)
5. Implementation Plan (실행 계획)
6. Budget & Timeline (예산 및 일정)
7. Conclusion (결론)
```

### 작성 과제 (300-500단어)

**주제 선택**:
- 신제품 출시 제안
- 새로운 마케팅 전략 제안
- 시스템 개선 제안
- 해외 시장 진출 제안

**필수 포함 사항**:
- [ ] 수동태 7개 이상
- [ ] 관계대명사 5개 이상
- [ ] 가정법 3개 이상 (1st/2nd)
- [ ] 간접화법 2개 이상
- [ ] 고급 비즈니스 표현 10개 이상

**작성 템플릿**:
```
Proposal for [제목]

Executive Summary
This proposal outlines a plan that has been developed to...
If implemented, this solution will...

Problem Statement
Currently, the company faces challenges that need to be
addressed. Research has shown that... According to the
data which was collected last month...

Proposed Solution
We propose a solution that will... The system which we
recommend is... If we adopt this approach, we will...

Benefits
The benefits that will be achieved include:
- Cost savings are expected to be 30%
- Efficiency will be improved by...
- If this is implemented successfully, revenue will...

Implementation Plan
The project will be completed in 3 phases...
Phase 1 will be finished by... The team whose expertise is
in this area will lead...

Budget & Timeline
The total budget that is required is... If approved, the
project will begin... The CEO said that funds have been
allocated...

Conclusion
In conclusion, this proposal offers... If we move forward,
significant benefits will be realized... We recommend that
this proposal be approved...
```

## 3️⃣ 제품 프레젠테이션 준비 (10분)

### 5분 프레젠테이션 스크립트 작성

**구조**:
1. Introduction (30초)
2. Product Overview (1분)
3. Key Features (2분)
4. Benefits & Results (1분)
5. Conclusion & Q&A (30초)

**작성 과제**:
```
Good morning, everyone. Today, I'd like to present...

The product which I'm going to introduce today has been
developed by our team. If you're looking for a solution
that can..., this is the product that meets your needs.

This product was launched last month and has already been
purchased by over 1,000 customers. According to the
feedback that we have received...

The key features include... The technology which was used
is the most advanced in the market. If you compare it with
competitors' products, you will see that...

The benefits that have been proven are... Sales data shows
that... If you implement this in your business, productivity
will increase by...

In conclusion, this is a product whose quality is guaranteed.
If you have any questions, I'd be happy to answer them.
Thank you.
```

## 4️⃣ 협상 시나리오 연습 (10분)

### 시나리오: 가격 협상

**상황**:
- 당신: 공급업체 영업 담당
- 상대: 고객 (대량 구매 원함)
- 목표: 최소 $80/unit에 판매

**대화 작성**:
```
Customer: We're interested in ordering 1,000 units.
         What price can you offer?

You: If you order 1,000 units, the price will be $90 per unit.
     This is a product that has been certified internationally.

Customer: That's higher than we expected. If we ordered 2,000
         units, could you reduce the price?

You: If you committed to 2,000 units, we could offer $85.
     The quality that you will receive is the best in the
     market. According to customers who have purchased from
     us, satisfaction rates are over 95%.

Customer: We need to think about it. If we signed a long-term
         contract, would that help?

You: Absolutely. If you agreed to a 2-year contract, we would
     be willing to discuss $80 per unit. The CEO said that
     we value long-term partnerships.

Customer: That sounds reasonable. Let us review the terms
         that were proposed.

You: Of course. I'll send you a proposal that outlines all
     the details. If you have any questions, please let me
     know.
```
