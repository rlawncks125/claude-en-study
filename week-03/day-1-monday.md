## 1️⃣ 수동태 핵심 개념 (10분)

### 능동태 vs 수동태

**능동태**: 주어가 동작을 함
```
The team completed the project.
(팀이 프로젝트를 완료했다)
```

**수동태**: 주어가 동작을 받음
```
The project was completed (by the team).
(프로젝트가 완료되었다)
```

### 수동태 형태
```
be동사 + 과거분사 (+ by 행위자)
```

### 비즈니스에서 수동태를 쓰는 이유
1. **객관성**: 더 전문적이고 격식 있게 들림
2. **결과 강조**: 누가 했는지보다 무엇이 되었는지가 중요
3. **행위자 불명확**: 누가 했는지 모르거나 중요하지 않음
4. **책임 회피**: 책임 소재를 모호하게

## 2️⃣ 시제별 수동태 (15분)

### 현재형
```
형태: am/is/are + 과거분사

This product is made in Korea.
(이 제품은 한국에서 만들어집니다)

English is spoken in many countries.
(영어는 많은 나라에서 사용됩니다)

Our services are provided 24/7.
(우리 서비스는 24시간 제공됩니다)
```

### 과거형
```
형태: was/were + 과거분사

The product was launched in 2020.
(제품이 2020년에 출시되었습니다)

The email was sent yesterday.
(이메일이 어제 발송되었습니다)

The documents were delivered on time.
(문서가 제시간에 전달되었습니다)
```

### 미래형
```
형태: will be + 과거분사

The meeting will be held next week.
(회의가 다음 주에 열릴 것입니다)

The results will be announced tomorrow.
(결과가 내일 발표될 것입니다)

The project will be completed by June.
(프로젝트가 6월까지 완료될 것입니다)
```

### 현재완료
```
형태: have/has been + 과거분사

The report has been finished.
(보고서가 완료되었습니다)

1,000 units have been sold.
(1,000개가 판매되었습니다)

The issue has been resolved.
(문제가 해결되었습니다)
```

### 진행형
```
형태: am/is/are being + 과거분사

The document is being reviewed.
(문서가 검토되고 있습니다)

The problem is being investigated.
(문제가 조사되고 있습니다)
```

### 조동사
```
형태: 조동사 + be + 과거분사

The data should be checked carefully.
(데이터가 신중하게 확인되어야 합니다)

The problem can be solved easily.
(문제가 쉽게 해결될 수 있습니다)

All employees must be trained.
(모든 직원이 교육을 받아야 합니다)
```

## 3️⃣ 비즈니스 상황별 수동태 (10분)

### 보고서 작성
```
✅ The report was prepared by our team.
✅ The data has been analyzed carefully.
✅ The following points should be considered.
✅ The project is expected to be completed by June.
```

### 회의/공지
```
✅ The meeting will be held on Monday at 10am.
✅ All employees are required to attend the training.
✅ The decision was made after careful consideration.
✅ The results will be announced next week.
```

### 제품/서비스 설명
```
✅ This product is made with high-quality materials.
✅ Our services are provided worldwide.
✅ The software has been downloaded over 1 million times.
✅ This feature is designed for business users.
```

### 절차/프로세스
```
✅ Applications should be submitted by Friday.
✅ The forms must be filled out completely.
✅ Payment can be made by credit card.
✅ The issue is being investigated.
```

## 4️⃣ 실전 대화 (5분)

### 대화: 프로젝트 상태 보고
```
Manager: What's the status of the project?
        (프로젝트 상태가 어떻게 되나요?)

Employee: The design phase has been completed, and
         the development is being done by the IT team.
         The product will be tested next week, and
         it is expected to be launched in March.
         (디자인 단계가 완료되었고, 개발이 IT 팀에 의해
         진행되고 있습니다. 제품은 다음 주에 테스트될
         것이고, 3월에 출시될 것으로 예상됩니다.)

Manager: Has the budget been approved?
        (예산이 승인되었나요?)

Employee: Yes, it was approved last week. All resources
         have been allocated, and the team has been notified.
         (네, 지난주에 승인되었습니다. 모든 자원이
         할당되었고, 팀에게 통보되었습니다.)
```

## 5️⃣ 연습 문제 (5분)

### 문제 1: 능동태를 수동태로
1. The team completed the project.
   → The project __________

2. We will announce the results tomorrow.
   → The results __________

3. Someone has sent the invitation.
   → The invitation __________

4. They are reviewing the application.
   → The application __________

5. You should check the document.
   → The document __________

### 문제 2: 적절한 형태 쓰기
1. This software __________ (use) by millions of people.
2. The meeting __________ (hold) on Monday.
3. The issue __________ (investigate) right now.
4. The product __________ (launch) last year.
5. All employees __________ (require) to attend.

---

## 📝 정답

### 문제 1
1. was completed (by the team)
2. will be announced tomorrow
3. has been sent
4. is being reviewed
5. should be checked

### 문제 2
1. is used
2. will be held
3. is being investigated
4. was launched
5. are required
