## 📝 Part 1: 필기 테스트 (30점, 45분)

### Section A: 수동태 (8점, 10분)

**문제 1-4: 적절한 형태로 바꾸기 (각 2점)**
```
1. The company _____ (launch) the product in 2020.
   → The product _____________________________

2. We _____ (hold) the meeting next Monday.
   → The meeting _____________________________

3. Someone _____ (already/send) the invitation.
   → The invitation _____________________________

4. You _____ (should/check) the data carefully.
   → The data _____________________________
```

---

### Section B: 관계대명사 (8점, 10분)

**문제 5-8: 두 문장을 하나로 연결 (각 2점)**
```
5. The manager works here. He is very experienced.
   → _____________________________

6. The product won an award. We launched it last year.
   → _____________________________

7. I know a person. His company is very successful.
   → _____________________________

8. This is the office. I work here.
   → _____________________________
```

---

### Section C: 가정법 (8점, 15분)

**문제 9-11: 적절한 형태로 완성 (각 2점)**
```
9. If you _____ (order) 100 units, we _____ (give) a discount. (1st)

10. If I _____ (be) the CEO, I _____ (change) the policy. (2nd)

11. If we _____ (invest) more, we _____ (succeed). (3rd)
```

**문제 12: 3가지 가정법 구분 (2점)**
```
다음 중 2nd Conditional은?
a) If it rains, I will stay home.
b) If it rained, I would stay home.
c) If it had rained, I would have stayed home.
```

---

### Section D: 간접화법 (6점, 10분)

```

    → _____________________________

    → _____________________________
```

## 🎯 Part 2: 실전 프로젝트 (30점, 35분)

### Project 1: 비즈니스 제안서 (15점, 20분)

**과제**: 다음 중 하나의 주제로 비즈니스 제안서 작성 (300-500단어)
- 신제품 출시 제안
- 새로운 마케팅 전략
- 시스템 개선 방안

**필수 포함**:
- [ ] 수동태 7개 이상 (3점)
- [ ] 관계대명사 5개 이상 (3점)
- [ ] 가정법 3개 이상 (3점)
- [ ] 간접화법 2개 이상 (2점)
- [ ] 논리적 구조와 전문적 어조 (4점)

**평가 기준**:
- 문법 정확성 (9점)
- 내용 완성도 (4점)
- 전문성 (2점)

---

### Project 2: 제품 프레젠테이션 (10점, 10분)

**과제**: 제품/서비스 소개 프레젠테이션 스크립트 (200-300단어)

**구조**:
1. Introduction
2. Product Overview
3. Key Features
4. Benefits
5. Conclusion

**필수 포함**:
- [ ] 수동태 4개 이상
- [ ] 관계대명사 3개 이상
- [ ] 비교급/최상급 2개 이상
- [ ] 전문적인 프레젠테이션 표현

**평가 기준**:
- 문법 정확성 (5점)
- 설득력 (3점)
- 구조 (2점)

---

### Project 3: 회의록 작성 (5점, 5분)

**상황**: 다음 회의 내용을 간접화법으로 회의록 작성

**회의 내용**:
```
CEO: "We need to increase market share by 20%."
Marketing Manager: "I will develop a new campaign."
Sales Manager: "Can we get more budget for advertising?"
CEO: "The budget has been approved. Let's start next week."
```

**회의록 작성**:
```
Meeting Minutes
Date: ___________
Attendees: CEO, Marketing Manager, Sales Manager

Summary:
_____________________________
_____________________________
_____________________________
```

**평가 기준**:
- 간접화법 정확성 (3점)
- 완성도 (2점)
