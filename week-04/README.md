# Week 4: 실전 비즈니스 영어 (Professional Business English in Practice)

## 📚 이번 주 학습 목표

Week 1-3에서 배운 모든 문법과 표현을 실제 비즈니스 상황에 적용합니다.
**새로운 문법이 아닌 실전 응용**에 집중합니다.

### 주요 학습 내용
1. **고급 이메일 작성**: 다양한 비즈니스 이메일 완벽하게 쓰기
2. **전화 및 화상회의**: 전화 영어와 온라인 미팅 마스터
3. **비즈니스 미팅**: 회의 진행, 참여, 의견 표현
4. **프레젠테이션 마스터**: 설득력 있는 발표 기법
5. **협상 및 설득**: 전문적인 협상 스킬
6. **네트워킹 및 스몰톡**: 비즈니스 관계 구축
7. **종합 실전 프로젝트**: 실제 업무 시뮬레이션

### 실전 프로젝트
- 비즈니스 이메일 10종 작성
- 전화 영어 시나리오 5개
- 프레젠테이션 완성본 (10분)
- 협상 롤플레이
- 네트워킹 이벤트 시뮬레이션

## 📖 Week 4 특징

### Week 1-3과의 차이점
- **문법 학습 X**: 새로운 문법 배우지 않음
- **실전 응용 O**: 배운 내용을 실제 상황에 적용
- **프로젝트 중심**: 매일 실전 프로젝트 수행
- **시나리오 기반**: 실제 업무 상황 시뮬레이션
- **통합 연습**: 모든 문법과 표현 종합 활용

### Week 4에서 사용할 모든 문법
```
✓ Week 1: Be동사, 현재/과거형, 진행형, 조동사
✓ Week 2: 현재완료, 미래형, 비교급, 전치사, 접속사
✓ Week 3: 수동태, 관계대명사, 가정법, 간접화법

→ Week 4: 위의 모든 문법을 실전에서 자유롭게 사용!
```

## 📈 진행 방법

1. **매일 학습** (월-금 50분, 토 90분, 일 100분)
2. **실전 프로젝트**: 매일 실제 비즈니스 문서/대화 작성
3. **녹음 연습**: 대화 및 프레젠테이션 녹음해보기 (선택)
4. **피드백**: 작성한 내용을 스스로 검토하고 개선
5. **반복 연습**: 같은 시나리오를 여러 번 연습
