## 1️⃣ 통합 시나리오 1: 신규 거래처 개척 (30분)

### 상황 설정
```
당신은 IT 솔루션 회사의 영업 담당자입니다.
목표: 잠재 고객사와 첫 미팅 → 제안서 제출 → 계약 성사

단계:
1. 첫 연락 이메일 작성
2. 전화로 미팅 일정 조율
3. 회의에서 제품 프레젠테이션
4. 가격 협상
5. 계약 확정 이메일
```

### Task 1: 첫 연락 이메일 (150단어)
```
받는 사람: ABC Corporation 구매팀장
목적: 회사 소개 및 미팅 제안
포함 사항:
- 간단한 회사 소개
- 귀사에 도움이 될 수 있는 솔루션 언급
- 구체적인 미팅 제안 (3가지 날짜 옵션)
```

### Task 2: 전화 대화 스크립트 (200단어)
```
상황: 구매팀장과 통화
- 자기소개
- 이메일 후속 조치
- 미팅 일정 확정
- 회의 안건 확인
- 필요한 준비 사항 논의
```

### Task 3: 5분 프레젠테이션 스크립트 (400단어)
```
구조:
1. Opening (30초)
   - 인사 및 감사
   - 아이스브레이커

2. 문제 제기 (1분)
   - 업계 현황 및 과제
   - 구체적인 pain points

3. 솔루션 제시 (2분)
   - 제품/서비스 소개
   - 핵심 기능 3가지
   - 차별화 요소

4. 실적/사례 (1분)
   - 수치로 증명된 결과
   - 유사 고객 사례

5. 행동 촉구 (30초)
   - Next steps 제안
   - 질문 유도
```

### Task 4: 협상 대화 (250단어)
```
고객 요구사항:
- 정가 $50,000 → $40,000 요청
- 6개월 무료 지원 요청
- 3개월 결제 조건 요청

당신의 협상 범위:
- 최저가: $45,000 (1년 계약 시)
- 무료 지원: 3개월까지 가능
- 결제 조건: 60일까지 가능

대화 스크립트 작성 (10-12 왕복)
```

---

## 2️⃣ 통합 시나리오 2: 고객 불만 처리 (25분)

### 상황 설정
```
고객이 제품 불량으로 불만 제기
- 납품된 제품 100개 중 15개 불량
- 고객사 생산 라인 지연 발생
- 즉각적인 해결 요구
- 보상 요구
```

### Task 1: 사과 및 해결 방안 이메일 (200단어)
```
포함 사항:
- 진심어린 사과
- 원인 설명 (간략히)
- 즉각적인 조치 사항
  * 불량품 교체 일정
  * 추가 보상 제안
- 재발 방지 대책
- 후속 조치 계획
```

### Task 2: 전화 통화 스크립트 (200단어)
```
상황: 화난 고객과 통화
- 고객 불만 경청
- 공감 표현
- 해결 방안 제시
- 고객 동의 확보
- 관계 회복 노력
```

### Task 3: 회의록 작성 (150단어)
```
Meeting: 불량 사고 대응 내부 회의
참석자: 품질팀장, 영업팀장, 생산팀장
안건:
1. 사고 원인 분석
2. 고객 보상 방안
3. 재발 방지 대책
4. 액션 아이템
```

---

## 3️⃣ 통합 시나리오 3: 화상 컨퍼런스 (20분)

### 상황 설정
```
국제 파트너사와 분기 리뷰 미팅
참석자:
- 당신 (한국 본사 - 프로젝트 매니저)
- 미국 파트너 (Sales Director)
- 일본 파트너 (Product Manager)
- 싱가포르 파트너 (Marketing Manager)

안건:
1. Q2 실적 리뷰
2. Q3 목표 및 전략
3. 신제품 론칭 계획
4. 마케팅 협업 방안
```

### Task 1: 회의 주최 (당신이 진행자)
```
스크립트 작성 (500단어):

1. Opening (2분)
   - 환영 인사
   - 기술 체크
   - 안건 소개

2. Q2 리뷰 (5분)
   - 주요 성과 발표
   - 각 지역 파트너 의견 청취
   - 과제 논의

3. Q3 전략 (5분)
   - 목표 제시
   - 전략 설명
   - 역할 분담 논의

4. 신제품 론칭 (5분)
   - 제품 소개
   - 론칭 일정
   - 지역별 전략

5. 마케팅 협업 (3분)
   - 협업 아이디어
   - 예산 논의
   - 타임라인

6. Closing (2분)
   - 요약
   - 액션 아이템
   - 다음 미팅 일정
```

## 4️⃣ 자가 평가 (15분)

### Week 4 스킬 체크리스트

#### 이메일 작성 능력
```
✅ 10가지 이메일 유형을 구분하여 작성할 수 있다
✅ 상황에 맞는 적절한 어조를 사용할 수 있다
✅ 명확한 구조로 이메일을 작성할 수 있다
✅ 전문적인 표현을 자연스럽게 사용할 수 있다
```

#### 전화/화상회의 능력
```
✅ 전화로 자신있게 소통할 수 있다
✅ 메시지를 명확하게 전달하고 받을 수 있다
✅ 화상회의를 효과적으로 진행할 수 있다
✅ 기술적 문제에 대처할 수 있다
```

#### 회의 진행 능력
```
✅ 회의를 체계적으로 진행할 수 있다
✅ 의견을 명확하게 표현할 수 있다
✅ 다른 사람의 의견을 경청하고 반응할 수 있다
✅ 회의록을 작성할 수 있다
```

#### 프레젠테이션 능력
```
✅ 설득력 있는 프레젠테이션을 구성할 수 있다
✅ 청중을 참여시킬 수 있다
✅ 시각 자료를 효과적으로 활용할 수 있다
✅ 질문에 적절하게 대응할 수 있다
```

#### 협상 및 네트워킹 능력
```
✅ 협상을 전략적으로 진행할 수 있다
✅ Win-Win 솔루션을 찾을 수 있다
✅ 네트워킹에서 자신감 있게 소통할 수 있다
✅ 비즈니스 관계를 구축할 수 있다
```
