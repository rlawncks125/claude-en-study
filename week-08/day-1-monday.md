## 🌍 Hofstede's 6 Cultural Dimensions

### Overview
Geert Hofstede's research identified six dimensions that explain cultural differences across nations. Understanding these helps navigate international business.

### 1. Power Distance Index (PDI) - 권력 거리 지수

**Definition:** The extent to which less powerful members accept unequal power distribution.

**High Power Distance Cultures:**
```
Examples: Malaysia, India, China, Arab countries, Latin America
Characteristics:
✓ Hierarchical organizations
✓ Centralized decision-making
✓ Formal titles and respect for authority
✓ Top-down communication
✓ Age and position determine respect
```

**Low Power Distance Cultures:**
```
Examples: Denmark, Austria, Israel, Nordic countries
Characteristics:
✓ Flat organizational structures
✓ Participative management
✓ Informal communication
✓ Accessibility to leadership
✓ Merit-based respect
```

**Business Communication Implications:**

**High PDI Communication:**
```
"Mr. Chairman, with your permission, I'd like to present..."
"Our esteemed director has decided that..."
"We await your wise guidance on this matter."
[Wait for senior person to speak first]
```

**Low PDI Communication:**
```
"Hi everyone, let's dive into this..."
"What do you all think about this approach?"
"I disagree with that strategy because..."
[Open debate regardless of hierarchy]
```

### 2. Individualism vs. Collectivism (IDV)

**Individualistic Cultures:**
```
Examples: USA, UK, Australia, Netherlands, Canada
Values:
✓ Personal achievement
✓ Individual rights and privacy
✓ Self-reliance
✓ Direct communication
✓ "I" orientation
```

**Collectivist Cultures:**
```
Examples: China, Korea, Japan, Indonesia, Colombia
Values:
✓ Group harmony
✓ Family/group loyalty
✓ Interdependence
✓ Indirect communication
✓ "We" orientation
```

**Communication Differences:**

**Individualistic:**
```
"I accomplished this project ahead of schedule."
"My opinion is that we should..."
"I need to prioritize my career goals."
"Let's be direct - this isn't working."
```

**Collectivistic:**
```
"Our team successfully completed this project."
"We believe that the consensus is..."
"We must consider what's best for the company."
"Perhaps we might consider other approaches..." [Indirect]
```

### 3. Masculinity vs. Femininity (MAS)

**Masculine Cultures:**
```
Examples: Japan, Germany, USA, Italy, Mexico
Focus:
✓ Achievement and success
✓ Competition
✓ Assertiveness
✓ Material rewards
✓ Clear gender roles
```

**Feminine Cultures:**
```
Examples: Sweden, Norway, Denmark, Netherlands
Focus:
✓ Quality of life
✓ Cooperation
✓ Modesty
✓ Work-life balance
✓ Fluid gender roles
```

**Business Language:**

**Masculine:**
```
"We'll dominate the market."
"Win at all costs."
"Be the best or nothing."
"Aggressive growth strategy."
```

**Feminine:**
```
"We'll create sustainable partnerships."
"Collaborative approach to growth."
"Balanced and inclusive strategy."
"Focus on employee well-being."
```

### 4. Uncertainty Avoidance Index (UAI) - 불확실성 회피

**High Uncertainty Avoidance:**
```
Examples: Greece, Portugal, Belgium, Japan, France
Characteristics:
✓ Detailed planning required
✓ Strict rules and procedures
✓ Low tolerance for ambiguity
✓ Risk-averse
✓ Need for structure
```

**Low Uncertainty Avoidance:**
```
Examples: Singapore, Denmark, UK, USA, China
Characteristics:
✓ Flexible and adaptive
✓ Comfortable with ambiguity
✓ Risk-taking encouraged
✓ Minimal rules
✓ Innovation-friendly
```

**Meeting Communication:**

**High UAI:**
```
"Please refer to section 3.2.1 of the protocol document."
"We need detailed risk analysis before proceeding."
"This must be approved by the compliance committee."
"Let's follow the established procedure exactly."
```

**Low UAI:**
```
"Let's experiment and see what works."
"We can figure it out as we go."
"Trust your judgment on this."
"Be flexible and adapt quickly."
```

### 5. Long-Term vs. Short-Term Orientation (LTO)

**Long-Term Orientation:**
```
Examples: China, Japan, South Korea, Taiwan
Focus:
✓ Future rewards
✓ Persistence and perseverance
✓ Thrift and saving
✓ Adaptation to circumstances
✓ Building relationships
```

**Short-Term Orientation:**
```
Examples: USA, Nigeria, Pakistan, Spain
Focus:
✓ Immediate results
✓ Tradition and social obligations
✓ Quick profits
✓ Maintaining "face"
✓ Absolute truths
```

**Business Discussions:**

**Long-Term:**
```
"Let's invest in building relationships first."
"This partnership will benefit us in 10 years."
"Short-term losses for long-term gains."
"We're playing the long game."
```

**Short-Term:**
```
"What are this quarter's results?"
"We need immediate ROI."
"Quick wins are essential."
"Let's close this deal now."
```

### 6. Indulgence vs. Restraint (IVR)

**Indulgent Cultures:**
```
Examples: Mexico, Venezuela, USA, Australia
Values:
✓ Enjoying life and having fun
✓ Leisure time important
✓ Spending freely
✓ Positive emotions expressed
✓ Work to live
```

**Restrained Cultures:**
```
Examples: Russia, China, India, Baltic states
Values:
✓ Self-control and discipline
✓ Work before pleasure
✓ Saving and frugality
✓ Suppressed emotions
✓ Live to work
```

## 🎯 High-Context vs. Low-Context Communication

### Edward T. Hall's Context Theory

**High-Context Cultures** (간접적 소통 문화)
```
Examples: Japan, Korea, China, Arab countries, Mediterranean

Characteristics:
✓ Implicit communication
✓ Reading between the lines
✓ Context is everything
✓ Relationship-focused
✓ Indirect rejection
✓ Silence is meaningful
✓ Nonverbal cues critical
```

**High-Context Communication Examples:**
```
Saying "That might be difficult" means "No, impossible"
"I'll consider it" means "Not interested"
"We'll do our best" means "We can't promise"
Silence after proposal = Rejection
"Perhaps" or "Maybe" often means "No"
```

**Low-Context Cultures** (직접적 소통 문화)
```
Examples: USA, Germany, UK, Scandinavia, Canada

Characteristics:
✓ Explicit communication
✓ Direct and clear
✓ Words matter most
✓ Task-focused
✓ Direct rejection acceptable
✓ Silence is awkward
✓ Verbal clarity crucial
```

**Low-Context Communication Examples:**
```
"No, that won't work" means exactly that
"Yes" means yes, "No" means no
"I disagree" is professional, not personal
Detailed written agreements
Explicit contracts with specifics
Questions are encouraged
```

### Communication Matrix

| Aspect | High-Context | Low-Context |
|--------|--------------|-------------|
| **Message** | Implicit, indirect | Explicit, direct |
| **Conflict** | Avoid confrontation | Address directly |
| **Feedback** | Subtle, indirect | Frank, direct |
| **Contracts** | Flexible guidelines | Detailed specifications |
| **Relationships** | Build first, then business | Business first, relationships develop |
| **Time** | Polychronic (flexible) | Monochronic (punctual) |
| **Silence** | Comfortable, meaningful | Uncomfortable, fill it |

### Practical Business Scenarios

**Scenario 1: Saying "No" in Different Cultures**

**Japan (High-Context):**
```
❌ DON'T: "No, we can't do that."
✅ DO: "That would be quite challenging. We would need to
    carefully consider the implications."
```

**Germany (Low-Context):**
```
❌ DON'T: "Perhaps we might explore alternatives..."
✅ DO: "No, that's not feasible within our current
    constraints."
```

**Scenario 2: Giving Criticism**

**Korea (High-Context):**
```
❌ DON'T: "Your presentation was poorly organized."
✅ DO: "The presentation was good. Perhaps for the next one,
    you might consider reorganizing the flow slightly."
    [Give feedback privately, focus on future improvement]
```

**Netherlands (Low-Context):**
```
❌ DON'T: Beat around the bush
✅ DO: "The presentation structure needs improvement.
    Here are three specific issues: [list them clearly]"
    [Direct feedback is expected and appreciated]
```

## 🗣️ The Lewis Model: Cultural Communication Styles

### Three Categories

**1. Linear-Active** (논리적-능동형)
```
Countries: Germany, USA, UK, Switzerland, Nordic countries

Characteristics:
- Task-oriented
- Highly organized
- Facts over feelings
- Sequential planning
- Time = money
- Direct communication

Business Style:
"Let's stick to the agenda."
"What are the facts?"
"Time is of the essence."
"Let's be efficient."
```

**2. Multi-Active** (다중-능동형)
```
Countries: Italy, Spain, Latin America, Arab countries, India

Characteristics:
- People-oriented
- Flexible schedules
- Emotional expressiveness
- Multi-tasking
- Relationships first
- Indirect communication

Business Style:
"Let's get to know each other first."
"How is your family?"
"We have all the time we need."
"Trust is most important."
```

**3. Reactive** (경청-반응형)
```
Countries: Japan, China, Korea, Vietnam, Finland

Characteristics:
- Respect-oriented
- Listen more than speak
- Subtle communication
- Harmony-seeking
- Save face
- Reactive to partner's actions

Business Style:
"Please share your thoughts first."
[Thoughtful silence]
"We must consider all perspectives."
"Let us reflect on this carefully."
```

### Communication Strategies by Type

**When Working with Linear-Active Partners:**
```
✓ Be punctual - arrive 5 minutes early
✓ Prepare detailed agenda
✓ Stick to facts and data
✓ Be direct and clear
✓ Respect their time
✓ Follow up in writing
```

**When Working with Multi-Active Partners:**
```
✓ Build relationship first
✓ Be flexible with time
✓ Show enthusiasm
✓ Share meals together
✓ Allow conversation to flow naturally
✓ Be patient with interruptions
```

**When Working with Reactive Partners:**
```
✓ Show respect and humility
✓ Listen more than you speak
✓ Allow silence for thinking
✓ Avoid putting them on spot
✓ Be patient with decisions
✓ Focus on harmony and consensus
```

## 🌏 Cultural Intelligence (CQ) Development

### Four Components of CQ

**1. CQ Drive (Motivation)**
```
- Interest in other cultures
- Confidence in cross-cultural situations
- Willingness to adapt
```

**2. CQ Knowledge (Cognition)**
```
- Understanding cultural differences
- Knowledge of cultural frameworks
- Awareness of cultural norms
```

**3. CQ Strategy (Metacognition)**
```
- Planning for cultural interactions
- Checking cultural assumptions
- Adjusting mental models
```

**4. CQ Action (Behavior)**
```
- Adapting verbal communication
- Modifying nonverbal behavior
- Adjusting communication style
```

### Developing Your CQ

**Self-Assessment Questions:**
```
1. How comfortable am I with cultural ambiguity?
2. Do I genuinely enjoy learning about other cultures?
3. Can I suspend judgment about unfamiliar practices?
4. How well do I adapt my communication style?
5. Am I aware of my cultural biases?
```

**CQ Development Activities:**
```
✓ Study international business cases
✓ Watch foreign films and documentaries
✓ Read international news daily
✓ Practice with language learning apps
✓ Join multicultural professional groups
✓ Travel with cultural immersion mindset
✓ Seek mentors from different cultures
```
