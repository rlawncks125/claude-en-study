## 🌏 Regional Business Etiquette Guide

### ASIA

#### 🇨🇳 China - 중국

**Greetings & Meetings:**
```
✓ Handshake is common (lighter grip than Western style)
✓ Greet highest-ranking person first
✓ Use full title + surname (Director Wang, Manager Li)
✓ Present business card with both hands, facing recipient
✓ Study received cards respectfully before putting away
✓ Arrive 10-15 minutes early
✓ Wait to be told where to sit (hierarchy matters)
```

**Communication Style:**
```
✓ Indirect communication - read between lines
✓ "Maybe" or "We'll consider it" often means "No"
✓ Avoid direct confrontation or saying "no"
✓ Silence indicates thoughtfulness, not agreement
✓ Save face - never embarrass anyone publicly
✓ Build guanxi (关系 - relationships) before business
```

**Key Phrases:**
```
"请多关照" (Qǐng duō guānzhào) - "Please take care of me"
"辛苦了" (Xīnkǔle) - "You've worked hard" [shows appreciation]
"给面子" (Gěi miànzi) - "Give face" [show respect]
```

**Cultural Taboos:**
```
❌ Pointing with index finger (use open hand)
❌ Putting hands in pockets while talking
❌ Using red ink (signifies death)
❌ Gifts: clocks, white flowers, sharp objects (scissors/knives)
❌ Number 4 (sounds like "death")
```

#### 🇯🇵 Japan - 일본

**Greetings & Meetings:**
```
✓ Bow (slight bow for casual, deeper for respect)
✓ Business card exchange is ritual (meishi koukan 名刺交換)
  - Present with both hands
  - Receive with both hands
  - Read carefully, never write on it
  - Keep on table during meeting
✓ Extreme punctuality (arrive 5-10 min early)
✓ Remove shoes when required (look for slippers at entrance)
✓ Hierarchy strictly observed
```

**Communication Style:**
```
✓ Highly indirect and formal
✓ "Hai" (はい) means "I'm listening," not necessarily "yes"
✓ Sucking air through teeth = concern or difficulty
✓ Nemawashi (根回し) - behind-scenes consensus building
✓ Honne (本音) vs. Tatemae (建前) - true feelings vs. public facade
✓ Long silences are normal and respected
```

**Business Behavior:**
```
✓ Dress conservatively (dark suits)
✓ No excessive gesturing
✓ Sit up straight, feet flat on floor
✓ Pour drinks for others, not yourself
✓ After-work socializing (nomikai 飲み会) is important
✓ Be humble, avoid self-promotion
```

**Key Phrases:**
```
"よろしくお願いします" (Yoroshiku onegaishimasu) - "Please treat me favorably"
"お疲れ様です" (Otsukaresama desu) - "Thank you for your hard work"
"恐れ入ります" (Osore irimasu) - "I'm much obliged"
```

#### 🇰🇷 South Korea - 한국

**Greetings & Meetings:**
```
✓ Bow + handshake common (slight bow with handshake)
✓ Use both hands or support right forearm with left hand
✓ Business cards with both hands
✓ Age and position determine hierarchy
✓ Use appropriate titles (사장님 - President, 부장님 - Director)
✓ Punctuality important
```

**Communication Style:**
```
✓ Indirect communication, high-context
✓ Kibun (기분) - maintaining good feelings/harmony
✓ Respect for elders/seniors paramount
✓ Avoid direct "no" - use "It's difficult" or "We'll try"
✓ Nunchi (눈치) - reading the atmosphere/situations
✓ Building personal relationships crucial (정 - jeong)
```

**Business Culture:**
```
✓ Hierarchical decision-making
✓ Group harmony valued
✓ After-work drinking culture (회식 - hoesik)
✓ Conservative dress code
✓ Gift-giving at Chuseok and Lunar New Year
✓ Business relationships often become personal friendships
```

**Cultural Notes:**
```
✓ Receive/give with both hands or right hand with left support
✓ Don't pour your own drink; pour for others
✓ Elder pours first, turns away when drinking
✓ Number 4 avoided (sounds like "death")
```

#### 🇮🇳 India - 인도

**Greetings & Meetings:**
```
✓ Namaste gesture (🙏) or handshake (with men)
✓ Avoid physical contact with opposite gender unless offered
✓ Address with title + last name
✓ "IST" = Indian Stretchable Time (meetings may start late)
✓ Build relationships through personal conversations first
✓ Hierarchy important - respect seniority
```

**Communication Style:**
```
✓ Indirect communication to maintain harmony
✓ Head wobble (side to side) = yes/agreement/understanding
✓ Avoid direct confrontation
✓ "I'll try" or "I'll do my best" may mean it's unlikely
✓ English widely spoken but with local variations
✓ Extensive relationship building before business
```

**Cultural Considerations:**
```
✓ Right hand for eating/giving/receiving (left considered unclean)
✓ Remove shoes before entering homes/temples
✓ Dress conservatively (cover shoulders and knees)
✓ Vegetarianism common - always ask about dietary restrictions
✓ Cows are sacred - avoid beef products
```

### EUROPE

#### 🇩🇪 Germany - 독일

**Greetings & Meetings:**
```
✓ Firm handshake with eye contact
✓ Use professional titles + last name (Herr Dr. Schmidt)
✓ Extreme punctuality (arrive exactly on time, not early)
✓ Formal "Sie" (you) until invited to use "du"
✓ Structured, agenda-driven meetings
✓ Direct, factual communication
```

**Business Culture:**
```
✓ Efficiency and precision valued
✓ Detailed planning expected
✓ Decisions based on thorough analysis
✓ Work-life balance respected
✓ Quality over speed
✓ Written agreements detailed and binding
```

**Communication:**
```
✓ Direct and explicit - say what you mean
✓ Criticism is factual, not personal
✓ Stick to agenda and timelines
✓ Prepare thorough documentation
✓ Avoid small talk during business meetings
```

**Phrases:**
```
"Guten Tag" (Good day) - formal greeting
"Sehr geehrte/r" (Dear Sir/Madam) - formal letters
"Mit freundlichen Grüßen" (With friendly regards) - letter closing
```

#### 🇫🇷 France - 프랑스

**Greetings & Meetings:**
```
✓ Handshake (lighter than German)
✓ La bise (cheek kisses) only after relationship established
✓ Use "Monsieur" or "Madame" + last name
✓ "Vous" (formal you) until invited to use "tu"
✓ Dress elegantly and stylishly
✓ Punctuality expected, though some flexibility
```

**Business Culture:**
```
✓ Centralized decision-making (hierarchy respected)
✓ Long lunch breaks common (1.5-2 hours)
✓ Separate work and personal life
✓ Value intellectual debate and discussion
✓ Appreciation for French language (attempt some French)
✓ Quality of life important
```

**Communication:**
```
✓ Eloquent, sophisticated communication valued
✓ Debate and disagreement are normal
✓ Personal questions considered intrusive
✓ Written communication formal and precise
✓ Avoid aggressive sales tactics
```

#### 🇬🇧 United Kingdom - 영국

**Greetings & Meetings:**
```
✓ Firm handshake with eye contact
✓ Use titles and surnames until invited otherwise
✓ Punctuality important (arrive 5 minutes early)
✓ Understatement and restraint valued
✓ Queue culture - never jump the line
```

**Communication Style:**
```
✓ Polite indirectness (soften messages)
✓ "Quite good" = excellent, "Not bad" = very good
✓ "That's interesting" may mean disagreement
✓ Self-deprecating humor common
✓ Avoid boasting or over-enthusiasm
✓ "Sorry" used frequently (even when not at fault)
```

**British Business Phrases:**
```
"With all due respect..." = I completely disagree
"That's a brave proposal" = That's a terrible idea
"I'll bear that in mind" = I'll ignore that
"Correct me if I'm wrong..." = You're wrong
"Quite frankly..." = I'm about to be blunt
```

### MIDDLE EAST

#### 🇦🇪 UAE & Gulf States

**Greetings & Meetings:**
```
✓ Handshake (same gender) - may be prolonged
✓ Right hand only (left is unclean)
✓ Don't shake hands with opposite gender unless offered
✓ "As-salamu alaykum" (peace be upon you)
✓ Response: "Wa alaykumu s-salam" (and upon you peace)
✓ Meetings may not start on time - be patient
✓ Personal relationship building essential
```

**Cultural Considerations:**
```
✓ Islam central to culture - respect prayer times (5x daily)
✓ Dress modestly (men: long pants; women: cover shoulders/knees)
✓ Ramadan: no eating/drinking in public during daylight
✓ Friday is holy day (weekend: Friday-Saturday)
✓ Hierarchy and age highly respected
✓ Hospitality is sacred - accept tea/coffee offered
```

**Business Culture:**
```
✓ Relationship-based business
✓ Decisions made by senior authority
✓ Inshallah ("God willing") common - doesn't mean "no"
✓ Extended small talk before business
✓ May negotiate assertively
✓ Written contracts less important than trust
```

**Taboos:**
```
❌ Showing soles of feet/shoes
❌ Left hand for eating/giving
❌ Alcohol (in some countries)
❌ Public displays of affection
❌ Discussing politics, religion, or Israeli relations
❌ Photographing people without permission
```

## 🎁 International Gift-Giving Etiquette

### General Principles

**When to Give Gifts:**
```
✓ First business meeting (some cultures)
✓ Closing a deal
✓ Holiday seasons
✓ Return visit or hosting
✓ Expressing gratitude
```

**Gift Selection Guidelines:**
```
✓ Quality over quantity
✓ Branded from your country
✓ Company logo items (for initial meetings)
✓ Thoughtful and appropriate to culture
✓ Neither too cheap nor too expensive
✓ Professional, not personal (initially)
```

### Regional Gift-Giving Customs

**China:**
```
✓ Give: Fine liquor, specialty foods from home country, quality pens
✓ Avoid: Clocks (death), white flowers (funerals), sharp objects
✓ Red/gold wrapping (lucky colors)
✓ Give and receive with both hands
✓ Gifts opened in private
✓ Refuse gift 2-3 times before accepting (politeness)
✓ Eight of something = lucky, Four = unlucky
```

**Japan:**
```
✓ Give: Regional specialties, quality sweets, fine whisky
✓ Avoid: Sets of 4 or 9 (unlucky numbers), white flowers
✓ Meticulous wrapping essential
✓ Present with both hands, slight bow
✓ Gift quality matters - appearance is important
✓ Omiyage (お土産) - souvenirs for colleagues after travel
✓ Not opened in front of giver
```

**Korea:**
```
✓ Give: Fruits (expensive), ginseng, quality alcohol
✓ Avoid: Sets of 4, sharp objects, red ink
✓ Give and receive with both hands
✓ Don't open immediately unless asked
✓ Reciprocation expected
✓ More personal after relationship established
```

**Middle East:**
```
✓ Give: High-quality items, luxury goods, specialty foods
✓ Avoid: Alcohol, pork products, intimate items, dog-related items
✓ Give with right hand only
✓ Gold wrapping acceptable
✓ Opened in private
✓ Hospitality gifts appreciated
```

**Germany:**
```
✓ Give: Wine, books, office accessories
✓ Avoid: Personal items (initially), expensive gifts (seen as bribery)
✓ Unwrap immediately, show appreciation
✓ Quality and thoughtfulness important
✓ Odd number of flowers (but not 13)
```

**United States:**
```
✓ Give: Regional specialties, quality wine, gift baskets
✓ Avoid: Overly expensive (ethical concerns)
✓ Open immediately and express thanks
✓ Gifts less common in business than other cultures
✓ Be mindful of company gift policies
```

### Gift-Giving Phrases

```
"This is a small token of our appreciation."
"I hope you'll accept this humble gift."
"Please share this with your team."
"I thought you might enjoy this specialty from our region."
"Thank you so much for your hospitality."
"You're too kind. I really shouldn't..."
"This is too much, but thank you."
```

## 🍽️ International Business Dining Etiquette

### General Dining Principles

**Before the Meal:**
```
✓ Wait to be seated
✓ Follow host's lead
✓ Place napkin on lap when host does
✓ No phones on table
✓ Bread plate on left, drinks on right
```

**During the Meal:**
```
✓ Wait for host to start
✓ Pace yourself with others
✓ Keep elbows off table
✓ Small bites, chew with mouth closed
✓ Break bread, don't cut it
✓ Pass items to the right
```

**After the Meal:**
```
✓ Place utensils parallel on plate when finished
✓ Wait for host to signal end
✓ Thank the host
✓ Offer to host next time
```

### Regional Dining Customs

**China:**
```
✓ Guest of honor sits facing door
✓ Host orders for table
✓ Lazy Susan - turn clockwise
✓ Try everything offered
✓ Leaving food = you were well fed
✓ Toasting: "Ganbei!" (干杯 - Dry glass/Bottoms up)
✓ Pour for others, not yourself
✓ Host pays (arguing over bill is customary)
```

**Japan:**
```
✓ Say "Itadakimasu" (いただきます) before eating
✓ Say "Gochisousama deshita" (ごちそうさまでした) after
✓ Chopstick etiquette critical:
  - Don't stick upright in rice (funeral rite)
  - Don't pass food chopstick to chopstick
  - Rest on chopstick holder, not bowl
✓ Slurping noodles = showing appreciation
✓ Finish everything on plate
✓ Pour drinks for others
```

**Korea:**
```
✓ Eldest person eats first
✓ Pour drinks for others with both hands
✓ Receive with both hands
✓ Turn away from elders when drinking
✓ Chopsticks + spoon, but not simultaneously
✓ Don't leave chopsticks or spoon in rice
✓ Finish rice completely
✓ Keep pace with others
```

**Middle East:**
```
✓ Right hand only for eating
✓ May eat with hands (follow host's lead)
✓ Sitting on floor common
✓ Leave some food on plate (shows abundance)
✓ Accept second helpings (refusing = insult)
✓ Expect large portions and multiple courses
✓ Tea/coffee after meal important
```

**France:**
```
✓ Fork in left hand, knife in right (always)
✓ Wrists on table edge, not lap
✓ Bread on table, not on plate
✓ Never cut salad with knife
✓ Cheese course before dessert
✓ Wine knowledge appreciated
✓ Coffee comes after dessert
✓ Meal is social event - may last 2-3 hours
```

**United States:**
```
✓ "Zig-zag" method or European style acceptable
✓ Business discussion may start immediately
✓ Split bills common (but host usually pays)
✓ Tipping 15-20% expected
✓ Doggy bags acceptable
✓ More casual atmosphere
```

### Dietary Restrictions - Key Phrases

```
"Do you have any dietary restrictions?"
"I'm vegetarian/vegan."
"I don't eat pork/beef."
"I'm allergic to shellfish/nuts."
"I observe halal/kosher dietary laws."
"Could you recommend something?"
"I'll have the same as you."
"This looks delicious!"
```
