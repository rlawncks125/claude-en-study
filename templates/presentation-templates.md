## 1. Title Slides | 타이틀 슬라이드

### 1.1 Standard Title Slide
**표준 타이틀 슬라이드**

**Slide Content:**
```
[PRESENTATION TITLE]
[Subtitle or Tagline]

Presented by: [Your Name]
[Your Title]
[Company Name]

[Date]
```

**Opening Script:**
```
Good [morning/afternoon], everyone. Thank you for being here today.

My name is [Your Name], and I'm the [Your Title] at [Company Name].

Today, I'm going to talk about [TOPIC], and by the end of this presentation,
you'll understand [KEY TAKEAWAY 1], [KEY TAKEAWAY 2], and [KEY TAKEAWAY 3].

I've prepared [NUMBER] slides that will take approximately [DURATION] minutes,
and I'll be happy to take your questions at the end.

Let's get started.
```

**한국어 설명:**
- 명확한 제목과 발표자 정보
- 청중이 얻을 수 있는 것을 미리 제시
- 소요 시간 안내로 기대치 설정

---

### 1.2 Problem-Statement Title Slide
**문제 제기형 타이틀 슬라이드**

**Slide Content:**
```
[PROVOCATIVE QUESTION OR STATISTIC]

[Main Title]
How [Your Solution] Can Help

[Your Name], [Title]
[Company Name]
[Date]
```

**Opening Script:**
```
Let me start with a question: [THOUGHT-PROVOKING QUESTION]?

According to [SOURCE], [SURPRISING STATISTIC OR FACT].

This is exactly why we're here today. I'm [Your Name] from [Company Name],
and today I'm going to show you how [YOUR SOLUTION] can address this challenge.

Over the next [DURATION] minutes, we'll explore [KEY POINTS],
and I think you'll find some surprising insights.
```

**한국어 설명:**
- 충격적인 질문이나 통계로 관심 유도
- 문제 의식 공유로 청중과 공감대 형성
- 해결책을 제시할 것임을 예고

---

### 1.3 Story-Based Title Slide
**스토리형 타이틀 슬라이드**

**Slide Content:**
```
[IMAGE RELATED TO STORY]

[Intriguing Title]
A Story About [TOPIC]

[Your Name]
[Date]
```

**Opening Script:**
```
I want to start with a story.

[TELL BRIEF, RELEVANT STORY - 30-60 seconds]

This story illustrates exactly what we're going to discuss today: [MAIN TOPIC].

I'm [Your Name], and I've spent the last [TIME PERIOD] working on [AREA].
Today, I'll share what we've learned and how it can help you [BENEFIT].

Here's what we'll cover...
```

**한국어 설명:**
- 스토리텔링으로 청중의 감정적 연결
- 개인적 경험이나 사례 공유
- 기억에 남는 시작

## 2. Agenda Slides | 안건 슬라이드

### 2.1 Simple Agenda
**단순 안건**

**Slide Content:**
```
Today's Agenda

1. [TOPIC 1]
2. [TOPIC 2]
3. [TOPIC 3]
4. [TOPIC 4]
5. Q&A

Estimated Time: [DURATION] minutes
```

**Script:**
```
Here's what we'll cover today.

First, we'll look at [TOPIC 1], where I'll explain [BRIEF DESCRIPTION].

Then, we'll move on to [TOPIC 2], which addresses [BRIEF DESCRIPTION].

Third, we'll discuss [TOPIC 3], covering [BRIEF DESCRIPTION].

And finally, we'll wrap up with [TOPIC 4], where we'll [BRIEF DESCRIPTION].

After that, I'll open the floor for questions.

Does this agenda work for everyone? Great, let's dive in.
```

**한국어 설명:**
- 명확한 흐름 제시
- 각 섹션의 간단한 설명
- 예상 소요 시간 공유

---

### 2.2 Visual Journey Agenda
**시각적 여정 안건**

**Slide Content:**
```
Our Journey Today

[VISUAL: Path/Road with milestones]

Where We Are → Where We're Going → How We'll Get There → What Success Looks Like

[Milestone 1]  [Milestone 2]  [Milestone 3]  [Milestone 4]
```

**Script:**
```
Think of today's presentation as a journey.

We're starting from where we are now - [CURRENT STATE].

Then we'll explore where we need to go - [DESIRED STATE].

Next, we'll map out how we'll get there - [THE SOLUTION/STRATEGY].

And finally, we'll define what success looks like - [OUTCOMES/METRICS].

This journey will take us through [NUMBER] key insights that I believe will transform
how you think about [TOPIC].

Ready to begin?
```

**한국어 설명:**
- 은유적 표현으로 흥미 유발
- 시작부터 결과까지의 흐름 시각화
- 청중이 프레젠테이션의 방향을 이해하도록 도움

---

### 2.3 Time-Based Agenda
**시간 기반 안건**

**Slide Content:**
```
Agenda (60 minutes)

10:00-10:15  Opening & Context
10:15-10:30  Current Challenges
10:30-10:45  Proposed Solutions
10:45-10:55  Implementation Plan
10:55-11:00  Next Steps & Q&A
```

**Script:**
```
We have one hour together, and I want to make the most of your time.

In the first 15 minutes, I'll provide context and background.

From 10:15 to 10:30, we'll examine the challenges we're facing.

Then, from 10:30 to 10:45, I'll present our proposed solutions.

At 10:45, we'll discuss the implementation plan.

And we'll wrap up with next steps and your questions.

I'll do my best to stick to this timeline, so please feel free to signal
if I'm running over.
```

**한국어 설명:**
- 정확한 시간 배분
- 참석자들의 시간 관리 가능
- 전문성과 조직력 표현

## 3. Problem/Solution Slides | 문제/해결 슬라이드

### 3.1 Problem Statement
**문제 진술**

**Slide Content:**
```
The Challenge We Face

Current Situation:
• [PROBLEM POINT 1]
• [PROBLEM POINT 2]
• [PROBLEM POINT 3]

Impact:
• [CONSEQUENCE 1]
• [CONSEQUENCE 2]
• [CONSEQUENCE 3]

[SUPPORTING DATA/CHART]
```

**Script:**
```
Let's talk about the challenge we're facing.

Currently, we're dealing with [MAIN PROBLEM]. Specifically:

[PROBLEM POINT 1] - This means that [IMPACT].

[PROBLEM POINT 2] - As a result, [IMPACT].

And [PROBLEM POINT 3] - Which leads to [IMPACT].

The data here shows that [KEY INSIGHT FROM DATA].

This isn't just inconvenient - it's costing us [QUANTIFIABLE IMPACT]
in terms of [TIME/MONEY/RESOURCES/OPPORTUNITIES].

The question is: what do we do about it?
```

**한국어 설명:**
- 문제를 명확하고 구체적으로 제시
- 영향을 수치화
- 긴급성 강조

---

### 3.2 Solution Overview
**해결책 개요**

**Slide Content:**
```
Our Solution: [SOLUTION NAME]

The Answer:
[ONE-LINE DESCRIPTION OF SOLUTION]

Key Features:
✓ [FEATURE 1] → [BENEFIT 1]
✓ [FEATURE 2] → [BENEFIT 2]
✓ [FEATURE 3] → [BENEFIT 3]

Why It Works:
[BRIEF EXPLANATION]
```

**Script:**
```
Now, let me introduce our solution: [SOLUTION NAME].

In simple terms, [ONE-LINE DESCRIPTION].

This solution has three key features that directly address the problems
we just discussed.

First, [FEATURE 1]. This means you'll be able to [BENEFIT 1].

Second, [FEATURE 2], which will help you [BENEFIT 2].

And third, [FEATURE 3], enabling you to [BENEFIT 3].

Why does this work? Because it [EXPLANATION OF MECHANISM/APPROACH].

Unlike other approaches that [COMMON LIMITATION], our solution [UNIQUE ADVANTAGE].
```

**한국어 설명:**
- 해결책을 간단명료하게 설명
- 기능을 이점과 연결
- 차별점 강조

---

- 시각적 대비로 변화 강조

## 4. Financial Slides | 재무 슬라이드

### 4.1 Budget Breakdown
**예산 분석**

**Slide Content:**
```
Budget Overview

Total Investment: $[AMOUNT]

Breakdown:
• [CATEGORY 1]: $[X] ([X]%)
• [CATEGORY 2]: $[X] ([X]%)
• [CATEGORY 3]: $[X] ([X]%)
• [CATEGORY 4]: $[X] ([X]%)

[PIE CHART OR BAR GRAPH]
```

**Script:**
```
Let's talk about the investment required.

The total budget for this initiative is $[AMOUNT].

This breaks down into four main categories:

[CATEGORY 1] represents [X]% of the budget at $[X]. This covers [WHAT IT INCLUDES].

[CATEGORY 2] is [X]% or $[X], which will go toward [WHAT IT INCLUDES].

[CATEGORY 3] accounts for [X]%, totaling $[X]. This includes [WHAT IT INCLUDES].

And [CATEGORY 4] makes up the remaining [X]% at $[X] for [WHAT IT INCLUDES].

As you can see from this chart, the largest portion goes to [CATEGORY],
which is critical because [REASON].
```

**한국어 설명:**
- 명확한 예산 항목
- 백분율과 금액 모두 표시
- 각 항목의 용도 설명

### 4.2 ROI Projection
**ROI 예측**

**Slide Content:**
```
Return on Investment

Initial Investment: $[AMOUNT]

Year 1: $[RETURN] ([X]% ROI)
Year 2: $[RETURN] ([X]% ROI)
Year 3: $[RETURN] ([X]% ROI)

Break-Even Point: [TIMEFRAME]
Total 3-Year ROI: [X]%

[LINE GRAPH SHOWING GROWTH]
```

**Script:**
```
Now, let's look at the return on investment.

We're proposing an initial investment of $[AMOUNT].

In Year 1, we project a return of $[RETURN], which represents a [X]% ROI.

By Year 2, we expect returns to increase to $[RETURN], or [X]% ROI.

And in Year 3, we're forecasting $[RETURN], bringing us to a [X]% ROI.

The break-even point is [TIMEFRAME], which means we'll recoup the initial
investment [EXPLANATION OF TIMING].

Over three years, we're looking at a total ROI of [X]%, which translates
to [DOLLAR AMOUNT] in value created.

This chart illustrates the growth trajectory...
```

**한국어 설명:**
- 연도별 수익 전망
- 손익분기점 명확히
- 장기적 가치 강조

## 9. Q&A Handling | 질의응답 처리

### 9.1 Answering Questions Effectively
**효과적인 질문 답변**

**Techniques:**

**1. Acknowledge the Question**
```
"That's an excellent question."
"I'm glad you brought that up."
"That's a very important point."
```

**2. Clarify if Needed**
```
"Just to make sure I understand, you're asking about [RESTATE QUESTION]?"
"Are you specifically interested in [ASPECT]?"
"Let me make sure I'm answering the right question..."
```

**3. Provide a Clear Answer**
```
"The answer is [DIRECT ANSWER]."
"Here's how we handle that: [EXPLANATION]."
"There are two parts to that answer. First, [PART 1]. Second, [PART 2]."
```

**4. Check for Understanding**
```
"Does that answer your question?"
"Is that what you were looking for?"
"Would you like me to elaborate on any part of that?"
```

**한국어 설명:**
- 질문을 존중하는 태도
- 필요시 질문 명확화
- 간결하고 직접적인 답변
- 이해 확인

---

### 9.2 Handling Difficult Questions
**어려운 질문 처리**

**Scenarios and Responses:**

**When You Don't Know the Answer:**
```
"That's a great question, and I don't have that specific data with me right now.
What I can tell you is [RELATED INFORMATION].
Let me get back to you with the exact information by [TIMEFRAME]."
```

**When the Question is Off-Topic:**
```
"That's an interesting point, though it's a bit outside the scope of today's
discussion. I'd be happy to discuss that with you separately after the
presentation if you'd like."
```

**When the Question is Critical/Negative:**
```
"I appreciate you raising that concern. It's a valid point.
Here's how we've addressed that: [RESPONSE].
Are there specific aspects you'd like me to expand on?"
```

**When You Need Time to Think:**
```
"That's a complex question. Let me think about the best way to explain this..."
[PAUSE]
"Okay, here's what I think..."
```

**When Someone Challenges Your Data:**
```
"I understand your skepticism. This data comes from [SOURCE], and here's the
methodology: [BRIEF EXPLANATION].
I'd be happy to share the full research with you after this."
```

**한국어 설명:**
- 모르는 것을 인정하되 후속 조치 약속
- 주제에서 벗어난 질문은 정중히 연기
- 비판적 질문에도 방어적이지 않게
- 생각할 시간이 필요하면 요청

## 10. Presentation Tips | 프레젠테이션 팁

### 10.1 Delivery Tips
**발표 기술**

**Voice and Pace:**
- Speak clearly and at a moderate pace
- Pause for emphasis
- Vary your tone to maintain interest
- Project your voice without shouting

**Body Language:**
- Make eye contact with different audience members
- Use natural hand gestures
- Stand straight with open posture
- Move purposefully, don't pace nervously
- Smile genuinely

**Energy:**
- Show enthusiasm for your topic
- Stay engaged and present
- Match energy to the importance of points
- Take deep breaths to stay calm

**한국어 설명:**
- 명확한 발음과 적절한 속도
- 강조할 때 잠시 멈춤
- 청중과 눈 맞춤
- 자연스러운 제스처
- 진정한 열정 표현

---

### 10.2 Slide Design Tips
**슬라이드 디자인 팁**

**Visual Hierarchy:**
- One main idea per slide
- Use large, readable fonts (minimum 24pt)
- Limit text (no more than 6 bullets per slide)
- Use high-contrast colors
- Consistent formatting throughout

**Images and Graphics:**
- Use high-quality images
- Charts should be simple and clear
- Icons can replace text when appropriate
- White space is your friend
- Animate only when it adds value

**Color Scheme:**
- Stick to 2-3 primary colors
- Ensure accessibility (color-blind friendly)
- Dark text on light background (or vice versa)
- Use brand colors consistently

**한국어 설명:**
- 슬라이드당 하나의 주요 아이디어
- 큰 글꼴과 적은 텍스트
- 고품질 이미지 사용
- 일관된 색상 구성
- 여백 활용

---

### 10.3 Technical Preparation
**기술적 준비**

**Before the Presentation:**
- Test all equipment in the actual room
- Have backup copies (USB, cloud, email)
- Test all videos and links
- Know how to access presenter mode
- Charge devices fully
- Bring adapters/dongles
- Have a backup plan if tech fails

**During the Presentation:**
- Start with slides in presenter view
- Know keyboard shortcuts
- Have a pointer or use software pointer
- Keep remote/clicker nearby
- Stay near power source if needed

**한국어 설명:**
- 사전 장비 테스트
- 백업 파일 준비
- 발표자 모드 숙지
- 기술 문제 대비 플랜 B

### 10.5 Common Mistakes to Avoid
**피해야 할 일반적인 실수**

❌ **Reading from slides**
- Slides are visual aids, not your script
- Know your content well enough to speak naturally

❌ **Turning your back to audience**
- Face the audience, not the screen
- Use presenter mode or quick glances

❌ **Speaking in monotone**
- Vary your voice and energy
- Show enthusiasm

❌ **Going over time**
- Practice timing
- Be ready to skip slides if needed
- Respect the schedule

❌ **Too much text on slides**
- Use visuals instead of words
- Bullet points, not paragraphs

❌ **No clear structure**
- Tell them what you'll tell them
- Tell them
- Tell them what you told them

❌ **Ignoring the audience**
- Watch for confused faces
- Check for understanding
- Adjust based on reactions

❌ **Not preparing for questions**
- Anticipate likely questions
- Practice answers
- It's okay to say "I don't know"

**한국어 설명:**
- 슬라이드를 읽지 말 것
- 청중에게 등을 돌리지 말 것
- 단조로운 톤 피하기
- 시간 엄수
- 텍스트 과다 사용 금지
- 명확한 구조 필요
- 청중 반응 관찰
- 질문 준비

---

### 10.6 Handling Nervousness
**긴장감 다루기**

**Before the Presentation:**
- Practice multiple times
- Visualize success
- Arrive early to get comfortable with the space
- Do breathing exercises
- Remember: mild nervousness can enhance performance

**During the Presentation:**
- Start with a confident opening you've rehearsed
- Focus on friendly faces in the audience
- Remember to breathe
- Pause when needed
- It's okay to have water nearby
- Slow down if you're speaking too fast

**Reframe Nervousness:**
- Nervousness = excitement about your topic
- The audience wants you to succeed
- You know more about this topic than they do
- Focus on the value you're providing

**한국어 설명:**
- 충분한 연습
- 성공적인 발표 상상
- 일찍 도착하여 환경 적응
- 호흡 조절
- 긴장을 열정으로 재해석
- 청중은 발표자의 성공을 원함

## Quick Reference Guide | 빠른 참조 가이드

### Presentation Structure Template
```
1. Title Slide (1 minute)
   - Grab attention
   - Introduce yourself
   - Set expectations

2. Agenda (1 minute)
   - Show roadmap
   - Set time expectations

3. Problem/Context (5-7 minutes)
   - Establish why this matters
   - Use data and stories

4. Solution/Main Content (15-20 minutes)
   - Present your main ideas
   - Use visuals and examples
   - Pause for questions

5. Evidence/Support (5-10 minutes)
   - Case studies
   - Data and metrics
   - Testimonials

6. Implementation/Next Steps (3-5 minutes)
   - Timeline
   - Resources needed
   - Clear action items

7. Summary (2 minutes)
   - Recap key points
   - Reinforce main message

8. Call to Action (1 minute)
   - What you want them to do
   - How to proceed

9. Q&A (10-15 minutes)
   - Answer questions
   - Clarify points

10. Closing (1 minute)
    - Thank audience
    - Provide contact info
```

```

- Opening: 2 min

- Close + Q&A: 3 min

30-Minute Presentation:
- Opening: 3 min

- Close + Q&A: 7 min

45-Minute Presentation:
- Opening: 5 min
- Content: 30 min

60-Minute Presentation:
```
