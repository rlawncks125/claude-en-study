## 📖 오늘의 문법: I + 동사

### 기본 구조
```
I + 동사 + (목적어)
```

### 패턴 익히기

#### 1. I + 동사 (간단한 문장)
```
I go. (나는 가)
I run. (나는 달려)
I sleep. (나는 자)
```

#### 2. I + 동사 + 명사 (목적어 있는 문장)
```
I eat food. (나는 음식을 먹어)
I drink water. (나는 물을 마셔)
I like cats. (나는 고양이를 좋아해)
I want a book. (나는 책을 원해)
I have a phone. (나는 전화기를 가지고 있어)
```

### 문장 만드는 방법
1. I (나는)
2. + 동사 (행동)
3. + 명사 (무엇을?)
