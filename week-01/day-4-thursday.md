## 📖 문법: 현재진행형

> 상세 설명: [grammar/06-progressive.md](../grammar/06-progressive.md)

### 기본 구조

```
am/is/are + 동사ing

I am working. (지금 일하는 중)
She is attending a meeting. (미팅 참석 중)
They are discussing the plan. (계획 논의 중)
```

### -ing 만들기
```
일반: work → working
-e로 끝: make → making, write → writing
단모음+단자음: run → running, sit → sitting
```

## 🎯 현재 vs 현재진행형

### 현재 시제 (일반적, 습관)
```
I work at Samsung.
(삼성에서 일해요 - 직장)

I check my email every morning.
(매일 아침 이메일 확인해요 - 습관)

She manages a team.
(팀을 관리해요 - 역할)
```

### 현재진행형 (지금, 임시)
```
I'm working on a report.
(보고서 작업 중이에요 - 지금)

I'm checking my email.
(이메일 확인하는 중이에요 - 현재)

She's managing this project.
(이 프로젝트를 관리 중이에요 - 임시)
```

### 비교표

| 상황 | 현재 | 현재진행형 |
|------|------|------------|
| 직업 | I work as a developer. | I'm working on a project. |
| 거주지 | I live in Seoul. | I'm living with my parents. (임시) |
| 상태 | I use Mac. | I'm using the meeting room. |

## 💬 실전 상황

### 1. 전화 응대
```
A: Hi, is Sarah available?
B: Sorry, she's in a meeting right now.
   She's presenting the quarterly results.

A: When will she be available?
B: The meeting should end at 3.
   She's meeting a client after that.
```

### 2. 업무 현황 공유
```
A: What are you working on?
B: I'm working on the marketing campaign.
   I'm creating the content calendar.

A: When is the deadline?
B: We're launching it next week.
```

### 3. 일정 조율
```
A: Can we meet tomorrow?
B: I'm meeting clients all day tomorrow.
   How about Friday?

A: I'm attending a conference on Friday.
B: Are you available next Monday?
A: Yes, that works.
```

## ⚠️ 상태동사 (진행형 X)

다음 동사들은 진행형으로 쓰지 않습니다:

### 감정/사고
```
❌ I'm knowing the answer.
✅ I know the answer.

❌ I'm understanding it.
✅ I understand it.

also: love, like, hate, want, need, believe, think(의견)
```

### 소유
```
❌ I'm having a car.
✅ I have a car.

also: own, belong, possess
```

### 감각
```
❌ I'm seeing it.
✅ I see it.

also: hear, smell, taste (인식의 의미)
```

**예외:**
```
I'm having a meeting. ✅ (경험)
I'm thinking about it. ✅ (생각하는 과정)
I'm seeing him tomorrow. ✅ (만나다)
```

## 💡 현재진행형의 3가지 용도

### 1. 지금 진행 중
```
I'm working on it right now.
She's attending a meeting.
They're discussing the proposal.
```

### 2. 임시 상황
```
I'm working from home this week.
(이번 주만 재택)

She's using my office while I'm away.
(내가 없는 동안 임시로)

We're hiring temporary staff.
(임시 직원 채용 중)
```

### 3. 가까운 미래 (확정된 계획)
```
I'm meeting the client tomorrow.
We're launching the product next week.
They're presenting on Friday.
```
