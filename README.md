1. Read the full strategy guide: [영어-초보자-학습-전략.md](./영어-초보자-학습-전략.md)
2. Start with the 4-week plan
3. Practice daily for at least 30 minutes
4. Be consistent and patient!

## 💪 Key Principles

- **Consistency over intensity** - Study a little every day
- **Don't fear mistakes** - They're part of learning
- **Start with basics** - Alphabet, pronunciation, common words
- **Make it fun** - Use content you enjoy
- **Practice all skills** - Listening, speaking, reading, writing

## 📈 Expected Progress

- **1-3 months**: Basic foundation (alphabet, 300 words, simple patterns)
- **3-6 months**: Basic conversation (common phrases, daily routines)
- **6+ months**: Continuous improvement (media consumption, real conversations)
