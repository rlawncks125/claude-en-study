## 💪 핵심 학습 원칙 (Key Principles)

- **매일 조금씩** - 하루 30분이라도 꾸준히
- **실수 두려워하지 않기** - 틀려도 괜찮아요!
- **기초부터 탄탄히** - 알파벳, 발음, 기본 단어부터
- **재미있게** - 좋아하는 콘텐츠로 학습
- **소리 내어 연습** - 듣기, 말하기, 읽기, 쓰기 모두

- ✅ 일상 영어 사용
- ✅ 영어로 생각하기 시작
- ✅ 실전 회화 가능
